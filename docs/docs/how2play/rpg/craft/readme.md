# 炼器，炼丹，符法，阵法，灵植，灵兽

这些辅助流派，可以创造物品。

## 炼器

当前工坊的装备打造即时完成，不使用图纸，也不需要等待。打造消耗矿产、木材、原玉等资源和词条碎片；材料本身不会直接把词条附加到装备上，额外词条通过装备精炼得到的 `ExtractedAffix` 注入。具体规则见「物品 → 装备」章节。

以下是辅助流派的长期规划，尚未完整实现：炼器可以消耗时间、材料和可选图纸；图纸可以指定物品的词条类型；矿物、动物和植物材料可以提供更丰富的打造选择。

## 卡牌精炼与太古词条

灵宝、神照、真定、坐忘、混元及对应碎片均为无境界材料，可用于任意境界的卡牌；符纸与符纸碎片也不分境界。新增或替换词条时，新词条直接使用卡牌当前境界。

破镜丹与破镜残韵保留境界和对应名称。卡牌破境要求丹药境界高于卡牌当前境界；角色突破试炼使用目标境界的破镜丹。

普通卡牌的额外词条上限为 3 条。太古是已有额外词条的品质，不占用新槽位：
太古额外词条在卡面前显示 `✶` 和黄色文本，自动锁定，主词条不会成为太古。
太古数值通常取来源卡牌当前境界满级后按词条配置强化，不统一放大所有机制。

- **灵宝**：优先补足当前境界的额外词条槽位。已有 3 条且达到结丹后，改为进行一次 5% 太古判定；
  成功时随机将一个合格的额外词条升为太古。未触发时仍消耗材料，并提示本次未凝结太古。
- **神照**：随机替换一个境界最低且未锁定的额外词条；新词条有 5% 概率成为太古。
- **真定**：随机锁定一个非太古额外词条，最多锁定 3 条，太古也计入数量。
- **坐忘**：随机移除一个未锁定的额外词条；已有太古因自动锁定而不会被移除。
- **混元**：先重置主词条及所有可变、非太古词条的等级，再进行一次 5% 太古判定；
  成功时随机选择一个合格的非太古额外词条，普通真定词条也可能被选中。
- **破境**：保留主词条和全部已有额外词条。普通词条保留当前等级，太古自动升至新境界满级。
  若仍有空槽，有 25% 概率新增一条；随后每个合格的非太古额外词条有 25% 概率成为太古。

符箓复制继承原卡的太古状态与数值快照，不会重新判定太古。
