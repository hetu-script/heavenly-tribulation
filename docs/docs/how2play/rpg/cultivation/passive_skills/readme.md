# 天赋盘

游戏中不能直接加属性点，而是提升修为等级获得对应的属性点。

每次提升修为等级会获得 1 点天赋点，可以在天赋盘上分配天赋点获得额外的卡牌、技能和属性。

游戏中需要从五个主流派中分别选择一个进行搭配。

## 规则

- 最内圈的五个节点是五个流派的起点，开局五选一。已有加点后，其他流派入口也遵循统一的邻接规则：沿连线到达其相邻节点后即可解锁；退回全部已分配的节点后，恢复开局五选一。
- 加点沿连线自由进行：任何与已解锁节点相邻的节点都可以分配（可以绕环而行，也可以沿另一条半径走回内侧）。
- 普通节点与流派境界节点均消耗 1 点天赋点，退回时均返还 1 点。
- 流派境界节点只要求角色已经达到节点对应境界，不再触发突破试炼。退点不会降低角色境界，重新解锁仍需满足境界要求并消耗天赋点。
- 退点时如果会导致其他已解锁节点与流派起点失去连接，则不允许退回。
