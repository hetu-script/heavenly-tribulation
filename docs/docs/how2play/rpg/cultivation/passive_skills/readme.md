# 天赋盘

游戏中不能直接加属性点，而是提升修为等级获得对应的属性点。

每次提升修为等级会获得 2 点天赋点，可以在天赋盘上分配天赋点获得额外的卡牌、技能和属性。

游戏中需要从五个主流派中分别选择一个进行搭配。

## 规则

- 最内圈的五个节点是五个流派的起点，五选一：一旦分配了任意节点，其余四个流派的起点不可再选。退回全部已分配的节点后，可以重新选择流派起点。
- 加点沿连线自由进行：任何与已解锁节点相邻的节点都可以分配（可以绕环而行，也可以沿另一条半径走回内侧）。
- 普通节点每个消耗 1 点天赋点，退回时返还 1 点；境界节点不消耗天赋点。
- 境界节点（大节点）首次需要通过突破试炼解锁；也可以退点，但不返还天赋点，且角色自身境界不变。再次解锁同境界的流派境界节点无需再次试炼。
- 退点时如果会导致其他已解锁节点与流派起点失去连接，则不允许退回。
