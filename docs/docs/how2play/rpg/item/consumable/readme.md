## 丹药

所有的丹药都固定包含一个治疗效果。

同时根据境界还会有其他的效果。其他效果分为临时 buff 和永久 buff 两种。

### 治疗

治疗
治疗（可超过最大生命）

### 临时效果

临时性丹药效果属于战前配置，在下一次战斗后消失。含额外词条的丹药会以整套新配置替换旧的非永久战前配置；仅主词条丹药保留现有配置，只精确更新同 ID 的旧临时主效果。永久效果和独立临时效果不受整体替换影响。旧配置包含太古时，服用前会显示额外警告。

### 丹药词条

| 境界 | 主词条             | 额外词条总数 | 其中太古上限(✶) |
| ---- | ------------------ | ------------ | --------------- |
| 无   | 治疗               | 0-1          | 0               |
| 凝气 | 治疗               | 0-2          | 0               |
| 筑基 | 治疗               | 0-3          | 0               |
| 结丹 | 治疗（可超过上限） | 0-3          | 0-1             |
| 还婴 | 治疗（可超过上限） | 0-3          | 0-2             |
| 化神 | 治疗（可超过上限） | 0-3          | 0-3             |

随机生成允许只有主词条。太古是已有额外词条的品质，不占新槽位，取来源丹药当前境界满级后按词条配置强化；主词条不参与。
服用丹药时写入完整词条快照，太古品质、等级、数值和机制修正均会生效，并在下一次战斗后随非永久临时效果一起清除。

## 绝世 unique

绝世是一种特殊丹药

这种丹药只有主词条，没有额外词条。因此所有词条都是固定的。
