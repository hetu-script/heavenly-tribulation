## 装备

装备可以为人物提供加成

装备使用的词条系统和天赋盘的技能使用的系统是相同的。

一个角色的总属性等于基础属性+装备提供的属性+天赋提供的属性+临时buff提供的属性（丹药和聚灵阵）。

最终他们会合并计算。

### 角色等级和装备栏位

角色根据境界可以装备不同数量的物品

| 境界 | 物品栏位 |
| ---- | -------- |
| 无   | 3        |
| 凝气 | 4        |
| 筑基 | 5        |
| 结丹 | 6        |
| 还婴 | 7        |
| 化神 | 8        |

### 装备类型限制

category 决定了能同时装备的种类数量
weapon, armor, helmet, boots, ship, aircraft 每种只能装备一个
jewelry 和 talisman 则无限制

### 装备稀有度

| 稀有度 | 名称      | 基础词条 | 额外词条 | 太古词条(✶) | 对应境界 |
| :----- | --------- | -------- | -------- | ----------- | -------- |
| 凡品   | common    | 1        | 0        | 0           | 无       |
| 良品   | rare      | 1        | 0-2      | 0           | 凝气     |
| 上品   | epic      | 1        | 1-3      | 0           | 筑基     |
| 极品   | legendary | 1        | 2-4      | 0-1         | 结丹     |
| 绝品   | mythic    | 1        | 3-5      | 1-2         | 还婴     |
| 神品   | arcane    | 1        | 4-6      | 2-3         | 化神     |

对于直接生成的物品，额外词条和太古词条数量会有数量浮动

在打造物品时，额外词条数量则固定为数量上限

### 装备精炼

装备精炼可以提取某个装备词条，并用于装备打造中。

但被提取后，原始的装备将会被销毁。

### 装备打造

在工坊中可以进行装备打造和装备精炼

打造装备需要消耗指定的资源，并花费一定的时间。

打造装备的过程并不要求玩家保持不动，而是可以自由行动等待装备完成。

## 绝世 unique

绝世是一种特殊装备

这种装备的词条 id 是固定的（词条的数值仍在生成时随机），并且不能进行词条析取。但仍可以进行重铸。

绝世装备的规则：

- 数据预定义在 `assets/data/items.json5` 中（字段约定见该文件末尾注释），不经随机生成，只能作为预定义物品获得
- 同一 id 的绝世装备同时只能装备一件；不同 id 的绝世装备（即使是同一种类）互不影响
- 获得时默认为未鉴定状态，需要使用鉴定卷轴鉴定后才能装备（类比绝世卡牌）
- 不能在工坊中进行词条析取

## 生产工具

某些装备可以提高生产效率，但同时也可以当做武器。

斧，可以使用剑法，提高伐木场效率
锤，可以使用刀法，提高矿场效率
耙，可以使用枪法，提高农场效率
锄，可以使用棍法，提高狩猎效率
弓，可以使用弓术，提高猎场效率
针，可以使用暗器功法，提高纹身工坊效率
