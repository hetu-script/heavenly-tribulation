## 装备

装备可以为人物提供加成

装备使用的词条系统和天赋盘的技能使用的系统是相同的。

一个角色的总属性等于基础属性+装备提供的属性+天赋提供的属性+临时buff提供的属性（丹药和聚灵阵）。

最终他们会合并计算。

### 角色等级和装备栏位

角色根据境界可以装备不同数量的物品

| 境界 | 物品栏位 |
| ---- | -------- |
| 无   | 3        |
| 凝气 | 4        |
| 筑基 | 5        |
| 结丹 | 6        |
| 还婴 | 7        |
| 化神 | 8        |

### 装备类型限制

category 决定同类装备的同时装备限制。weapon、shield、armor、gloves、helmet、boots、vehicle 七类每种默认只能装备一个；jewelry 和 talisman 不受类别数量限制。

角色拥有对应的 `${category}UnrestrictedEquip` 被动时，可以豁免该类别的数量限制。

### 装备属性要求

玩家装备需要满足由装备种类和实际等级决定的属性要求：`要求 = 种类基础值 + ceil(装备等级 × 种类系数)`。第一版种类基础值均为 0。

| 种类 | 属性 | 等级系数 |
| --- | --- | ---: |
| 剑 | 身法 | 1.5 |
| 刀 | 体魄 | 1.5 |
| 枪 | 神识 | 1.5 |
| 棍 | 神识 | 1.25 |
| 弓 | 念力 | 1.25 |
| 暗器 | 念力 | 1.5 |
| 宝珠 | 灵力 | 1.5 |
| 盾牌 | 体魄 | 1.0 |
| 护甲 | 体魄 | 1.25 |
| 手套 | 身法 | 1.0 |
| 头盔 | 念力 | 1.0 |
| 靴子 | 身法 | 1.25 |
| 船 | 神识 | 1.0 |
| 指环 | 灵力 | 1.0 |
| 项链 | 灵力 | 1.25 |

验收使用基础属性与天赋等永久来源之和，装备和临时增益不计入。绝世装备默认使用所属种类的规则，也可以在原型上单独覆盖。

属性下降不会自动卸下已装备物品，但会使其失效：不提供词条、地形能力或卡牌装备条件，栏位、类别数量和绝世重复限制仍然有效。属性重新达标后装备自动恢复。NPC 不受装备属性要求限制。

### 固定主词条

剑、刀、枪、棍、弓和暗器的主词条分别为对应功法伤害增加，例如剑为剑法和御剑术伤害增加；通用武器攻击力不会成为主词条。靴子与船的主词条池分别包含山地/水面移动速度。它们与其他来源的同 ID 词条按同一规则聚合，主词条不参与太古，也不能通过精炼提取。
功法与地形解锁直接由已装备物品的种类决定，不占用被动词条；相关说明显示在装备的风味文本中。

### 装备稀有度

| 稀有度 | 名称      | 基础词条 | 额外词条总数 | 其中太古上限(✶) | 对应境界 |
| :----- | --------- | -------- | ------------ | --------------- | -------- |
| 凡品   | common    | 1        | 0-1          | 0               | 无       |
| 良品   | rare      | 1        | 0-2          | 0               | 凝气     |
| 上品   | epic      | 1        | 0-3          | 0               | 筑基     |
| 极品   | legendary | 1        | 0-3          | 0-1             | 结丹     |
| 绝品   | mythic    | 1        | 0-3          | 0-2             | 还婴     |
| 神品   | arcane    | 1        | 0-3          | 0-3             | 化神     |

随机生成允许只有主词条；主动打造固定取当前境界的额外词条上限，结丹及以上均为 3 条。
太古是已有额外词条的品质，不占新槽位。构造生成有 5% 概率出现太古，取来源装备当前境界满级后按词条配置强化；主词条不参与。
太古额外词条在悬浮提示中以 `✶` 和黄色文本显示。

### 装备精炼

装备精炼可以提取某个**额外词条**，并用于装备打造中；主词条不能提取，原装备会被销毁。
提取太古词条会完整保留品质、有效等级、数值快照和来源装备境界 `sourceRank`。
填槽时词条的 `kinds` 必须包含目标装备种类，来源境界不得高于目标装备境界；已有太古计入目标装备当前境界上限，不重新判定太古，普通提取词条仍可参与打造后的 5% 太古判定。种类不匹配时无法选择或打造。
打造成功后会消耗填入的萃取词条物品。同一件装备不能重复注入相同 ID 或 `uniqueId` 的词条；注入词条也不能与所有可用主词条冲突，否则无法打造。

### 装备打造

在工坊中可以进行装备打造和装备精炼。打造消耗指定资源与词条碎片，并即时完成，不需要等待。

## 绝世 unique

绝世是一种特殊装备

这种装备的词条 id 是固定的，主词条之后固定有 3 个额外词条；不能进行词条析取，装备破境与重铸尚未实现。

绝世装备的规则：

- 数据预定义在 `assets/data/items.json5` 中（字段约定见该文件末尾注释），不经随机生成，只能作为预定义物品获得
- 原型 rank 是最低生成境界；奖励可以显式指定更高境界，低于原型的传入值不会削弱装备
- rank 1 解锁 2 个固定额外词条，rank 2 解锁 3 个；rank 3～5 按 `greaterAffixes` 依次将三个已有词条太古化，主词条不参与
- 同一 id 的绝世装备同时只能装备一件；不同 id 的绝世装备（即使是同一种类）互不影响
- 获得时默认为未鉴定状态，需要使用鉴定卷轴鉴定后才能装备（类比绝世卡牌）
- 不能在工坊中进行词条析取

### 中立绝世装备

#### 乾坤戒 `cosmos_ring`（凝气）

- **主效果**：手牌上限 +2，每回合抽牌 -1。
- `turn_start_gain_vigor`：每回合元气产出 +1；化神太古时提高至 +2。
- `handSizeMax`：手牌上限再 +1；还婴太古时提高至 +2。
- `energyRetainLife`（筑基解锁）：至多保留 1 点元气，每保留 1 点在下回合开始受到 2 点纯粹伤害；结丹太古时保留上限提高至 2。
- 所有正负抽牌修正统一累加，与基础抽牌合并为一批；实际抽牌仍受手牌剩余空间约束。太极之气的永久保留不受本装备影响。

#### 无极佩 `limitless_amulet`（结丹）

- **主效果**：每回合第一张实际打出的中立加持牌使自身获得 1 层无极之气；五种流派卡牌费用 +1。中立攻击牌不触发，流派牌不会消耗当回合机会，法身牌属于流派牌。
- `start_battle_with_buff_all_damage`：战斗开始获得无极之气，结丹时已经太古化，在普通数值上额外 +1 层。
- `penetration`：提高护甲穿透，还婴太古时数值 ×1.5。
- `critThreshold`：降低暴击充能阈值，化神太古时数值 ×1.5，仍受全局上下限约束。
- 每层无极之气使造成的所有伤害 +5。新增无极在卡牌结算后获得，不会追溯强化触发它的那张牌。
