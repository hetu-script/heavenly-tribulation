# 资源列表

战斗中的气分为**资源气**（参与费用与产出循环）与**普通状态**两类。

## 资源气（6 阳 6 阴，按对列出）

| 阳气     | 作用                                                                     | 阴气     | 作用                                                                   |
| -------- | ------------------------------------------------------------------------ | -------- | ---------------------------------------------------------------------- |
| 元气     | 无色费用池：回合开始获得固定 3 层（+装备词条加成）；支付元气（无色）费用 | 死气     | 抵消元气；产出对冲后仍有剩余时失去 5% 生命上限，不自动消耗            |
| 灵气     | 支付灵气（悟道）费用                                                     | 逆灵之气 | 抵消持有者获得的灵气                                                   |
| 剑气     | 支付剑气（御剑）费用                                                     | 止戈之气 | 抵消持有者获得的剑气                                                   |
| 怒气     | 支付怒气（锻体）费用；自身受伤 +5%/层                                    | 非战之气 | 抵消持有者获得的怒气                                                   |
| 煞气     | 支付煞气（炼魂）费用                                                     | 无心之气 | 抵消持有者获得的煞气                                                   |
| 太极之气 | **万能费用色**：任意有色费用不足时自动抵扣                               | 混沌之气 | **万能封锁**：抵消持有者获得的四色阳气（元气除外）；与太极之气互相抵消 |

> 无极之气与虚空之气**不再是资源气**：它们已拆分为纯粹的攻击增益/减益状态，
> 见文末「攻击轴状态」一节。

资源气占一个 UI 槽位，显示**净值**（阳 − 阴）：阴阳对冲保证同对阴阳不会同时持有
（获得阳气时先抵消持有的对应阴气）；阴大于阳时同一图标以反色显示。

除太极外的阳气遵循**统一生命周期**：在持有者的下个回合开始时清空（而非自己回合结束），
即持有期间覆盖对方的整个回合——对方能看到你没花完的费用。回合结束的结算
（煞气未用量返回业力池）仍按剩余量进行，仅清空时机延后。
战斗开始时获得的阳气是例外：角色在本场战斗中的第一次行动不会清空它们，之后恢复统一生命周期。
**太极之气与阴气不适用该周期**：两者永久存在，直到被支付或被对应阴气对冲抵消。

元气：每回合开始获得固定 3 层（+装备词条 basicEnergyBonus 加成），下次行动开始时清空上回合残留
死气：先抵消本次元气产出；若抵消后仍有剩余，失去 5% 生命上限，不自动消耗层数
煞气：未用量在下次清空时返回业力池，战斗胜利业力池 +5；战斗开始从池中提取的规则仍属规划
灵气：已通过悟道凝气节点「太上感应」按灵力产出，也可由卡牌和装备效果提供
剑气/怒气：流派产出规则随天赋树重构中，见 plan/battle_resource_rework.md 与 plan/skill_tree/
太极之气：永久保留，只能通过支付费用或与混沌之气对冲来减少

# 资源消耗和使用

卡牌费用为**硬检查**：费用不足时卡牌不能打出（置灰并提示缺少什么）。
支付无色费用 = 移除元气层数；支付有色费用 = 移除对应气层数，先扣本色气、
不足的部分自动以太极之气抵扣。

# 战斗资源系统设计

## 一、费用模型：单资源（见 plan/battle_resource_rework.md）

每张卡牌只花一种资源，费用在数据层显式写入卡牌的 coloredCost 映射（含 life 键）：

- **流派卡 = rank 点流派色**：悟道→灵气、御剑→剑气、锻体→怒气、炼魂→煞气；以对应有色气（energy*positive*\* 状态层数）支付。
- **中立卡（无流派，含法身）= ceil((rank+1)/2) 点元气（1,1,2,2,3,3）**：以元气（energy_positive_life 状态层数）支付。基础产出为每回合 3 层，装备词条、先天功与万化归墟等效果还可提供额外元气。
- 特例：符箓固定 1 元气；显式 `life: 0` 的免费卡（如绝世卡归元功）。
- 多色/混费卡现阶段不设计，但支付引擎保留能力（未来设计）。

费用检查规则：无色费用 ≤ 剩余元气，且每色需求 ≤ 对应气存量 + 太极之气存量。
阴气不直接增费，其影响通过阴阳对冲体现（抵消阳气后存量不足则无法支付）。

## 二、统一生命周期

除太极外的阳气（元气、灵气、剑气、怒气、煞气）在持有者**下个回合开始时清空**，
顺序：先清空上回合残留（煞气未用量返回业力池）→ 再结算本回合新产出。
元气产出会先与死气对冲；若抵消后仍持有死气，失去 5% 生命上限，死气不会自动消耗。
角色第一次行动跳过清空步骤，以保留战斗开始时获得的阳气。
太极之气与阴气不在此列：两者永久存在，直到被支付或被对应阴气对冲抵消；死气仅按上述规则结算伤害。
设计理由：

- 怒气的"每层受伤 +5%"等防御侧效果必须让资源活到对方回合才有意义；
- 对方能看到你没花完的费用（炉石式信息）；
- 没花掉的怒气在对方回合是防御风险——花掉怒气既是进攻收益也是卸除防御 debuff。

## 三、产出模型

| 气 | 当前产出与实现状态 |
| --- | --- |
| 元气 | 每回合开始固定 3 层 + 装备词条加成（先清空上回合残留）；先天功、万化归墟等卡牌效果也可提供额外元气。 |
| 灵气 | 悟道凝气节点「太上感应」在产出阶段每 10 点灵力提供 1 层；蓄灵诀、聚灵旗等卡牌和装备也能提供。 |
| 剑气/怒气 | 流派产出规则仍在天赋树重构中，见 `plan/skill_tree/`。 |
| 太极之气 | 中立心法转换卡以 0 费耗尽所有元气，按 2:1 向下取整转化；先天功达到元气门槛后也可额外提供。 |
| 煞气 | 战斗胜利业力池 +5，未用完的煞气在清空时返回业力池；战斗开始从池中提取的规则仍属规划。 |

规划中的剑气/怒气滞后产出会延后一轮：上回合没打武器牌则断剑气，没被打则断怒气。
这是武器系持续进攻、徒手系以伤换力的节奏设计；种子与产出保底同样尚未实现。

## 四、溢出与剩余利用

原则：**剩余不用不再有惩罚，只作为特殊天赋可以利用的资源**。

- 元气的回合结束回血已移除（单资源模型下元气纯资源化）；构筑级治疗出口见绝世卡归元功（消耗所有元气按比例回复生命）。
- 悟道结丹境界节点「阴阳五行」已在回合结束时将未保留、未使用的灵气转化为随机元素伤害；蓄灵佩保留的灵气不参与该结算，其余剩余气默认清空。
- 乾坤戒可通过承受纯粹伤害保留元气，蓄灵佩可通过同类规则保留灵气。
- 单次获得的层数仍受上限（灵力/身法）约束，超出部分在获得时截断。

| 流派 | 费用色 | 产出定位 |
| --- | --- | --- |
| 悟道 spellcraft | 灵气 | 已通过「太上感应」实现每回合按灵力产出。 |
| 御剑 swordcraft | 剑气 | 战初按身法÷10，之后按上回合武器牌数产出（规划中）。 |

# 攻击轴状态（非资源气）

无极之气与虚空之气曾是资源气（万能费用对，旧 id 已由太极/混沌沿用），
现为**普通状态**，与资源气体系完全分离：

| 状态     | 作用                                        |
| -------- | ------------------------------------------- |
| 无极之气 | 每层使造成的所有伤害 +5；与虚空之气互相抵消 |
| 虚空之气 | 每层使造成的所有伤害 -5；只能被无极之气抵消 |

- 不占用资源气槽位，以普通状态图标显示在状态栏；
- **不适用统一生命周期**：永久保留，不随回合清空；
- 互相获得时按对立状态对冲（同幸运/不幸等 buff/debuff 对）；
- 来源：rank 3 起的卡牌额外词条（无极真言/虚空侵蚀）、装备被动、丹药。

# 特殊资源

## 充能

法器是一种打造出的战斗卡牌，效果等同于凝气期或以上的卡牌。但法器本身没有流派要求。只是有使用次数限制。

御剑可以掌握给法器充能的能力。之后便可以花费灵石为法器补充次数。

将被充能的物品装备在身上之后，进入战斗便会附带灵气。但会消耗物品上的充能数量。

装备本身的储能有上限。装备在身上后即可带入战斗，体现为灵气。

## 淬毒

> 注：淬毒装备系统为规划中内容，当前版本尚未实现（战斗重构阶段 4 仅落地了毒素攻击卡牌与中毒持续伤害）。

炼魂流可以掌握给装备淬毒的能力。之后便可以花费毒药材料，将可装备类物品淬毒。

装备本身的储能有上限。

战斗中无法补充此资源。
