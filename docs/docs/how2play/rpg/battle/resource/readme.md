# 资源列表

战斗中的气分为**资源气**（参与费用与产出循环）与**普通状态**两类。

| 阳气     | 作用                                                                                                   | 阴气     | 作用                                                                       |
| -------- | ------------------------------------------------------------------------------------------------------ | -------- | -------------------------------------------------------------------------- |
| 元气     | 无色费用池：回合开始获得 rank+3 层；支付无色费用；回合结束每剩余 1 层回复 2% 生命上限（每层至少 1 点） | 死气     | 回合开始时消耗 1 层，失去 10% 生命上限；持有时每层使无色费用 +1（至多 +2） |

| 无极之气 | 所有攻击 +5/层；**万能费用色**：任意有色费用不足时自动抵扣                                             | 虚空之气 | 所有攻击 -5/层；有色费用 +1/层（至多 +2）                                  |

资源气占一个 UI 槽位，显示**净值**（阳 − 阴）：阴阳对冲保证同对阴阳不会同时持有
（获得阳气时先抵消持有的对应阴气）；阴大于阳时同一图标以反色显示。

所有资源气遵循**统一生命周期**：在持有者的下个回合开始时清空（而非自己回合结束），
即持有期间覆盖对方的整个回合——对方能看到你没花完的费用。回合结束的结算
（元气回血、灵气溢出利用、煞气返回业力池）仍按剩余量进行，仅清空时机延后。

# 资源消耗和使用

卡牌费用为**硬检查**：费用不足时卡牌不能打出（置灰并提示缺少什么）。
支付无色费用 = 移除元气层数；支付有色费用 = 移除对应气层数，先扣本色气、
不足的部分自动以无极之气抵扣。

另外，获得资源还可以驱散对应的伤势：每次获得元气时减少 1 层内伤；
每次获得灵气（含无极之气）时减少 1 层幻觉。

# 战斗资源系统设计

## 一、费用模型：无色 + 有色

每张卡牌的总费用 = 境界 + 1，由两部分组成：

- **无色费用**：以元气（energy_positive_life 状态层数）支付，每回合开始获得 rank + 3 层。
- **有色费用**（qiCost）：以四色气（灵气/剑气/怒气/煞气）支付，颜色由卡牌流派决定：
  悟道→灵气、御剑→剑气、锻体→怒气、炼魂→煞气、法身→怒气+煞气（双色对半拆，奇数时多出的一点给怒气）。
  无流派卡与 rank 0 卡全无色。

费用检查规则：无色费用 ≤ 剩余元气，且每色需求 ≤ 对应气存量 + 无极之气存量。
持有某色的阴气时，该色费用 +1/层（同色至多 +2）；死气对应无色费用。

## 二、统一生命周期

所有资源气（元气、四色、无极，及 6 种阴气）在持有者**下个回合开始时清空**，
顺序：先清空上回合残留（煞气未用量返回业力池）→ 再结算本回合新产出。
设计理由：

- 怒气的"每层受伤 +5%"等防御侧效果必须让资源活到对方回合才有意义；
- 对方能看到你没花完的费用（炉石式信息）；
- 没花掉的怒气在对方回合是防御风险——花掉怒气既是进攻收益也是卸除防御 debuff。

## 三、产出模型（滞后一轮的滚雪球）

| 气   | 产出                                                                                                                                                              |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 元气 | 每回合开始 rank + 3（先清空上回合残留）                                                                                                                           |
| 灵气 | 战斗开始按灵力 ÷10 获得；回合开始若开启"灵气获取"且未达上限则 +1；流派节点产出（规划中）                                                                          |
| 剑气 | 开启"剑气获取"后：回合开始获得 = **上回合打出的武器攻击牌数量**；节点种子/加成（规划中）                                                                          |
| 怒气 | 开启"怒气获取"后：回合开始获得 = **上回合自身受到的伤害 ÷10**（向下取整）；节点种子/加成（规划中）                                                                |
| 煞气 | 开启"煞气获取"后：每回合开始从业力池提取 `min(提取上限, max(1, 池存量 ÷10))`，提取上限 = 念力 ÷10（+天赋）；未用完的煞气在下次清空时返回业力池；战斗胜利业力池 +5 |

剑气/怒气的产出滞后一轮：上回合没打武器牌 → 本回合断剑气；没被打 → 断怒气。
这是有意的节奏设计（武器系要持续进攻、徒手系要以伤换力），流派境界节点的
种子与产出加成（规划中）将作为每回合保底，降低断档风险。

## 四、溢出与剩余利用

原则：**剩余不用不再有惩罚，只作为特殊天赋可以利用的资源**。

- 灵气：回合结束时按**剩余层数**触发溢出天赋——转化为元气（转化出的元气赶上同回合回血），
  或对对手造成随机元素伤害。
- 剑气：溢出惩罚已删除；剩余剑气默认直接清空，剩余利用天赋/装备（规划中）。
- 单次获得的层数仍受上限（灵力/身法）约束，超出部分在获得时截断。

| 流派            | 费用色      | 产出定位                                   |
| --------------- | ----------- | ------------------------------------------ |
| 悟道 spellcraft | 灵气        | 战初一次性 + 获取天赋 + 节点（规划中）     |

# 特殊资源

## 充能

法器是一种打造出的战斗卡牌，效果等同于凝气期或以上的卡牌。但法器本身没有流派要求。只是有使用次数限制。

御剑可以掌握给法器充能的能力。之后便可以花费灵石为法器补充次数。

将被充能的物品装备在身上之后，进入战斗便会附带灵气。但会消耗物品上的充能数量。

装备本身的储能有上限。装备在身上后即可带入战斗，体现为灵气。

## 淬毒

> 注：淬毒装备系统为规划中内容，当前版本尚未实现（战斗重构阶段 4 仅落地了毒素攻击卡牌与中毒持续伤害）。

炼魂流可以掌握给装备淬毒的能力。之后便可以花费毒药材料，将可装备类物品淬毒。

装备本身的储能有上限。

战斗中无法补充此资源。
