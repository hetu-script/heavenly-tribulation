# 资源消耗和使用

卡牌费用为**硬检查**：费用不足时卡牌不能打出（置灰并提示缺少什么）。
支付无色费用 = 移除元气层数；支付有色费用 = 移除对应气层数，先扣本色气、
不足的部分自动以无极之气抵扣。

另外，获得资源还可以驱散对应的伤势：每次获得元气时减少 1 层内伤；
每次获得灵气（含无极之气）时减少 1 层幻觉。

# 战斗资源系统设计

## 一、费用模型：单资源（见 plan/battle_resource_rework.md）

每张卡牌只花一种资源，费用在数据层显式写入卡牌的 coloredCost 映射（含 life 键）：

- **流派卡 = rank 点流派色**：悟道→灵气、御剑→剑气、锻体→怒气、炼魂→煞气；以对应有色气（energy_positive_* 状态层数）支付。
- **中立卡（无流派，含法身）= rank+1 点元气**：以元气（energy_positive_life 状态层数）支付；元气每回合开始获得固定 3 层（装备词条 battleEnergyBonus 可加成）。
- 特例：符箓固定 1 元气；显式 `life: 0` 的免费卡（如绝世卡归元功）。
- 多色/混费卡现阶段不设计，但支付引擎保留能力（未来设计）。

费用检查规则：无色费用 ≤ 剩余元气，且每色需求 ≤ 对应气存量 + 无极之气存量。
阴气不直接增费，其影响通过阴阳对冲体现（抵消阳气后存量不足则无法支付）；
唯一的例外是虚空之气：存在时使所有有色费用 +1/层，无上限。
唯一的例外是虚空之气：存在时使所有有色费用 +1/层，无上限。

## 二、统一生命周期

所有阳气（元气、四色、无极）在持有者**下个回合开始时清空**，
顺序：先清空上回合残留（煞气未用量返回业力池）→ 再结算本回合新产出。
角色第一次行动跳过清空步骤，以保留战斗开始时获得的阳气。
阴气不在此列：阴气永久存在，直到被对应阳气对冲抵消。
设计理由：

- 怒气的"每层受伤 +5%"等防御侧效果必须让资源活到对方回合才有意义；
- 对方能看到你没花完的费用（炉石式信息）；
- 没花掉的怒气在对方回合是防御风险——花掉怒气既是进攻收益也是卸除防御 debuff。

## 三、产出模型

| 气   | 产出 |
| ---- | ---- |
| 元气 | 每回合开始固定 3 层 + 词条加成（先清空上回合残留） |
| 煞气 | 战斗开始时从业力池一次性带入；未用完的煞气在下次清空时返回业力池；战斗胜利业力池 +5 |
| 灵气/剑气/怒气 | 随天赋树重构中：由各流派初始（凝气）节点产出——悟道每回合按灵力产出；御剑战初按身法÷10、之后按上回合武器牌数滞后产出；锻体战初按体魄÷10、之后按上回合受伤滞后产出。见 plan/battle_resource_rework.md 第 3 节与 plan/skill_tree/ |

剑气/怒气的滞后产出延后一轮：上回合没打武器牌 → 本回合断剑气；没被打 → 断怒气。
这是有意的节奏设计（武器系要持续进攻、徒手系要以伤换力）。
种子与产出加成（规划中）将作为每回合保底，降低断档风险。

## 四、溢出与剩余利用

原则：**剩余不用不再有惩罚，只作为特殊天赋可以利用的资源**。

- 元气的回合结束回血已移除（单资源模型下元气纯资源化）；构筑级治疗出口见绝世卡归元功（消耗所有元气按比例回复生命）。
- 灵气溢出天赋（转化为元气/随机元素伤害）暂未启用，设计以注释形式保留在回合结束资源结算钩子中（待悟道境界节点）；剩余气默认直接清空。
- 剩余利用类天赋/装备（规划中）。
- 单次获得的层数仍受上限（灵力/身法）约束，超出部分在获得时截断。

# 特殊资源

## 充能

法器是一种打造出的战斗卡牌，效果等同于凝气期或以上的卡牌。但法器本身没有流派要求。只是有使用次数限制。

御剑可以掌握给法器充能的能力。之后便可以花费灵石为法器补充次数。

将被充能的物品装备在身上之后，进入战斗便会附带灵气。但会消耗物品上的充能数量。

装备本身的储能有上限。装备在身上后即可带入战斗，体现为灵气。
