# 战斗资源系统设计

## 一、流派-资源映射：链条模型

### 设计

五大流派与四种资源不是一一对应，而是一条**资源链**：

```
灵气 ────→ 剑气 ────→ 怒气 ────→ 煞气
 │           │           │           │
悟道        御剑        锻体        炼魂
            (灵气+剑气)  (剑气+怒气)
                        法身
                        (怒气+煞气)
```

| 流派            | 主要资源    | 次要资源 | 在链条上的位置          |
| --------------- | ----------- | -------- | ----------------------- |
| 悟道 spellcraft | 灵气        |          | 最左端，纯法术          |
| 御剑 swordcraft | 剑气        | 灵气     | 灵气→剑气过渡，魔武双修 |
| 锻体 bodyforge  | 怒气        | 剑气     | 剑气→怒气过渡，以伤换怒 |
| 法身 avatar     | 怒气 + 煞气 |          | 怒气→煞气过渡，横跨两域 |
| 炼魂 vitality   | 煞气        |          | 最右端，纯因果          |

## 二、资源的双重功能

### 设计

每种资源同时具有两个功能：

| 功能         | 机制                             | 例子                         |
| ------------ | -------------------------------- | ---------------------------- |
| **被动加成** | 持有资源本身就会增强对应伤害类型 | 每点怒气 +5 徒手攻击基础伤害 |
| **主动消耗** | 卡牌可以消耗资源换取更强效果     | 消耗 3 点怒气，造成额外伤害  |

## 三、四种资源的差异化节奏

### 灵气（Mana）

**生成**：战斗开始时，基于灵力（spirituality）获得初始灵气。灵力同时决定灵气上限。

**消耗**：部分卡牌消耗灵气换取额外效果（法术增伤、元素共鸣等）。

**溢出**：无效果。超出上限的灵气直接浪费。

**节奏特征**：**计划型**。灵气在战斗开始时就确定了大致的可用量。战斗中的核心决策是"如何分配有限的灵气"。配合悟道的元素共鸣（换元素=额外灵气），可以延长灵气的可用时间。

**设计意图**：灵气是"内力"——有限而珍贵，需要规划使用。这不奖励无脑倾泻，而奖励精打细算。

---

### 剑气（Chakra）

**基础生成**：使用**武器攻击卡牌**并造成伤害时，获得 1 点剑气。Per-card 触发，多段攻击与单段攻击平权。

**额外生成**：通过天赋节点、绝世装备或特定卡牌效果获得额外剑气。例如：身法高于阈值时额外 +1、剑法暴击时额外 +1 等。额外剑气的获取分散到构筑中，成为有意义的投资选择。

**消耗**：回合结束时，**所有剑气全部消失**。

**上限**：身法（dexterity）决定剑气上限。超出上限的部分造成随机负面效果（如给自己施加 debuff）——溢出有害。

**节奏特征**：**爆发窗口型**。"本回合内生成→本回合花掉→回合结束清零"。这创造了一种独特的回合内节奏：

- 回合开始：剑气为 0
- 打出武器攻击卡牌 → 积累剑气
- 用积累的剑气打出强力终结技
- 回合结束：剑气归零，下回合重新开始

**设计意图**：剑气是"锐气"——锋锐但转瞬即逝。按卡牌计数简洁明了，不需要玩家做伤害计算。多段攻击的优势体现在触发 on-hit 额外词条（外伤等），与剑气生成形成自然分工。

**设计方案排除记录**：

| 方案             | 问题                                                   |
| ---------------- | ------------------------------------------------------ |
| per-hit 触发     | 暗器 5 段 = 5 剑气 vs 剑法 1 段 = 1 剑气，多段碾压单段 |
| 每 10 伤害触发   | RPG 数值成长后固定阈值形同虚设                         |
| 目标生命 5% 触发 | 玩家需做除法才能预估资源收益，理解成本过高             |

---

### 怒气（Rage）

**生成**：以下两种情况立刻获得 1 点怒气：

1. 自己的伤害被对手的护甲阻挡时（包括全部被挡与部分被挡）
2. 对手使用攻击卡牌时

**软上限**：**无硬性上限，但每点怒气使自身受到的伤害 +5%。**

- 5 点怒气 → +25 徒手伤害，但受到伤害 +25%
- 15 点怒气 → +75 徒手伤害，但受到伤害 +75%
- 上限由"你能承受多少额外伤害"决定，而非系统强制扣减

**衰减**：每回合结束时，怒气减半（最低为 0）。

**节奏特征**：**反击型玻璃大炮**。越是被压制，反击越强——但同时自身越来越脆弱。核心张力："我还能承受几轮？反击的时机到了吗？"

- 对手猛烈进攻 → 怒气飙升 → 下一拳威力惊人，但也暴露在致命伤害下
- 主动消耗怒气可以降低风险；攒着不花则越来越危险
- 配合防御卡牌（堆防御 → 被挡 → +怒气 → 但受伤放大让穿透更危险）

**设计意图**：怒气是"战意"——战意越盛，越是舍弃防御。无上限但自带反噬，上限由玩家的生命值管理能力决定。这与锻体的"叠层爆发"定位契合：爆发力随怒气增长，但风险同步增长。

**设计方案排除记录**：

| 方案                  | 问题                                           |
| --------------------- | ---------------------------------------------- |
| 无限制 + per-hit 获取 | 长战斗无限积累，需系统强制扣减                 |
| 有怒气时攻击自伤      | 惩罚主动攻击，多段卡变自残，违背"叠层爆发"幻想 |
| 回合结束固定扣减+回收 | 被动损耗，"系统收走怒气"而非玩家管理           |

**与剑气的对比**：

| 维度     | 剑气                  | 怒气                   |
| -------- | --------------------- | ---------------------- |
| 生成条件 | 武器攻击卡造成伤害    | 你被打/被挡            |
| 消失条件 | 回合结束全部清零      | 每回合减半             |
| 上限     | 有（身法 + 溢出惩罚） | 无硬上限，受伤放大软限 |
| 鼓励行为 | 武器攻击、卡牌连用    | 承受、防御反击         |
| 玩法感觉 | 灵敏、爆发            | 嗜血、高风险           |

---

### 煞气（Karma，又称业力）

**生成**：战斗结束后获得（目前通过 `enable_karma` 被动：战斗胜利 +5）。在下一次战斗中，每 10 点念力（perception/willpower）可以带入 1 点煞气进入战斗。

**消耗**：部分卡牌消耗煞气换取强大效果（诅咒、生命操控等）。

**节奏特征**：**跨战斗积累型**。煞气是唯一横跨多场战斗的资源。它在战斗之间积累，在战斗中消费。

- 普通战斗：积累煞气
- Boss 战/关键战：带上充足的煞气进入，释放强大效果
- 连战/副本：前几场积累煞气，后几场释放

**设计意图**：煞气是"因果"——业力不虚，报应不爽。它是长期的、不可见的、积累性的。炼魂流派的核心玩法是"管理一个跨战斗的资源池"——这是完全不同于其他三个资源的维度。

**潜在问题**：如果煞气只能通过战斗胜利积累，那么失败会打断积累节奏。建议增加替代积累方式：冥想、服用丹药、特定事件等。

## 四、四种资源节奏对比

| 维度     | 灵气                 | 剑气                  | 怒气                     | 煞气                 |
| -------- | -------------------- | --------------------- | ------------------------ | -------------------- |
| 生成时机 | 战斗开始             | 武器攻击卡造成伤害    | 被攻击/被挡时            | 战斗结束后           |
| 消失时机 | 只有主动使用才会消耗 | 回合结束全部清零      | 回合结束减半             | 只有主动使用才会消耗 |
| 时间跨度 | 整场战斗             | 单个回合              | 数回合                   | 多场战斗             |
| 上限     | 有（灵力）           | 有（身法 + 溢出惩罚） | 无硬上限（受伤放大软限） | 有（念力/10）        |
| 溢出行为 | 浪费                 | 自我 debuff           | 不适用                   | 无                   |
| 核心决策 | 如何分配             | 何时爆发              | 何时反杀/何时花掉        | 何时消费             |
| 对应流派 | 悟道                 | 御剑                  | 锻体                     | 炼魂                 |
| 玩法感觉 | 精打细算             | 瞬息万变              | 嗜血、高风险             | 厚积薄发             |

四种资源各有完全不同的时间节奏和决策维度。这不是"四种颜色的 mana"——它们从生成、存续、到消失的方式都截然不同。

## 五、灵气和煞气的细化

> 以下为**设计提案，尚未实现**，仅作记录。

### 灵气的细化

当前设计中灵气"战斗开始一次性获得 + 上限限制 + 溢出无效果"，对比另三种资源缺少交互感。建议：

1. **灵气自然回复**：

每次牌库为空，重新将弃牌堆洗牌时，恢复一定数量的灵气。

灵力的价值不只是"初始灵气多"，而是"灵力越高，能维持的灵气水平越高"。

2. **悟道的灵气额外来源**：元素共鸣（换元素 +1 灵气）成为悟道流派的灵气续航手段。非悟道角色只能依赖初始灵气 + 自然回复，使用元素法术的续航远不如悟道。

3. **上限的意义**：灵力决定了"可以同时持有多少灵气"。高灵力 = 可以囤积灵气等待爆发窗口。低灵力 = 必须随用随补，无法囤积。

### 煞气的细化

1. **积累方式多样化**：
   - 战斗胜利：基础积累
   - 对敌人施加 debuff：额外积累
   - 自身承受 debuff：额外积累
   - 特定卡牌："获得煞气"（类似 mana 卡牌生成灵气）

2. **跨战斗携带**：每 10 点念力携带 1 点煞气。这意味：
   - 低念力角色：煞气再多也只能带少量进入战斗
   - 高念力角色：可以带入大量煞气
   - 念力成为炼魂流派的核心属性——不只是伤害加成，还决定资源获取

3. **煞气的双重功能**：
   - 被动：每点煞气 +5 诅咒/精神攻击基础伤害（对应"咒语"标签）
   - 主动：消耗煞气换取强大效果

## 六、灵气的溢出机制（补充讨论）

> 以下为**设计提案，尚未实现**，仅作记录。

灵气溢出默认无效果，但现有 passives.json5 中有几个相关被动：

- `overflowed_mana_convert_to_vigor`（灵气溢出转为元气）
- `overflowed_mana_deal_elemental_damage`（灵气溢出造成元素伤害）
- `mana_is_also_chakra`（灵气同时视为剑气）

建议：灵气溢出**默认无效果**（简洁），但通过天赋节点或装备可以获得溢出效果。这样：

- 新手不需要理解溢出，浪费了就是浪费了
- 老手通过构筑解锁溢出价值，形成构筑深度
- 道法自然袍（绝世装备）可以将溢出灵气转为护盾

## 七、资源平衡考量

### 每点资源的伤害等效

| 资源 | 被动加成        | 主动消耗回报                    | 生成难度                            |
| ---- | --------------- | ------------------------------- | ----------------------------------- |
| 灵气 | +5 法术基础伤害 | 8-10（通过卡牌消耗）            | 易（战斗开始 + 自然回复 + 共鸣）    |
| 剑气 | +5 武器基础伤害 | 8-10（通过卡牌消耗）            | 中（每张武器卡 +1，但回合结束清零） |
| 怒气 | +5 徒手基础伤害 | 8-10（通过卡牌消耗）            | 难（挨打才获得，自带受伤放大）      |
| 煞气 | +5 诅咒基础伤害 | 10+（跨战斗积累，应有更高回报） | 最难（跨战斗积累，带入有限）        |

煞气的主动消耗回报应高于其他三种资源，因为它的积累跨越多个战斗，投入的时间成本更高。

### 防止无限积累

- 灵气：上限限制
- 剑气：回合结束清零 + 上限 + 溢出惩罚
- 怒气：回合结束减半（软性衰减）
- 煞气：跨战斗带入上限（念力/10）+ 战斗中消耗

# 特殊资源

## 充能

法器是一种打造出的战斗卡牌，效果等同于凝气期或以上的卡牌。但法器本身没有流派要求。只是有使用次数限制。

御剑可以掌握给法器充能的能力。之后便可以花费灵石为法器补充次数。

将被充能的物品装备在身上之后，进入战斗便会附带灵气。但会消耗物品上的充能数量。

装备本身的储能有上限。装备在身上后即可带入战斗，体现为灵气。

## 淬毒

炼魂流可以掌握给装备淬毒的能力。之后便可以花费毒药材料，将可装备类物品淬毒。

装备本身的储能有上限。

战斗中无法补充此资源。
