# 卡牌

卡牌代表了功法和招式，是战斗的核心。

## 获得

1，战斗后，会有一定几率得到对方卡组中的一张卡牌。每个 npc 每个月只能切磋一次。而生死之战会杀死对方，所以只有一次机会。

2，通过打坐冥想，消耗游戏内的时间来获得卡包。

3，通关副本，完成任务，有可能直接获得卡包。

## 使用

每个流派能获得该流派本身的卡牌。

使用卡牌只受到境界和装备的限制，卡牌没有等级或者流派的限制。

## 费用

每张卡牌的无色费用与有色费用各自独立，均按阶梯 L(rank) = ⌊境界/2⌋+1 取值
（凝气及以下 1、筑基/结丹 2、还婴/化神 3）：

- 无色费用：卡面右上角的数字徽章，以元气（费用池）支付。每回合开始固定获得 3 点元气（装备词条可加成）。
- 有色费用：由卡牌流派决定颜色（悟道→灵气、御剑→剑气、锻体→怒气、炼魂→煞气、法身→怒气+煞气），
  无流派卡与无境界（rank 0）卡全无色。费用不足时卡牌**不能打出**（手牌置灰，悬浮提示缺少什么）。

有色费用在卡面描述区以"另需：剑气×2"形式展示；万智牌式费用图标（pip）的美术设计仍在制作中。
有色费用条目可以是固定数值，也可以是 `{base, rankIncrement}` 公式（floor(base + rankIncrement × 境界)，
随卡牌境界缩放，破境时重算），例如 `{base: 0.5, rankIncrement: 0.5}` → 凝气/筑基费用 1，结丹/还婴费用 2，化神费用 3。
支付有色费用时先扣本色气，不足的部分自动以无极之气抵扣；
虚空之气存在时使所有有色费用 +1/层（无上限）；其他阴气通过抵消阳气间接影响支付能力。

## 卡牌词条

每个流派有数张不同的固定词条的卡牌，它们会有一个固定的词条，这个固定词条本身决定了卡牌的类型（拳法，咒语，法术等等）

每张卡牌，根据其境界，还可能拥有其他词条，这些随机词条从该类型和流派的全部词条中随机选取。

## 卡牌需求

角色需要达到主词条的境界要求才能使用卡牌
如果是主流派卡牌还需要解锁该流派天赋入口
流派还决定了卡牌如何获取

## 鉴定

绝世卡牌需要鉴定后才能使用。在卡牌库中对未鉴定的绝世卡牌使用鉴定卷轴即可完成鉴定。

## 卡牌类型

攻击（普通攻击，法术攻击或使对方获得减益）
加持（自身获得资源或增益）
持续（持续数个回合，通常是在某个时机，例如回合开始时或发动攻击时产生效果）
消耗（用完会被销毁，战斗后也将不存在）

1，每种类型卡牌有单独的词条列表
2，卡牌费用由境界按阶梯决定（无色与有色各自独立取值），与词条数量无关；词条不再单独携带消耗

## 词条等级、卡牌等级、卡牌境界

词条本身可以通过卡牌升级强化。但词条等级不能超过卡牌等级。
随机生成的卡牌，其词条等级也是在 1-卡牌等级之间随机的。
词条本身的随机值只能通过精炼·混元调整。
化神或以上可能有 1/20 的几率得到太古词条，太古词条是普通词条数值最大值的 1.5 倍。只能在化神或一上境界的卡牌上才能出现。

卡牌本身可以被精炼
卡牌升级会附带卡牌主词条的升级。

提升境界后会增加词条数量的下限和上限。
提升境界后，如果词条数量不足下限，会随机增加词条。

| 卡牌境界 | 基础词条 | 额外词条(◆) | 太古词条(✶) |
| -------- | -------- | ----------- | ----------- |
| 无       | 1        | 0           | 0           |
| 凝气     | 1        | 0-2         | 0           |
| 筑基     | 1        | 1-3         | 0           |
| 结丹     | 1        | 2-4         | 0-1         |
| 还婴     | 1        | 3-5         | 0-2         |
| 化神     | 1        | 4-6         | 0-3         |

主词条的属性是固定的，但会随着等级提升而提升。

额外词条的等级是随机的，具体取值在当前境界的等级上下限之间。

额外词条的等级只能通过精炼·混元调整，但满值的太古词条只能在化神或以上境界的卡牌上才能出现。并且每个境界太古词条总数量有上限。达到上限后，就不能再获得太古词条。

### 精炼·灵宝

随机增加一个额外词条（不能超过境界允许的词条上限）

### 精炼·神照

随机替换一个额外词条

### 精炼·真定

随机锁定一个词条，使其不会被神照替换，或者被混元随机化，也不会被坐忘删除。

### 精炼·坐忘

随机移除一个词条。

### 精炼·混元

随机化词条的等级。词条的等级最大值等于主词条的等级，也就是卡牌等级。

### 精炼·破境

提升卡牌境界（卡牌本身升级满后才能提升境界，每个境界需要的材料不同）

打造卡牌词缀时，只能从角色已知的词条库中随机获取
获得新卡牌并领悟后，可以将新词条加入词条库

## 绝世 unique

绝世卡牌是一种特殊卡牌

这种卡牌所有词条都是固定的，并且不能进行灵宝、神照、真定、坐忘的精炼。但仍可以进行混元（重 roll 词条数值）和破境精炼。

绝世卡牌随着自身境界解锁固定数量和ID（在卡牌数据中预先定义的affixes是额外词条id）的额外词条。从无境界的1个额外词缀，到化神的6个额外词缀。

卡组中只能有一个相同uniqueId的绝世卡牌

## 易逝

易逝卡牌在回合结束时，如果还在手牌中，不会进入弃牌堆，而是直接被消耗。

某些战斗中获得的临时卡牌是易逝的。

## 符箓

符箓是用空白符纸把一张已有卡牌**复制**转化而来的消耗品卡牌（原卡保留）。
符箓继承原卡的全部词条与数值，但境界归 0（无境界需求、费用全无色 1 点）。

符箓是**消耗**（isEphemeral）卡牌：

- 加入卡组时受消耗卡牌数量上限（3）限制；
- 战斗中打出后即碎裂消失，不进入弃牌堆；未打出的不受影响；
- 符箓自带使用次数（标题上以 `(当前/上限)` 显示，上限 3），战斗结束后，
  战斗中实际打出过的符箓使用次数 -1；次数耗尽的符箓在下次战斗开始时会被替换为默认卡（基础拳法）；
- 在卡牌库中对符箓使用空白符纸可以补充 1 次使用次数。
