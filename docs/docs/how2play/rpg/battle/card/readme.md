# 卡牌

卡牌代表了功法和招式，是战斗的核心。

## 获得

1，战斗后，会有一定几率得到对方卡组中的一张卡牌。每个 npc 每个月只能切磋一次。而生死之战会杀死对方，所以只有一次机会。

2，通过打坐冥想，消耗游戏内的时间来获得卡包。

3，通关副本，完成任务，有可能直接获得卡包。

## 使用

每个流派能获得该流派本身的卡牌。

使用卡牌只受到境界和装备的限制，卡牌没有等级或者流派的限制。

## 费用

卡牌费用为单资源模型：一张卡只花一种资源。费用由独立的线性公式
`ceil(base + rankIncrement × 境界)` 决定（随卡牌境界缩放，破境时重算），
与词条数值的境界指数公式脱钩；费用条目也可以是固定数值，固定数值按 `floor` 取整。

- 无色费用：卡面右上角的数字徽章，以元气（费用池）支付。每回合开始固定获得 3 点元气（装备词条可加成）。
  中立卡（含法身）费用 = ⌈(境界 + 1) / 2⌉ 点元气（公式 `{base: 0.5, rankIncrement: 0.5}` →
  凝气/筑基 1、结丹/还婴 2、化神 3）；免费卡费用显式为 0。
- 有色费用：由卡牌流派决定颜色（悟道→灵气、御剑→剑气、锻体→怒气、炼魂→煞气、法身→怒气+煞气），
  流派卡费用 = 境界 点对应色（公式 `{base: 0, rankIncrement: 1}`）。
  无流派卡与无境界（rank 0）卡全无色。费用不足时卡牌**不能打出**（手牌置灰，悬浮提示缺少什么）。

有色费用在卡面描述区以"另需：剑气×2"形式展示；万智牌式费用图标（pip）的美术设计仍在制作中。
支付有色费用时先扣本色气，不足的部分自动以太极之气抵扣；
阴气通过抵消阳气间接影响支付能力（存量不足则无法支付）。
特例：绝世·万法归宗的费用不受减费效果影响，也不能以太极之气抵扣，必须全额以灵气支付。
未指定颜色的「费用 ±1」表示修改卡牌的首个费用条目；指定颜色时只修改对应颜色。
动态费用条目不参与减费或置零，加费只提高其最低门槛。

## 手牌上限

战斗中默认最多持有 10 张手牌，可通过 `handSizeMax` 属性及装备词条提高上限。
抽牌数量按剩余手牌空间截断；达到上限后，剩余抽牌不会发生，卡牌留在原区域，
不洗牌、不进入弃牌堆，也不触发入手/离手回调或「抽到的牌」修饰。
通过额外抽牌效果实际抽到 0 张时，不会对该次未抽到的牌施加费用修正。

## 卡牌词条

每个流派有数张不同的固定词条的卡牌，它们会有一个固定的词条，这个固定词条本身决定了卡牌的类型（拳法，咒语，法术等等）

每张卡牌，根据其境界，还可能拥有其他词条，这些随机词条从该类型和流派的全部词条中随机选取。

## 卡牌需求

角色需要达到主词条的境界要求才能使用卡牌
如果是主流派卡牌还需要解锁该流派天赋入口
流派还决定了卡牌如何获取

## 鉴定

绝世卡牌需要鉴定后才能使用。在卡牌库中对未鉴定的绝世卡牌使用鉴定卷轴即可完成鉴定。

## 卡牌类别 - category

攻击（普通攻击，法术攻击或使对方获得减益）
加持（自身获得资源或增益）
持续（持续数个回合，通常是在某个时机，例如回合开始时或发动攻击时产生效果）
消耗（用完会被销毁，战斗后也将不存在）

1，每种类别卡牌有单独的词条列表
2，卡牌费用由境界按阶梯决定（无色与有色各自独立取值），与词条数量无关

## 卡牌类型 - cardType

卡牌类型，一共七种，徒手，武器，法术，咒语，身法，心法，神通(divinity)

其中徒手，武器，法术，咒语可能是攻击牌。其余类型没有攻击。

法术类型的卡牌必然有对应的元素类型。元素类型包含七种：金，木，水，火，土，风，雷。

## 词条等级、卡牌等级、卡牌境界

词条数值按境界指数公式计算：`value = (base + increment × (等级 − 本境界等级下限)) × rankBaseScale ^ 境界 + rankIncrement × 境界`，
其中 `rankBaseScale = 1.3`。每提升 1 级的相对提升在同一境界内恒定，且任何境界一致。
费用与词条数值脱钩，由独立的线性公式决定。

战斗内升级是**临时**的：允许突破卡牌自身的等级上限，只在本场战斗中生效，不会改变卡牌库中的原卡。
打造、养剑等永久升级路径仍受卡牌等级上限约束。

### 普通卡牌额外词条与太古

| 卡牌境界 | 主词条 | 额外词条总数 | 其中太古上限 |
| -------- | ------ | ------------ | ------------ |
| 无       | 1      | 0-1          | 0            |
| 凝气     | 1      | 0-2          | 0            |
| 筑基     | 1      | 0-3          | 0            |
| 结丹     | 1      | 0-3          | 0-1          |
| 还婴     | 1      | 0-3          | 0-2          |
| 化神     | 1      | 0-3          | 0-3          |

高境界随机生成也可能只有主词条。太古是已有额外词条的品质，不占新槽位：
太古额外词条前显示 `✶` 和黄色文本，自动锁定，主词条不会成为太古。
太古词条取来源卡牌当前境界满级，再按词条自己的配置强化数值或既有参数，不统一放大全部机制。
只有明确配置了太古方案的额外词条才能成为太古。

普通构造生成、灵宝、神照和混元相关太古判定概率为 5%；破境新增词条与已有词条的太古判定概率分别为 25%。
符箓复制继承原卡的太古状态与数值快照，不重新判定。

### 精炼·灵宝

优先随机增加一个额外词条，不超过当前境界上限。
已有 3 条且达到结丹后，改为进行一次 5% 太古判定；成功时随机选择一个合格的非太古额外词条。
未触发太古时仍消耗材料，不另作失败提示。

### 精炼·神照

随机替换一个境界最低且未锁定的额外词条，随后只对本次新词条进行一次 5% 太古判定。

### 精炼·真定

随机锁定一个非太古额外词条，使其不会被神照替换、混元随机化或坐忘删除。
最多锁定 3 条，太古也计入数量。

### 精炼·坐忘

随机移除一个未锁定的额外词条；已有太古因自动锁定而不会被移除。

### 精炼·混元

先重随主词条及所有可变、非太古词条的等级，再检查太古名额并进行一次 5% 判定。
成功时随机选择一个合格的非太古额外词条，普通真定词条也可能被选中；失败时仅保留数值重随结果。

### 精炼·破境

提升卡牌境界并保留主词条和全部已有额外词条，不再重随普通额外词条。
普通词条保留当前等级，太古词条自动升至新境界满级。
若仍有空槽，有一次 25% 新增词条的机会；随后每个合格的非太古额外词条有 25% 概率成为太古。

打造卡牌词缀时，只能从角色已知的词条库中随机获取
获得新卡牌并领悟后，可以将新词条加入词条库

## 绝世 unique

绝世卡牌是一种特殊卡牌

这种卡牌所有词条都是固定的，并且不能进行灵宝、神照、真定、坐忘的精炼。但仍可以进行混元（重 roll 词条数值）和破境精炼。

绝世卡牌最多有 3 个固定额外词条：凝气解锁 2 个、筑基解锁 3 个；结丹、还婴、化神不再增加词条，而是按 `greaterAffixes` 的顺序依次将三个已有词条太古化。主词条不参与太古。

卡组中只能有一个相同uniqueId的绝世卡牌

## 易逝（规划中，尚未实现）

设计上，易逝卡牌在回合结束时如果还在手牌中，不会进入弃牌堆，而是直接被消耗。当前版本没有独立的易逝机制。

符箓使用的 `isEphemeral` 是另一种「消耗」机制：打出后碎裂，不要与尚未实现的易逝混用。

## 符箓

符箓是用空白符纸把一张已有卡牌**复制**转化而来的消耗品卡牌（原卡保留）。
符箓继承原卡的全部词条与数值，但境界归 0（无境界需求、费用全无色 1 点）。

符箓是**消耗**（isEphemeral）卡牌：

- 加入卡组时受消耗卡牌数量上限（3）限制；
- 战斗中打出后即碎裂消失，不进入弃牌堆；未打出的不受影响；
- 符箓自带使用次数（标题上以 `(当前/上限)` 显示，上限 3），战斗结束后，
  战斗中实际打出过的符箓使用次数 -1；次数耗尽的符箓在下次战斗开始时会被替换为默认卡（基础拳法）；
- 在卡牌库中对符箓使用空白符纸可以补充 1 次使用次数。
