# 个人战

个人战是游戏中的小游戏之一。

战斗中的招式就是卡牌，招式在战斗中一张一张轮流打出，并且带有一些直接伤害或者影响对手的即时效果。

本质上是卡牌打造和卡牌自动战斗。

卡牌打造借鉴自游戏: 《流放之路》

卡牌自动战斗借鉴自游戏: 《弈仙牌》。

# 卡组

战斗前可以探测对手使用的卡牌，自身的神识属性决定了能探测卡牌的数量上限。

# 卡牌需求

卡牌可能会有两种需求: 装备和境界。

例如剑法要求角色需要装备一把剑后才可以使用。

卡牌没有流派限制。只要满足境界即可使用任何卡牌。

# 绝世卡牌

绝世卡牌是一种特殊卡牌

这种卡牌所有词条都是固定的，并且不能进行灵宝、神照、真定、坐忘的精炼。但仍可以进行混元（重 roll 词条数值）和破境精炼。

绝世卡牌随着自身境界解锁固定数量和ID（在卡牌数据中预先定义的affixes是额外词条id）的额外词条。从无境界的1个额外词缀，到化神的6个额外词缀。

卡组中只能有一个相同uniqueId的绝世卡牌

### 攻击、伤害和资源

角色可以从法宝和卡牌中发动四种不同的攻击方式。攻击类型决定了自己如何获得伤害增强。
伤害类型决定了对手如何防御，每种伤害类型恰好有一种对策。
物理伤害只被护甲抵消，也是唯一可以暴击的伤害类型；
真气伤害同样面对护甲，但自带 50% 穿透，不可暴击但不会被完全抵挡；
火、冰、雷、毒四种元素伤害无视护甲，只被各自的元素抗性（百分比）减免，并各自附带一种元素持续伤害状态；
精神伤害与对手的念力属性对抗，无视护甲和抗性；
纯粹伤害没有任何对策，全部无视，十分稀有。
元素与术法的对应关系: 火→火、水→冰、雷→雷、木→毒、土→物理、风→物理。
暴击是物理伤害的专属机制：每造成一次物理伤害积累 1 点暴击充能，充能达到暴击阈值（基础 10）后，下一次物理伤害消耗阈值数量的充能并暴击；
元素伤害则共享同一个异常充能计数器（火、冰、雷、毒共同积累），达到异常阈值（基础 10）后，下一次元素伤害消耗阈值数量的充能并造成该元素的异常状态（每满 10 点伤害 1 层）。
暴击阈值和元素异常阈值可以通过天赋、装备和战斗状态改变（阈值最大 15，最小 5）。
幸运（原豪气）可以使物理攻击牌必定暴击（对元素攻击牌则变为必定造成元素异常），不消耗计数器；
衰气会削弱持有者的爆发——每层使暴击倍率 -50%（按层消耗至倍率降为 100%），或按层抵消其赋予的元素异常。
拥有阳气资源时可以被动增强某种对应攻击的基础数值。
卡牌的总费用由境界决定（境界 + 1 = 无色费用 + 有色费用），打出时做硬检查：
元气支付无色费用，四色气支付有色费用（无极之气可抵扣任意有色费用），
费用不足则卡牌不能打出。详见「资源」章节与卡牌章节的费用小节。

### 加成

装备可以提供攻击增强，某些 buff 卡牌可以提供攻击削弱。同种攻击的增强和削弱抵消计算。

#### 百分比影响拥有者发动的攻击

增强攻击: 每一层使自己发出的该类型攻击造成的伤害增加 1%。
削弱攻击: 每一层使自己发出的该类型攻击造成的伤害减少 1%，最多减少 95%。
计算方式为先将所有的百分比加起来，然后一同乘以基础值。

#### 百分比影响拥有者受到的伤害

抗性: 只有火、冰、雷、毒四种元素分型。每一层使自己受到的对应元素伤害减少 1%，基础抗性上限 75%。
全元素抗性是一种装备词条，会折算进每一种单元素抗性，属性面板上不单独显示。
弱点: 同样只有四种元素分型（weakness_fire/ice/lightning/poison），相当于负元素抗性，与抗性互相抵消。
物理、真气、精神伤害没有百分比对策。
计算方式为先将所有的百分比加起来，然后一同乘以基础值。

#### 基础数值影响拥有者发动的攻击

气根据其阴阳来增加或减少攻击所造成每次伤害的基础值。
气对每一次伤害的加成都分别计算。
气可能被作为可以消耗的资源。
除非另有说明，气在生效之后会消失。

#### 基础数值影响拥有者受到的伤害

护甲和易伤，每次受到伤害时自动消耗，按照数值抵消或增加伤害。
护甲抵挡物理与真气伤害（真气自带 50% 穿透），元素、精神、纯粹伤害均无视护甲，在回合开始时会自动减少一半；
易伤是不分类型的单一数值增伤，在触发伤害后即消耗，不会随时间衰减。

护盾（原浩然之气）每层可以抵挡一次任意非纯粹伤害，触发时消耗 1 层。
萧索之气使持有者下一次受到的任意类型伤害翻倍（含纯粹），触发时消耗 1 层。

#### 元素持续伤害

火、冰、雷、毒四种元素各自附带一种持续伤害状态（DOT），id 为 `element_dot_fire/ice/lightning/poison`：

| 元素 | 状态 | 效果                                                                   | 节奏     |
| ---- | ---- | ---------------------------------------------------------------------- | -------- |
| 火   | 点燃 | 回合开始时受到 5 点火焰伤害，同时消耗 1 层（层数=剩余触发次数）。      | 稳定     |
| 雷   | 感电 | 回合开始时耗尽所有层数，每层随机受到 1~10 点雷电伤害（每层单独跳字）。 | 爆发     |
| 冰   | 冰缓 | 回合结束时耗尽层数，每层受到 1 点寒冰伤害，并随机转化为缓慢或迟钝。    | 绵长干扰 |
| 毒   | 中毒 | 回合结束时受到 5 点毒素伤害，不自动消耗。                                              | 累积     |

异常触发机制：火、冰、雷、毒共享同一个异常充能计数器，攻击方每造成一次元素伤害积累 1 点充能；
充能达到元素异常阈值（基础 10）后，下一次元素伤害消耗阈值数量的充能，并按每满 10 点最终伤害附加 1 层对应元素的异常。
异常造成的伤害受承受方对应元素抗性减免，
并受攻击方的元素异常伤害属性（基础 100%）放大。

幸运对元素攻击牌生效时，跳过计数器判定（也不消耗计数器），固定每满 10 点最终伤害附加 1 层异常；
攻击方持有的衰气会按层抵消其赋予的异常（1 层衰气抵消 1 层，消耗至异常抵消完或衰气耗尽）。

伤势系统只剩流血（物理）、内伤（真气）、幻觉（精神）三种；中毒已从伤势迁入元素持续伤害。
内伤在每次获得元气时减少 1 层；幻觉在每次获得灵气（含无极之气）时减少 1 层。
此外，每次恢复生命时会随机移除一层当前持有的负面效果
（缓慢、迟钝、易伤、不幸、邪祟、破绽、三种伤势、四种元素持续伤害）。

### 加成作为资源

各种加成效果都可以被双方消耗利用。例如一个角色可以将对方身上的剑气吸收，或者消解自身的破绽等等。

### 计算方式

卡牌的伤害 10 base damage
增加 5 伤害 阳气
增加 30% 伤害 enhance/weaken

最终值:
base = 10 + 5
final = base + base × 0.3

### 资源回合节奏

每个回合开始，依次结算（顺序固定，不依赖状态遍历）：

1. 回合开始回调（死气/劫气失去生命、元素 DOT、缓慢跳过判定等）
2. 清空上回合残留的所有资源气（煞气未用量返回业力池，有跳字提示）
3. 结算新产出：元气 rank+3、剑气（上回合武器攻击牌数）、怒气（上回合受伤 ÷10）、
   灵气获取天赋 +1、煞气从业力池提取
4. 摸牌；手牌按费用硬检查置灰（不足则打不出）

每个回合结束，依次结算：

1. 灵气溢出天赋：按剩余灵气层数转化为元气，或对对手造成随机元素伤害
2. 元气回血：每剩余 1 层回复 2% 生命上限（每层至少 1 点），不消耗层数
3. 其余回合结束回调（速度/闪避阈值、冰缓/中毒 DOT 等）

资源图标在对方回合期间保留显示——对方能看到你没花完的费用。

## 劫气（软狂暴）

战斗拖得太久时天道降下的惩罚，**不是资源**：不参与阴阳对冲、不影响费用、不占资源槽位。
每 16 回合双方各叠 `回合数/16` 层；回合开始时消耗 1 层，失去 10% 生命上限的生命。
