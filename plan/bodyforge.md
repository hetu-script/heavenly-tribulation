# 锻体流派（bodyforge）机制深化设计

## 核心机制：怒意爆发

### 设计目标

锻体流的核心玩法是**在战斗中积累怒气，达到阈值后解锁爆发效果——同时承受越来越高的受伤风险**。这是一个主动管理风险的游戏：怒气越积越多，你的伤害越来越高，但你也越来越脆弱。

与悟道的"精打细算"和御剑的"瞬息爆发"不同，锻体是"刀尖舔血"——你在和自己的身体极限赛跑。

### 五层怒意

| 境界     | 被动 ID            | 名称         | 效果                                                                      |
| -------- | ------------------ | ------------ | ------------------------------------------------------------------------- |
| 凝气 (1) | `bodyforge_rank_1` | **战意勃发** | 徒手攻击卡牌费用 -1。                                                     |
| 筑基 (2) | `bodyforge_rank_2` | **怒不可遏** | 怒气达到 3 点时，。                                                       |
| 结丹 (3) | `bodyforge_rank_3` | **破釜沉舟** | 怒气达到 5 点时，攻击的 30% 伤害无视对方防御和护盾。                      |
| 还婴 (4) | `bodyforge_rank_4` | **血战到底** | 怒气达到 7 点时，。                                                       |
| 化神 (5) | `bodyforge_rank_5` | **天崩地裂** | 怒气达到 10 点时，或者一张手牌：可消耗全部怒气，造成"怒气 × 10"真实伤害。 |

### 设计意图

- **Rank 1 是基础**：减费。
- **Rank 2-4 是阈值系统**：不是线性成长，而是达到某个怒气水平后解锁新能力。这创造了一种"再坚持一回合"的紧张感——马上就到阈值了，要不要再等等？
- **Rank 4 是生存转折**：在血量危险时降低怒气带来的自伤惩罚。"血战到底"让你在低血量时有更强的生存力，鼓励操作到极限。
- **Rank 5 是终极清算**：10 点怒气的天崩一击。打出后怒气归零——你从极度脆弱变回正常状态。时机选择是生死问题。

### 关键设计约束

- 怒气阈值是**实时检查**的——达到即生效，不需要手动激活。
- 阈值的多个效果**同时生效**（达到 5 点时 Rank 2 和 Rank 3 的效果都在）。
- "天崩"不消耗能量，但消耗全部怒气——这是你爆发的代价（失去所有被动加成和风险）。
- 每回合结束时怒气 -1。如果你在阈值边缘，-1 可能让你失去 Rank 4 的减伤保护。

### 怒气节奏示意

```
对手回合：
  对手打出 3 张攻击卡 → 你获得 3 点怒气（不触发受伤放大，因为是对手在打）
  你受到伤害时受伤放大生效

你的回合：
  怒气 3 点 → Rank 2 激活：+25% 徒手伤害 → 但受到伤害 +9%
  你打出徒手攻击 → 伤害可观

  继续挨打 → 怒气到 5 → Rank 3 激活：30% 无视防御
  血量降到 50% → Rank 4 激活：受伤放大从 +15% 降到 +10.5%

  怒气到 10 → 消耗全部怒气打出"天崩" → 怒气归零 → 风险解除
```

### 子流派分支方向

- **高怒狂战流**：顶住风险，追求 Rank 5 天崩终结。需要大量生命值缓冲和生机回复。
- **阈值维持流**：将怒气维持在 5-7 的甜区（享受 Rank 2-4 加成 + 减伤保护），不追求 10 点天崩。
- **防御反击流**：堆高防御和护盾，利用"被阻挡"额外获取怒气，配合 Rank 3 无视部分防御——攻守一体。

### 与其他流派的机制差异

| 维度     | 悟道             | 御剑               | 锻体                 |
| -------- | ---------------- | ------------------ | -------------------- |
| 核心节奏 | 跨回合规划       | 回合内连斩         | 阈值触发             |
| 触发条件 | 不同元素         | 武器攻击卡         | 怒气水平             |
| 风险维度 | 低（打错没奖励） | 低（清零但不惩罚） | 高（自伤放大）       |
| 资源来源 | 主动生成         | 主动生成           | 被动生成（对手行动） |
| 玩法感觉 | 精打细算         | 瞬息爆发           | 刀尖舔血             |
