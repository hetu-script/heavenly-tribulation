# 卡牌、装备与丹药词条数量及太古词条重构计划

> 本文只规划词条系统重构，不包含御剑流派本身的机制设计与落地。

## 1. 背景与目标

当前普通卡牌、装备和丹药共用 `GameLogic.getMinMaxExtraAffixCount`，三者最多可有 5 个额外词条，绝世卡牌与绝世装备固定有 5 个逐步解锁的额外词条。词条数量过多会削弱主词条辨识度，增加战斗阅读和打造评估成本。

本次重构采用以下单一方案：

- 普通卡牌、装备和丹药保留额外词条数量随机性，但最多 3 条。
- 结丹以后不再增加槽位，改为提升已有词条的太古数量。
- 太古是已有词条的品质，不占用新槽位，不增加卡面或物品说明的文本行。
- 直接生成普通卡牌、装备和丹药时低概率出现太古；卡牌灵宝在词条满 3 条后提供低概率强化，卡牌打造破境使用较高概率。
- 卡牌太古词条自动锁定，默认数值为当前词条境界满级计算值的 1.5 倍；特殊数值与纯机制词条使用定制强化或禁止太古。
- 绝世卡牌与绝世装备在凝气解锁 2 个、筑基解锁 3 个固定额外词条，结丹/还婴/化神依次把三个已有词条升级为太古。
- 聚灵阵临时太古按独立计划复用同一数据模型。

### 非目标

- 不重做卡牌战斗、资源、伤害或天赋系统。
- 不实现御剑新流派内容。
- 不实现装备破境。
- 不考虑旧存档兼容与迁移（项目当前阶段明确无需兼容）。

## 2. 最终规则

### 2.1 普通卡牌、装备与丹药额外词条数量

“额外词条总数”包含普通与太古词条，太古不额外增加数量。卡牌、装备与丹药的主词条均不计入下表。

| 境界 | rank | 额外词条总数 | 其中太古上限 |
| ---- | ---: | ------------ | ------------ |
| 无   |    0 | 0～1         | 0            |
| 凝气 |    1 | 1～2         | 0            |
| 筑基 |    2 | 2～3         | 0            |
| 结丹 |    3 | 3            | 0～1         |
| 还婴 |    4 | 3            | 0～2         |
| 化神 |    5 | 3            | 0～3         |

灵宝增加词条仍受同一个总数上限约束，太古词条也计入已有词条数。装备打造固定取额外词条上限时，结丹及以上同样为 3 条，不再继续增加。

### 2.2 太古获得方式

首期开放四个入口，分别服务刷取、物品生成、定向打造和卡牌破境成长：

1. **直接生成普通卡牌**：全部额外词条生成后，对合格词条逐个进行低概率判定，初始概率常量建议为 5%。
2. **直接生成普通装备与丹药**：掉落、奖励、装备打造和炼丹生成完整词条后，按同一规则进行低概率判定，初始概率常量建议为 5%。主动制作不会额外提高概率。
3. **精炼·灵宝**：始终优先补足当前境界的词条槽位，满 3 条且达到结丹后才进行太古判定。
   - 额外词条未达到当前境界上限：100% 增加 1 条额外词条，仍受当前境界的词条池限制。
   - 额外词条已满 3 条且 rank ≥ 3：从尚未太古的合格额外词条中随机选取 1 条，进行 5% 太古判定；成功则自动锁定，未触发太古时卡牌不变。
   - 满 3 条后的灵宝操作直接按成功返回并正常消耗 1 份材料，不区分“判定成功”和“未触发太古”的结果提示；未触发太古、没有合格候选或已达到太古上限时，均可能没有实际变化。
   - 已达到当前境界上限但不足 3 条（rank < 3）：不能继续补槽也不能太古，按不可使用处理，不消耗材料。
4. **普通卡牌打造破境**：破境、保留/重随词条全部完成后，对全部尚未太古的合格额外词条逐个进行 25% 判定，包括被真定锁定但本次也重随数值的词条。

判定规则：

- 直接生成与破境在候选词条中随机顺序判定，避免固定偏向前几个槽位。
- 当前已有太古数加上新增数不能超过本境界上限，达到上限后停止。
- 没有 `greater` 配置的词条不可太古，不消耗成功次数。
- 灵宝满 3 条后的 5% 判定只选择 1 条候选，不是对整卡所有词条各判定一次。
- 神照、混元不额外进行太古判定；已有太古按锁定规则保护。
- 符箓复制继承原卡的太古状态与数值快照，不重新判定。

概率集中在常量中，便于后续平衡，不散落为脚本魔法数。

### 2.3 太古与锁定、破境

运行时增加两个独立标记：

- `affix.isGreater`：太古品质及展示、数值规则的真值。
- `affix.isFreezed`：卡牌打造保护标记；卡牌词条太古时自动写入 `true`，普通真定也继续写入。

规则如下：

- 太古只作用于额外词条，主词条不参与。
- 太古时把词条等级设为**该词条自身 rank 的满级**，随后计算太古数值。
- 普通卡牌破境保留全部太古词条；破境同步词条 rank 后，太古自动达到新境界满级并重新计算，不再次判定该词条。
- 神照、坐忘、混元和真定选择目标时通过 `isFreezed` 自然排除太古。
- 普通卡牌破境仍只保留主词条、真定词条和太古词条，其余重随；由于太古自带锁定，可复用现有保留通道。
- 普通真定的最大锁定数从 5 调整为普通卡牌额外词条上限 3；太古也计入已锁定数量。
- 装备本期不开放破境和卡牌式锁定操作，只使用 `isGreater` 表示品质；不因为装备太古而引入新的打造操作。

### 2.4 数值、纯机制词条与太古描述

禁止对所有 `value` 和机制字段统一乘以 1.5。每个词条原型通过可选 `greater` 表显式声明自己是否可太古以及如何强化：

```json5
example_numeric_affix: {
  // 其他词条字段……
  greater: {
    values: [
      { mode: "multiply", factor: 1.5 }, // value[0]
      // 其余下标不强化
    ],
  },
},

example_count_affix: {
  greater: {
    values: [
      { mode: "add", amount: 1 }, // 观星/抽牌等次数使用加法而非乘出小数
    ],
  },
},

example_mechanism_affix: {
  greater: {
    description: "affix_example_mechanism_greater", // 可选：太古后的专用描述
    data: { scryBonus: 1 }, // 由对应脚本在 isGreater 时读取
  },
},
```

规则：

- `greater.values` 与 `valueData` 按下标对应，支持 `multiply`、`add`、`set`；缺省下标不改变数值。
- 默认强化为满级普通值 ×1.5，但只有显式配置的词条才可太古。
- 卡牌先按现有 `calculateCardAffixValue` 得出满级普通值，再应用 `greater.values`；装备与丹药先按 `calculatePassiveAffixValue` 得出普通值，再应用同一配置。均不修改普通公式。
- 纯机制词条没有统一默认效果。只有脚本明确消费 `greater.data` 时才提供对应强化；否则该词条不可太古。
- 阈值、费用、段数、百分比、资源数量等必须逐条审查，不能因存在 `valueData` 或 `increment` 就自动缩放。
- `isFixed` 只表示不随等级缩放，不妨碍显式配置的太古倍率。
- `greater.description` 为可选本地化键。太古合并了新机制或需要改变文案时，在 `isGreater` 后替换普通 `description`；未配置时沿用普通描述。普通状态不能提前展示太古才会获得的效果。

## 3. 绝世卡牌规则与数据迁移

### 3.1 新的固定成长结构

绝世卡牌最多有 3 个固定额外词条，固定额外词条数量为 `min(rank + 1, 3)`。凝气与筑基依次解锁词条1～3，结丹、还婴、化神不再增加词条，而是按 `greaterAffixes` 的顺序各将一个已解锁词条太古化：

| 境界 | rank | 固定额外词条数 | 固定太古数 |
| ---- | ---: | -------------: | ---------: |
| 凝气 |    1 |              2 |          0 |
| 筑基 |    2 |              3 |          0 |
| 结丹 |    3 |              3 |          1 |
| 还婴 |    4 |              3 |          2 |
| 化神 |    5 |              3 |          3 |

在主词条增加：

```json5
greaterAffixes: [
  { rank: 3, affixId: "example_affix_1" },
  { rank: 4, affixId: "example_affix_2" },
  { rank: 5, affixId: "example_affix_3" },
],
```

目标词条必须已经包含在该卡的 `affixes` 中，在对应境界已经解锁，并且自身具有合法 `greater` 配置。直接生成高境界绝世卡时，也要一次性应用所有已到达境界的固定太古成长。

普通随机词条允许没有 `greater` 配置，但**所有被绝世卡牌保留的固定额外词条必须统一提供太古版本**，使三个词条在化神时都能完成一次品质成长。

### 3.2 现有悟道绝世卡牌迁移

修改 `assets/data/cards.json5` 中所有带 5 个固定额外词条的绝世卡，包括五张常规绝世卡、紫微斗数和万法归宗。

这里的“去掉”指从该卡的固定成长列表移除，不一定删除词条 ID 或机制。优先把有辨识度的效果合并为已有词条的太古强化；重复抽牌、通用护甲等不再占用固定槽位。仍被其他卡或随机池使用的词条继续保留，只为旧固定列表服务且已合并/淘汰的词条，在确认无引用后移除。

以下统一按固定列表顺序称为词条1、词条2、词条3，不再为各词条额外使用标题。每张卡按 rank 3、4、5 列出三个词条各自的太古版本。

#### 天机术 `spellcraft_scry_draw`

- **保留 3 条**：词条1使未选牌费用 +1；词条2使选中牌升级；词条3使本次观星额外查看 1 张。
- **rank 3 太古**：词条2变为“选中牌升级且费用 -1”。
- **rank 4 太古**：词条3变为“本次观星额外查看 2 张”。
- **rank 5 太古**：词条1使未选牌费用由 +1 提高至 +2；同一张牌每场战斗仍只生效一次。

#### 相生相克 `spellcraft_ailments_by_used_elements`

- **保留 3 条**：词条1按已用元素增加异常层数；词条2清除自身异常并抽牌；词条3在异常种数达标时获得灵气。
- **rank 3 太古**：词条1提高每种异常的层数加成。
- **rank 4 太古**：词条3在获得灵气的同时，按自身异常层数获得护甲。
- **rank 5 太古**：词条2的抽牌数由 1 提高至 2，清除自身异常的数量不变。

#### 一气化三清 `spellcraft_element_amplify`

- **保留 3 条**：词条1使所选元素手牌减费；词条2按灵气提高自身增幅；词条3降低自身受到的所选元素伤害。
- **rank 3 太古**：词条2增加“对手使用所选元素后，下回合获得灵气”。
- **rank 4 太古**：词条3增加一次性护盾。
- **rank 5 太古**：词条1使所选元素手牌费用由 -1 提高至 -2。

#### 蓄灵诀 `spellcraft_ailments_to_mana`

- **保留 3 条**：词条1把本次获得的灵气转化为护甲；词条2在获得灵气后降低悟道手牌费用；词条3以延迟自伤换取下回合爆发。
- **rank 3 太古**：词条1提高每点灵气转化的护甲数值。
- **rank 4 太古**：词条2增加“自身异常种数达到 5 时额外获得太极之气”。
- **rank 5 太古**：词条3提高下回合首张悟道牌增伤，自伤规则不变。

#### 太上忘情 `spellcraft_handcards_to_mana`

- **保留 3 条**：词条1降低每张手牌造成的自伤；词条2提高每张手牌产灵量；词条3使随机悟道手牌获得保留。
- **rank 3 太古**：词条2使每张手牌的额外灵气由 +1 提高至 +2。
- **rank 4 太古**：词条3增加“强化下回合首张悟道牌”。
- **rank 5 太古**：词条1增加按手牌数获得护甲。

#### 紫微斗数 `spellcraft_draw_cards_reduce_cost`

- **保留 3 条**：词条1使抽到的牌升级；词条2在抽到悟道牌时获得灵气；词条3在未抽到悟道牌时额外抽牌。
- **rank 3 太古**：词条1使抽到的牌同时获得保留。
- **rank 4 太古**：词条2把抽到悟道牌时的灵气获得量由 1 提高至 2。
- **rank 5 太古**：词条3的额外抽牌数由 1 提高至 2；额外抽到的牌均不归零费用，避免免费牌循环。

#### 万法归宗 `spellcraft_ultimate_spell`

- **保留 3 条**：词条1按超额支付施加感电并促成转化；词条2按本回合元素种数增伤；词条3抽牌减费但获得逆灵之气。
- **rank 3 太古**：词条1增加按超额支付量获得护甲。
- **rank 4 太古**：词条2增加“若对手打出前已有感电，再获得增伤”。
- **rank 5 太古**：词条3的抽牌数由 1 提高至 2，获得的逆灵之气层数不变。

迁移时同步更新 `plan/skill_tree/spellcraft.md`、`docs/docs/how2play/rpg/cultivation/genre/spellcraft.md` 与相关本地化描述，确保不再按旧规则逐境新增词条或只在后两境提供太古。没有固定额外词条列表的通用绝世卡不受数量迁移影响，主词条仍不参与太古。

## 4. 装备规则与悟道绝世装备迁移

### 4.1 普通装备

- 普通装备使用与卡牌相同的 2.1 数量表，额外词条最多 3 条。
- 掉落、奖励和装备打造在生成全部词条后进行低概率太古判定，已有太古数量不能超过当前境界上限。
- 普通装备的太古数值使用 `calculatePassiveAffixValue` 的普通结果作为基础，再应用 `greater.values`；纯机制词条仍需要明确的 `greater.data` 消费方。
- 装备打造继续固定取当前境界额外词条上限，结丹及以上为 3 条；`ExtractedAffix` 填槽不能超过该上限。
- 装备估价继续使用现有公共数量函数，并随其新规则改为最多按 3 条额外词条估算，避免仍按旧 5 条上限计算。
- 本期不开放装备破境，也不要求普通装备的全部随机词条都支持太古。

### 4.2 绝世装备固定成长

绝世装备与绝世卡牌采用相同的“两次固定解锁 + 三次固定太古”结构：

- `items.json5` 的 `affixes` 首条仍为装备主词条，不计入 3 条额外词条上限。
- 主词条之后最多保留 3 个固定额外词条，数量为 `min(rank + 1, 3)`；rank 1 解锁词条1～2，rank 2 解锁词条1～3。
- 在物品 prototype 上增加 `greaterAffixes`，rank 3～5 依次将三个已有额外词条太古化。
- 直接生成高境界绝世装备时，一次性应用所有已到达境界的固定太古成长。
- 所有被绝世装备保留的固定额外词条必须统一提供 `greater` 配置。
- 绝世装备的太古不设置卡牌打造保护语义；本期只处理品质、数值、机制与展示。

### 4.3 悟道绝世装备迁移

以下词条1～3均指主词条之后保留的三个固定额外词条。通用属性、重复观星效果和重复资源效果可以不再占用槽位；被合并或淘汰的词条 ID 在确认无其他引用后再删除。每件装备按 rank 3、4、5 列出三个词条各自的太古版本。

#### 窥天镜 `heaven_peeking_mirror`

- **保留 3 条**：词条1使观星额外查看 1 张；词条2使每回合首次观星选中的牌获得保留；词条3使每回合首次获得元素异常时获得 1 点灵气。
- **rank 3 太古**：词条3使每回合首次获得元素异常时的灵气由 1 提高至 2。
- **rank 4 太古**：词条2增加“受到的元素异常层数 -1”。
- **rank 5 太古**：词条1的观星深度加成由 1 提高至 2，仍受观星上限约束。

#### 五行珠 `five_elements_pearl`

- **保留 3 条**：词条1提高元素异常伤害；词条2降低元素异常充能阈值；词条3使造成的元素异常层数 +1。
- **rank 3 太古**：词条3增加“每回合首次获得元素异常时获得 1 点灵气”。
- **rank 4 太古**：词条2进一步降低元素异常充能阈值，仍受阈值下限约束。
- **rank 5 太古**：词条1提高元素异常伤害数值。

#### 天机盘 `heavenly_mechanism_disc`

- **保留 3 条**：词条1使非悟道牌费用 +1，与主词条的抽牌课税叠加；词条2降低牌库下限；词条3增加每回合抽牌数。
- **rank 3 太古**：词条1使非悟道牌费用由 +1 提高至 +2，强化纯悟道构筑与混编构筑的差异。
- **rank 4 太古**：词条3提高每回合额外抽牌数值。
- **rank 5 太古**：词条2进一步降低牌库下限。

#### 蓄灵佩 `spirit_storing_amulet`

- **保留 3 条**：词条1提高生命上限；词条2提高护甲保持；词条3使回合产出阶段灵气 +1。
- **rank 3 太古**：词条3的回合灵气产出由 1 提高至 2。
- **rank 4 太古**：词条2提高护甲保持数值。

#### 聚灵旗 `spirit_gathering_banner`

### 5.7 数据校验

涉及：`utils/data_validate/game_data_validate.dart`

新增校验：

- `greater` 只能为表，且至少含 `values`、`data` 或 `description` 之一；只有描述而没有数值或机制变化的词条给出警告。

- 无 `valueData` 的卡牌词条不得配置 `greater.values`；无普通数值来源的装备与丹药词条同样不得配置。

- `greaterAffixes` 的 rank 只能为 4～5、顺序合法、目标不重复，目标必须存在于本卡或本装备的 `affixes` 中、在对应境界已经解锁，并且目标存在合法 `greater`。
- 普通随机词条的 `greater.data` 必须属于已登记、确有脚本消费方的契约字段，避免“看似能太古但实际无效果”。
- 绝世卡牌固定额外词条与绝世装备主词条后的固定额外词条均不超过 3 条；无对应成长的纯机制词条给出错误或明确警告。
