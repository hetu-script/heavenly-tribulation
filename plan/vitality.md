# 炼魂流派（vitality）机制深化设计

## 核心机制：因果报应

### 设计目标

炼魂流的核心玩法是**对敌人施加负面状态（业报），从对手的痛苦中获得力量**。它使用煞气——唯一横跨多场战斗的资源——将持久战的消耗转化为优势。

与其他三个流派的关键区别：炼魂不追求瞬间伤害，而是让对手陷入越来越深的泥潭。战斗越长，炼魂越强。

### 煞气积累（跨战斗资源）

煞气在战斗之间积累，而非战斗中生成：

- **战斗胜利**：基础获得 5 点煞气。
- **每次给对手施加负面状态**：额外获得 1 点煞气（每场战斗上限等于角色念力）。
- **门派建筑·万魂幡**：提升每次战斗的煞气获得量（如 +50%）。
- **带入战斗**：每 10 点念力可将 1 点煞气带入下一场战斗。多余的暂存。

### 五层因果

| 境界     | 被动 ID           | 名称         | 效果                                                                  |
| -------- | ----------------- | ------------ | --------------------------------------------------------------------- |
| 凝气 (1) | `vitality_rank_1` | **因果缠身** | 咒语卡牌费用 -1。                                                     |
| 筑基 (2) | `vitality_rank_2` | **业力流转** | 对手每有一种不同的负面状态，你的咒语卡牌伤害 +10%。                   |
| 结丹 (3) | `vitality_rank_3` | **轮回不息** | 战斗中消耗煞气时，战斗结束后返还消耗量的 50%。                        |
| 还婴 (4) | `vitality_rank_4` | **因果报应** | 回合结束时，对手每种负面状态有 25% 几率扩散到另一层（同类型 +1 层）。 |
| 化神 (5) | `vitality_rank_5` | **业火红莲** | 可消耗全部煞气：对对手造成"消耗量 × 对手负面状态种类数"的真实伤害。   |

### 设计意图

- **Rank 1 是基础赋能**：减费 + 解锁煞气带入机制。没有此被动时煞气不可带入战斗。
- **Rank 2 定义核心玩法**："对手负面状态越多 → 你越强"。这创造了明确的构筑方向——卡组应包含多种不同类型的 debuff。
- **Rank 3 提供资源循环**：煞气不是一次性消耗品。返还机制让你敢于在非 Boss 战中消费煞气。
- **Rank 4 创造自动扩散**：每个负面状态都可能自己增长。配合 Rank 2，伤害加成随时间指数增长。给对手时间压力——拖得越久越惨。
- **Rank 5 是终结技**："业火红莲"是唯一可以接受"需要长时间铺垫"的终结技，因为炼魂的整个机制就是拖延和积累。

### 关键设计约束

- "不同负面状态"指 uniqueId 不同的负面效果。减速 × 3 层只算 1 种。
- 扩散不会扩散到没有负面状态的对手身上——必须有"种子"。
- 煞气的双重功能仍然存在：被动 +5 诅咒伤害/点，主动消耗换更强效果。
- "业火红莲"消耗煞气后，被动加成暂时消失，直到重新积累。

### 典型战斗弧线

```
回合 1-3：建立 debuff 基础
  打出减速、笨拙、外伤、灼烧等不同负面卡 → 对手挂上 3-4 种不同 debuff
  Rank 2 生效 → 伤害开始攀升

回合 4-6：debuff 扩散
  Rank 4 自动扩散 → 对手的 debuff 种类不增但层数增长
  对手越来越弱，你越来越强

回合 7+：终结
  消耗煞气打出"业火红莲"：6 种 debuff × 10 煞气 = 60 真实伤害
  战斗结束 → 煞气返还 50%
```

### 子流派分支方向

- **debuff 广谱流**：尽可能挂上多种不同类型的负面状态，最大化 Rank 2 和 Rank 5 收益。
- **debuff 纵深流**：专注 2-3 种 debuff，利用扩散（Rank 4）和层数堆叠来压制对手。
- **煞气囤积流**：尽量减少战斗中煞气消耗，依靠被动 +5/点的诅咒伤害加成打基础伤害，把煞气留给 Boss 战。
- **万魂幡特化流**：通过门派建筑和装备提升煞气获取速度，以量取胜。

### 与其他流派的机制差异

| 维度     | 悟道       | 御剑       | 锻体         | 炼魂          |
| -------- | ---------- | ---------- | ------------ | ------------- |
| 核心节奏 | 跨回合规划 | 回合内连斩 | 阈值触发     | 跨战斗积累    |
| 资源来源 | 主动生成   | 主动生成   | 被动生成     | 战斗间积累    |
| 伤害模式 | 直伤为主   | 连击爆发   | 高风险高回报 | debuff + 拖延 |
| 时间偏好 | 中速       | 快攻       | 中速         | 慢速/控制     |
| 玩法感觉 | 精打细算   | 瞬息爆发   | 刀尖舔血     | 步步蚕食      |
