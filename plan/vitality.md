# 炼魂（vitality）

### 核心循环

煞气是唯一可以跨战斗积累的资源：战斗胜利、施加负面状态、作恶行为与门派建筑（万魂幡）都在战斗之外为煞气池充能；战斗开始时从池中提取（min(karmaMax, max(1, 池存量÷10))），未用完的煞气回合结束返回池中。其他流派战斗开始才造弹药，炼魂进场时弹药已经上膛——这是"盘外招"的第一层含义。

战斗中，炼魂给对手施加负面状态与阴气（永久存在、与对应阳气对冲抵消的负能量），再从对手的痛苦中获益：负面越多，炼魂越强。拥有少量无法防御的纯粹伤害。盘外招的第二层含义：神识探查——窥探对手手牌、弃其关键牌、乱其心智（幻术）。反派不问江湖规矩。

### 关键字

五毒：五毒、淬毒、蛊毒、碧磷、见血封喉、蛇蝎
夺神：阴气森森、锁脉、断粮、窥心、摄魂、迷魂
咒术：诅咒、丧魂、索命、怨毒、殃及、口诛笔伐
血魂：血祭、噬魂、炼魄、夺舍、魂飞魄散、以血还血

### 境界节点

- 凝气「因果缠身」：战斗开始时提取的煞气量增加 50%\n战斗结束后返还 50% 消耗的煞气
- 筑基「业力流转」：炼魂牌煞气费用 -1
- 结丹「轮回不息」：回合结束时，对手每有一种负面状态，便有 25% 的几率再次获得一种随机负面状态
- 还婴「因果报应」：每次你造成伤害时，有 15% 的几率将其转化为纯粹伤害
- 化神「业火红莲」：战斗开始后将「绝世·业火红莲」洗入你的牌库。「业火红莲」：保留，耗费 10+X 点煞气，每点煞气造成 X 点纯粹伤害；对手每有一种负面状态，总伤害 +X%（业火烧尽因果，不可防御）

### 1. 五毒（毒 / 暗器 / 异常）——"见血封喉"的构筑（与悟道共享）

毒属木，入悟道的元素异常体系（element_dot_poison 已存在）。悟道侧的元素循环/元素异常词条（"对方每有一种元素异常造成 X 伤害"）与本分支互认。

- 天赋（规则）「淬毒」：你的暗器牌造成伤害时，附加 1 层中毒。
- 节点：中毒伤害 +X%
- 节点：暗器攻击 +X
- 节点：中毒层数上限 +X
- 节点（capstone）「五毒俱全」：对手每有一种元素异常，你对其伤害 +X%

### 2. 夺神（阴气 / 幻术 / 盘外招）——"不战屈人"的构筑

天赋树位置：悟道侧（靠炼魂一侧；悟道一侧是天道/归元，见 spellcraft.md）。

- 天赋（规则）「阴气森森」：你施加的阴气效果 +1 层。
- 节点：念力 +X
- 节点「窥心」：每场战斗开始时，查看对手手牌（盘外招入口）
- 节点「迷魂」：你施加的幻术/心神类负面效果 +X 层，并有概率使对手弃掉一张牌
- 节点（capstone）「断粮绝气」：对手每持有一种阴气，其回合开始时对应阳气的产出 -1

### 3. 咒术（咒语 / 纯粹伤害）——"口诛笔伐"的构筑（与法身共享）

咒语卡牌两派共用（咒术 → 法身/炼魂）；法身的古神形态以咒术攻击力缩放，投资本分支同时强化变身（见 avatar.md）。

- 天赋（规则）「怨毒」：对手每有一种负面状态，你的咒语牌伤害 +X%。
- 节点：咒术攻击 +X
- 节点：施加负面状态时获得 1 煞气（每回合限 X 次）
- 节点「殃及」：你获得负面状态时，将其复制给对手（现有词条 gained_debuff_affect_opponent 归位于此）
- 节点（capstone）「口诛笔伐」：你的咒语牌伤害的 X% 转化为纯粹伤害（纯粹伤害入口）

### 4. 血魂（献祭 / 生命操控）——"以血还血"的构筑（与法身共享：血肉献祭）

与法身的血肉载体同源（见 avatar.md 血祭词条），与锻体的破釜分支互为表里（一个耗血换怒，一个耗血换煞）。

- 天赋（规则）「血祭」：你对自己造成伤害时，获得等量煞气（每回合限 X 次）。
- 节点：生命上限 +X
- 节点：噬命（生命上限操控）效果 +X%
- 节点「炼魄」：战斗胜利获得的煞气 +X%
- 节点（capstone）「血海深仇」：你每损失 10% 生命，炼魂牌伤害 +X%

### 流派专属卡牌词条

主词条：
淬毒暗器：造成 X 伤害 ×N 段，每段附加 1 层中毒（暗器淬毒，木属性）
阴气侵蚀：对对手施加 X 层指定阴气（压制其对应阳气产出）
夺气：移除对手 X 点阳气，你获得等量煞气
噬命：降低对手生命上限 X，提升自己生命上限等量（血系；buff/debuff_lifemax 脚本已存在）
咒杀：对手每有一种负面状态，造成 X 伤害
索魂：消耗对手全部中毒层数，造成其剩余伤害 ×2（引爆）

额外词条：
见血封喉（若对手已中毒，伤害 +X）
淬毒（打出后附加 1 层中毒）
窥心（打出后查看对手手牌）
锁脉（对手下回合有色气产出 -1）
怨气（打出后获得 1 煞气）
回煞（打出后返还 1 煞气，每回合限一次）
殃及（将自身 1 个负面状态转移给对手）
纯粹（本牌伤害变为纯粹伤害）

### 绝世装备

- 万魂幡（法器）：战斗后获得的煞气 +X%（跨战斗积累引擎，与门派建筑万魂幡叠加）
- 五毒鼎（法器）：中毒层数上限 +X；中毒伤害 +X%
- 锁魂链（饰品）：对手的阳气对冲阴气时需要双倍数量
- 血魂珠（饰品）：你对自己造成的伤害 -X%；自伤获得的煞气 +1
- 摄魂铃（法器）：每场战斗一次，查看对手手牌并选择一张弃掉

### 绝世卡牌

- 业火红莲：（化神境界节点获得）保留，耗费全部煞气（至少 10 点），每点煞气造成 X 点纯粹伤害；对手每有一种负面状态，总伤害 +X%
- 万毒噬心：对手每有 1 层中毒造成 X 伤害；中毒 ≥10 层时伤害翻倍
- 摄魂夺魄：查看对手手牌，选择一张弃掉；若其中有绝世卡，额外复制其效果（盘外招的极致）
- 夺舍：与对手交换当前生命百分比（反派的究极招式）
- 魂飞魄散：消耗对手所有阴气，每层造成 X 点纯粹伤害
- 迷魂阵：对手下回合打出的第一张牌失效（幻术）
