# 法身流派（avatar）机制深化设计

> **注意**：法身涉及角色模型切换（化身降临），依赖美术资源。Base 机制（Rank 1-4）可先实现，化身降临（Rank 5）留待美术就绪后补充。

## 核心机制：阴阳调和

### 设计目标

法身流是唯一横跨两种资源（怒气 + 煞气）的流派。怒气是即时战斗资源（被攻击→积累→消费），煞气是跨战斗积累资源。法身流的核心玩法是**利用两种资源的互动创造协同效应**——阴阳相生。

与其他流派的关键区别：法身不追求单一维度的极致（悟道的灵气管理、御剑的连斩爆发），而是**玩弄两种资源的平衡与转换**。

### 五层阴阳

| 境界     | 被动 ID         | 名称         | 效果                                                                                                                        |
| -------- | --------------- | ------------ | --------------------------------------------------------------------------------------------------------------------------- |
| 凝气 (1) | `avatar_rank_1` | **阴阳相济** | 经文卡牌费用 -1。                                                                                                           |
| 筑基 (2) | `avatar_rank_2` | **太极化生** | 消耗怒气时获得等量"临时煞气"（仅本场战斗）；消耗煞气时获得等量"临时怒气"（仅本场战斗）。                                    |
| 结丹 (3) | `avatar_rank_3` | **阴阳逆转** | 可以将自身的 1 种负面能量（每回合限 1 次）转化为等量的相对正向能量。                                                        |
| 还婴 (4) | `avatar_rank_4` | **两仪归真** | 同时持有怒气和煞气时：每对怒气 + 每对煞气，额外 +2% 经文伤害。每对 = 1 怒气 + 1 煞气。                                      |
| 化神 (5) | `avatar_rank_5` | **化身降世** | 消耗全部怒气和煞气（各至少 5 点），激活"化身"形态 3 回合。化身体：生命上限 +50%，全属性 +20%，经文卡费用再 -1，不可被打断。 |

### 设计意图

- **Rank 1 是双钥匙**：法身是唯一同时解锁两种资源基础的流派。这也是它最难上手的原因——你需要同时管理两种完全不同节奏的资源。
- **Rank 2 是转换引擎**：这是法身流的核心。"临时"资源仅本场战斗有效——你无法通过转换来积累永久的煞气。但转换让你在战斗中灵活调配：怒气太多受伤太高？转换成临时煞气降低风险。
- **Rank 3 是防御机制**：游戏中有 5 种负能量（death/decline/violence/heartless/void）。法身可以净化这些——其他流派只能承受。这让法身在特定对局中极其坚韧。
- **Rank 4 是双资源加成**：鼓励同时持有两种资源，而非全部消费。"对"的设计意味着你需要 1:1 的比例——不平衡的持有只计算较少的那个。
- **Rank 5 是化身体（轻量版）**：不需要模型切换——用属性增益 + 特殊视觉边框即可代表。完整的美术资源替换留待后期。

### 资源转换示意

```
怒气（被攻击而来）──→ 太极化生 ──→ 临时煞气（战斗中可用）
                                    ↓
                                消费临时煞气
                                    ↓
                                太极化生（反向）
                                    ↓
煞气（战斗外积累）──→ 带入战斗 ──→ 消费煞气 ──→ 临时怒气（战斗中可用）
```

### 关键设计约束

- "临时"资源在战斗结束时清除，不计入煞气积累。
- Rank 3 的阴阳逆转每回合限 1 次，防止无限净化。
- Rank 4 的"对"计数只看实际持有的怒气/煞气数量，取两者的最小值。5 怒气 + 3 煞气 = 3 对 → +6% 伤害。
- Rank 5 化身需要各 5 点——这意味着一个需要同时积累两种资源的门槛。可以通过 Rank 2 的转换来补足缺的资源类型。
- 化身形态结束后，怒气和煞气都归零。如果没终结战斗，你回到了最脆弱的状态。

### 子流派分支方向

- **平衡流**：维持怒气:煞气 ≈ 1:1，最大化 Rank 4 加成。操作最复杂但伤害最高。
- **怒气主导流**：偏重即时战斗的怒气生成和消费，煞气只作为 Rank 2 转换的"电池"。
- **煞气主导流**：偏重煞气积累，依赖 Rank 2 将煞气转为临时怒气供爆发使用。
- **净化专精流**：利用 Rank 3 + 装备，成为唯一能免疫负面能量的流派。

### 与其他流派的机制差异

| 维度       | 悟道       | 御剑       | 锻体         | 炼魂        | 法身                   |
| ---------- | ---------- | ---------- | ------------ | ----------- | ---------------------- |
| 核心节奏   | 跨回合规划 | 回合内连斩 | 阈值触发     | 跨战斗积累  | 双资源平衡             |
| 资源数量   | 1 种       | 1 种       | 1 种         | 1 种        | 2 种（转换互通）       |
| 操作复杂度 | 中         | 中低       | 中           | 中高        | 高                     |
| 伤害模式   | 直伤       | 连击爆发   | 高风险高回报 | debuff 拖延 | 混合（取决于资源配置） |
| 玩法感觉   | 精打细算   | 瞬息爆发   | 刀尖舔血     | 步步蚕食    | 阴阳互济，灵活多变     |
