# 御剑流派（swordcraft）机制深化设计

## 核心机制：剑气连斩

### 设计目标

御剑流的核心玩法是**在同一回合内连续打出武器攻击卡牌以触发递增的连斩奖励**。这利用了剑气"回合内生成→回合结束清零"的独特节奏——你必须在本回合内完成整套连击，过时不候。

与悟道的"跨回合元素共鸣"形成鲜明对比：

|                      | 悟道               | 御剑                 |
| -------------------- | ------------------ | -------------------- |
| 计数单位             | 回合               | 卡牌                 |
| 达成终极奖励最少时间 | 5 回合             | 1 回合               |
| 资源支撑             | 灵气（跨回合持久） | 剑气（回合结束清零） |
| 中断条件             | 一整回合无元素卡   | 回合结束             |
| 玩法感觉             | 厚积薄发           | 瞬息爆发             |

### 五层连斩

| 境界     | 被动 ID             | 名称         | 效果                                         |
| -------- | ------------------- | ------------ | -------------------------------------------- |
| 凝气 (1) | `swordcraft_rank_1` | **剑气凝形** | 武器攻击卡牌费用 -1。                        |
| 筑基 (2) | `swordcraft_rank_2` | **剑气连斩** | 回合内打出第 2 张剑术卡时武器攻击伤害 +30%。 |
| 结丹 (3) | `swordcraft_rank_3` | **剑气化虹** | 回合内打出第 3 张剑术卡时武器攻击穿透 +30%。 |
| 还婴 (4) | `swordcraft_rank_4` | **万剑归宗** | 回合内打出第 4 张剑术卡时。                  |
| 化神 (5) | `swordcraft_rank_5` | **剑气纵横** | 回合内打出第 5 张剑术卡时。                  |

### 设计意图

- **Rank 1 是基础赋能**：减费让你能在一回合内打出更多卡牌。同时赋予武器攻击生成剑气的能力——这是整个流派的基础。
- **Rank 2 开始有"第二张"概念**：第一张只是铺垫，第二张开始有回报。这创造了"先用轻攻击铺垫再重击"的自然节奏。
- **Rank 3 引入质变**：无视防御让高剑气消耗的终结技不会被对手堆防轻易化解。
- **Rank 4 提供续航**：剑气返还意味着你可以继续连击，把回合内的爆发窗口拉到极限。
- **Rank 5 是终极形态**：双倍伤害 + 破盾让第五张卡成为战斗终结者。

### 关键设计约束

- 连斩计数在**回合结束时清零**，与剑气同步。下回合重新从 0 开始。
- 只有**武器攻击卡**（有 `weapon` attackType 的卡）计入连斩。徒手/法术/诅咒卡不参与。
- 非武器卡不打断连斩计数，只是不增加计数。
- 能量限制意味着：需要足够低的费用（Rank 1 减费 + 低 rank 卡 + 能量管理）才能在一回合内打出 3+ 张。

### 连斩节奏示意

```
回合开始（剑气0, 计数0）
  ↓
打出一张剑法 → 计数1, 剑气+1（无额外奖励）
  ↓
打出一张刀法 → 计数2, 剑气+1 → Rank 2 触发：+30%伤害
  ↓
打出一张飞剑 → 计数3, 剑气+1 → Rank 3 触发：无视防御
  ↓
回合结束 → 计数清零, 剑气全部清零
```

### 子流派分支方向

当前设计已隐含三个方向，未来可通过天赋侧枝或装备深化：

- **连斩数量流**：堆低费武器卡，追求在一回合内打出 4-5 张触发高阶奖励。需要高能量和低费卡支持。
- **重击终结流**：铺垫 1-2 张轻攻击后，用一张高费高伤害的终结技享受 Rank 2/3 的加成。不需要打到第 4-5 张，注重每张的质量。
- **剑气管理流**：利用 Rank 4 的剑气返还和额外词条（剑气上限、剑气溢出转化），在回合内反复循环剑气。

### 与悟道（spellcraft）的机制差异

| 维度     | 悟道               | 御剑               |
| -------- | ------------------ | ------------------ |
| 时间跨度 | 跨回合（链条保留） | 单回合（链条清零） |
| 触发条件 | 不同元素           | 武器攻击卡         |
| 中断条件 | 非元素卡           | 回合结束           |
| 资源节奏 | 灵气整场分配       | 剑气回合内爆发     |
| 玩法感觉 | 精打细算，长线规划 | 瞬息万变，一键爆发 |
