# 天赋树入口、境界与初始卡牌重构讨论

> 状态：讨论草案，尚未实施。
>
> 本文汇总天赋树境界节点、五个流派入口、无境界卡牌和元气费用的讨论结论。具体节点位置与连线仍由人工设计和调整，本文不给出 `track_*` 排布。

## 1. 背景与目标

原设计中，流派境界节点同时承担以下职责：

- 作为天赋树主轴上的关键连接点；
- 要求角色先达到对应境界；
- 消耗天赋点解锁流派能力；
- 为对应流派提供费用资源或其他核心机制。

境界突破已经从天赋树中移出，改由营地设施单独发起。如果继续保留天赋节点的境界要求，境界与天赋点会形成双重门槛，主轴上的境界节点也会成为实际上的必点节点，限制分支和混修设计。

本次讨论的目标是：

- 让天赋树专注于构筑，不再承担境界突破和境界资格认证；
- 保留有意义的初始流派选择，同时允许后期通过路径投资进行混修；
- 让五个入口提供基础费用资源，解决流派卡组的基本运转问题；
- 重新区分“无境界卡牌”和“中立卡牌”；
- 保留元气作为简单、通用的基础费用资源。

## 2. 境界与天赋树分离

### 推荐方向

- 移除天赋节点的境界要求，包括五个入口和原流派境界节点。
- 境界继续负责等级上限、天赋点总量、装备与卡牌成长、秘境进度等角色整体成长。
- 天赋树不再通过角色境界锁定节点，外层强度主要由路径深度、前置投资和机会成本形成。
- 原境界节点改为普通的关键节点，不必保留线性依次解锁关系，也不必继续位于主轴。

仅删除境界要求并不能自动增加自由度。如果关键节点仍是两个区域之间的唯一通道，玩家依然必须购买它们。因此还需要同步调整连接关系：

- 普通节点主要负责连通；
- 关键节点提供构筑方向，优先放在分支或终点；
- 跨流派连接不经过必须购买的关键节点；
- 如果关键节点位于主干，应提供绕行路径；
- 玩家不必点完某流派主轴，才能连接其他区域。

### 暂缓事项

境界突破的仪式感不在本计划内处理。后续可以单独设计突破动画、动效、即时奖励和明确的内容解锁列表，不通过恢复天赋树境界锁来解决。

## 3. 五个流派入口

### 基本结构

五个提供基础费用资源的关键节点作为整个天赋树的五个入口：

- 玩家最初选择其中一个入口；
- 选择后暂时无法直接解锁另外四个入口；
- 深入天赋树后，可以沿路径抵达其他入口，再花费天赋点获得其资源能力；
- 所有入口都没有境界要求；
- 第二流派的投资成本主要来自路径和机会成本，而不是额外境界门槛。

这一结构形成“前期有明确流派身份、后期可以付费混修”的节奏，也避免玩家拥有流派卡牌却完全没有对应资源。

现有“无加点时五个入口开放，有加点后按无向邻接开放”的规则基本能够表达该结构，不需要额外设计一套永久锁定机制。

### 入口设计原则

- 选择后立即生效，不依赖角色属性或境界；
- 提供基础循环，不附带终局能力；
- 五个入口采用相同的保底规则，流派差异由资源本身、卡牌和后续节点形成；
- 不直接提供另一个入口的完整能力；
- 配套初始卡组能够展示该入口的基本玩法；
- 入口规则应简单可靠，较复杂的资源循环拆到后续关键节点。

五个入口统一为：每次行动的产出阶段，无条件获得 1 点对应费用。这样玩家在第二个及以后回合也能持续使用基础流派卡，不需要先学会或购买其他产出机制。

- 御剑：每回合 1 点剑气；
- 悟道：每回合 1 点灵气；
- 炼魂：每回合 1 点煞气；
- 锻体：每回合 1 点怒气；
- 法身：每回合额外 1 点元气，即由基础 3 点变为总计 4 点。

## 4. 后续资源节点与属性分工

### 后续资源节点

入口不再从属性获得后续费用。更多资源由分布在天赋树不同位置的节点明确提供，以便控制各条路径的资源总量：

- 固定产出节点：每次行动额外获得 1 点指定资源，数量有限，作为重要的费用投资；
- 特色产出节点：根据武器牌、受到伤害、观星、自异常等行为提供额外资源；
- 御剑的武器牌接续、锻体的受伤积怒等均保留为后续节点，不再放入入口；
- 固定产出与行为产出共同决定资源循环，但都不需要按主属性换算。

部分词条和天赋仍可以单独把属性转换为伤害或其他战斗效果，这些属于具体内容设计，不恢复为属性的默认产气规则。

### 五种属性的基础分工

属性不再负责默认费用产出，推荐分别承担：

- 身法：影响战斗先手概率；
- 灵力：影响元素异常伤害，需在实施时明确异常 DOT、其他元素异常与元素直伤的具体边界；
- 念力：影响场外煞气池上限；
- 体魄：影响战斗最大生命上限；
- 神识：影响暴击伤害，同时可保留既有的视野和战前识别用途。

神识的暴击伤害目前只对能够暴击的物理伤害有意义，需要按这一适用范围控制数值。灵力与神识不再为了对称而提供通用费用或全伤害加成。

### 炼魂：基础保底与场外储备

炼魂入口同样每回合无条件提供 1 点煞气，保证基础卡组可以持续运转。额外煞气主要来自场外煞气池：

- 战斗开始时按规则从池中带入额外煞气，用于前期或关键回合爆发；
- 场外池通过战斗胜利、门派建筑、特定装备或其他炼魂内容补充；
- 念力决定池容量，天赋影响带入量、恢复和利用效率；
- 未使用的带入量可以按设计返回池中；
- 战斗胜利补充应排除练习、木人等无实际风险战斗，并考虑反复刷低难度敌人的问题。

因此炼魂的特色不是“资源耗尽后永久断供”，而是“每回合 1 点保证基础循环，场外储备决定额外爆发”。炼魂后续节点可以强化这一双层结构，不需要恢复按念力直接产气。

### 法身：阴阳相济

法身详细设计仍然是最后处理的流派，本计划只记录入口边界。

入口只提供每回合额外 1 点元气。借势、有色资源借贷和变身等能力放到后续节点或法身专项计划中，不与入口基础保底混合。

法身变身卡的高元气费用、元气跨回合清空、变身当回合行动空间等问题均留待法身专项计划处理。

## 5. 原悟道境界节点的重新定位

五个节点不需要全部推翻，但应解除线性套餐关系。

### 太上感应

作为悟道入口，负责基础灵气启动。它可以对常规悟道构筑很重要，但不应成为路过悟道区域的强制税费。

### 天道循环

悟道牌灵气费用 -1 的效果简单且泛用，但容易成为所有悟道构筑的必选，并与装备减费叠加制造大量 0 费牌。

可选处理：

- 保留为普通大型数值节点；
- 放入费用或爆发分支深处；
- 后续改为每回合首张或满足条件时减费。

它是原五个节点中最需要重新评估强度与定位的一个。

### 阴阳五行

保留为灵气蓄积／剩余利用分支的关键节点。它让未使用灵气成为回合结束伤害，能够改变玩家消费或保留资源的决策，无需因脱离境界而重写。

### 五气朝元

保留为多元素轮转分支的关键节点或终点。玩家可以围绕它组织多元素卡组，也可以完全选择其他悟道方向。

### 万法归宗

保留为灵气爆发或动态费用分支的终端关键节点。它提供终局构筑组件，不要求玩家先购买另外四个原境界节点。

## 6. 无境界卡牌与中立卡牌分离

原设计中，无境界卡牌同时承担“凝气前教学卡牌”和“中立通用卡牌”两种职责。新入口结构下，建议将两者拆开：

### 无境界·流派基础卡

- 可以拥有 `genre` 和对应有色费用；
- 每个流派提供少量基础攻击、加持或防御卡；
- 效果简单，用于展示入口资源和基本玩法；
- 通常只有主词条，或仅有简单额外词条；
- 通过初始卡组、入口奖励或早期获得渠道提供。

### 无境界·真正中立卡

- 任何构筑都可以使用；
- 主要支付元气；
- 保留基础拳腿、防御、治疗、通用武器和资源调整等功能；
- 负责保底、补位与跨流派通用性，不再等同于全部新手卡牌。

不建议把当前所有无境界卡机械地改成流派卡，应逐张区分通用基本功与流派起始内容。

### 现有中立卡池的改造方式

现有内容应逐项分成三类，而不是对整个中立卡池统一换色：

1. **保留为真正中立卡**：基础拳腿、通用防御、治疗、身法和普通武器招式继续没有 `genre`，使用元气。它们为所有入口提供保底和补位。
2. **改造为流派基础卡**：只挑选少量与某流派基本打法直接对应的现有卡，补充 `genre` 并改为对应的单一有色费用。改造后它们不再是中立卡，也不应继续进入中立随机池。
3. **保留现有中立原型并新增流派版本**：当一张卡同时具有很高的通用价值和流派教学价值时，不为入口强行夺走通用版本，可以新增一个数值和效果更明确的流派基础版本。

通用武器招式不应仅因某流派也使用武器就全部归入该流派。只有承担其初始资源教学或特色循环的版本才需要换色。初期可以优先考察以下对应关系，但不预设最终卡牌 ID：

- 御剑：基础剑法或飞剑，支付剑气；
- 悟道：低复杂度元素攻击或防御，支付灵气；
- 炼魂：基础暗器、毒术或真言，支付煞气；
- 锻体：基础拳腿、擒拿或防御，支付怒气；
- 法身：基础经文、祈祷或武器招式，继续支付元气。

每个流派在 rank 0 先形成约 2～3 张基础卡即可，至少覆盖一种攻击和一种防御／加持。入口剧情只固定授予其中一张，其余通过早期获得渠道补充，避免初始卡池一次引入过多机制。

### 费用改造原则

新方向恢复统一的逐级费用模型：rank 0～5 的标准费用分别为 `1,2,3,4,5,6`，中立卡和有色流派卡都采用这一对应关系，不再为中立卡使用 `1,1,2,2,3,3`。

- rank 0 中立基础卡支付 1 点元气，rank 0 流派基础卡支付 1 点对应资源，均能保证开局基础玩法。
- 中立卡不设置全局境界封顶。结丹及以上的中立卡需要 4～6 点元气，超出基础 3 点元气，玩家需要通过额外产出、保留或其他构筑投资才能使用。
- 基础拳腿、普通武器等卡牌仍可按自身定位单独设置较低的境界上限，但这属于逐卡内容设计，不再是所有中立卡的全局限制。
- 高境界中立卡可以存在，并可以成为中立构筑的目标；需要避免的是无需额外投资就成为所有流派的通用最优卡，而不是避免高境界中立内容本身。
- 法身继续使用元气并保留完整境界成长；入口剧情卡的费用与内容留待法身专项设计。
- 一张改造卡只使用一种费用资源，不在基础教学卡上引入元气与有色气混费。
- 给现有中立卡增加流派和颜色时，必须同步移除原元气费用，避免旧费用与新费用并存。
- 明确的免费卡仍可单独设计为 0 点，动态费用和其他特殊费用继续作为显式例外，不套用标准公式。

### 下放主词条到 rank 0

优先把现有流派中最简单的卡下放，而不是为每个流派重新复制一整套新卡。适合下放的内容应当：

- 只包含直接伤害、护甲、治疗、简单抽牌或一种常见状态；
- 不依赖其他天赋、复杂计数器或特定卡组才能产生基本价值；
- 不承担观星、自异常、剑意、多元素轮转、动态费用或永久减费等后续教学机制；
- 在下放时同步调整 `rank`、费用、数值和描述，而不是只修改境界字段。

下放后仍需按 rank 0 的等级区间和数值公式重新核对强度。动画、插画和音效可以复用，避免基础内容改造扩大美术工作量。

### 下放额外词条到 rank 0

主词条和额外词条应分别审查。rank 0 已允许的通用护甲、迅捷、闪避和治疗词条可以继续作为基础随机池，不必为了入口再下放整套流派词条。

如果确需增加，只考虑少量容易理解的词条，例如本牌升级、按实际伤害提供少量治疗或护甲。每条流派最多选择少量基础词条，并遵守：

- rank 0 仍受当前最多 1 条随机额外词条且可能为 0 条的数量规则；
- 不下放永久减费、复杂时机回调、资源爆发和跨回合引擎；
- 不让一个额外词条替代后续关键天赋的核心作用；
- 检查词条的 `categories`、`genres`、`rank`、`uniqueId` 和 `require`，避免下放后进入不合适的卡牌；
- 太古仍遵守 rank 0 不可出现的现有限制。

绝世卡及其固定成长内容不因本次下放而改变，归元功等现有 rank 0 特例继续单独处理。

### 凝气及以上进阶卡

继续承担复杂资源联动、流派机制、额外词条和太古成长。凝气后的成长主要体现为构筑复杂度和选择增加，而不是“终于可以使用有色卡牌”。

### 费用注意事项

当前实现仍采用中立卡 `1,1,2,2,3,3`、有色流派卡按境界点计费的旧规则，生成逻辑还会把有流派的 rank 0 卡提升到 rank 1。正式实施本计划时：

- 将标准费用统一调整为 rank 0～5 对应 `1,2,3,4,5,6`；
- 允许有流派的卡牌保留 rank 0，不再强制提升为 rank 1；
- rank 0 流派基础卡支付 1 点对应资源，rank 0 中立基础卡支付 1 点元气；
- 后续实施需同步调整生成逻辑和费用数据，但不恢复角色境界对卡牌使用的限制；
- 同时检查卡牌随机池、数据校验器、NPC 卡组生成、本地化和玩家文档中的旧费用阶梯及“有流派即至少 rank 1”假设。

## 7. 初始学习与卡牌获得节奏

不再需要保留十个等级的纯中立教学期。推荐使用短暂的无入口开局：

1. 初始角色暂时未选择流派入口，使用中立卡组；
2. 通过第一场教学战斗或短序章学习元气、抽牌、出牌和结束回合；
3. 第一次进入修炼界面时选择五个入口之一；
4. 获得对应基础资源和少量基础流派卡；
5. 后续卡组同时保留中立卡和流派卡，让玩家直观比较两类费用。

这样仍然保留“先学元气、再学有色费用”的顺序，但只占用一场战斗或一个短任务。

后续抵达第二个流派入口时，也可以提供一次该流派基础卡选择，避免只有资源而没有配套卡牌。

## 8. 元气作为中立费用

保留元气每回合固定 3 点的基础模型，暂不因其类似杀戮尖塔而重做。

其合理性在于：

- 所有角色都有稳定的最低行动能力；
- 中立卡不依赖流派入口即可使用；
- 中立卡的构筑代价主要来自卡组位置、抽牌机会和费用效率；
- 有色资源可以在简单底座上承载更复杂的流派机制。

元气还可以通过死气对冲、额外产出、保留、颜色转化和按实际支付量结算等现有机制形成深度。

暂不建议让基础元气随境界自动增长，额外产出继续由卡牌、装备和天赋提供。

## 9. 后续仍需决定的事项

- 固定费用节点的数量、位置与叠加规则；
- 御剑武器接续、锻体受伤积怒等特色后继节点的具体内容；
- 灵力异常伤害的适用范围与数值，以及神识暴击伤害的数值；
- 炼魂煞气池容量、带入量、胜利补充和建筑／装备恢复规则；
- 法身入口与借势能力的最终边界；
- 天道循环是否修改，以及永久减费的叠加上限或条件；
- rank 0 各流派基础卡的具体内容、费用和获得方式；
- 初始中立教学流程的实际长度；
- 五个入口之间的距离、跨流派连接和第二入口的路径成本；
- 境界突破动画、解锁列表与即时奖励，另行创建计划。

## 10. 实施阶段

### 阶段 1：悟道入口与原境界节点改造

先将悟道现有五个境界词条改为普通英文语义 ID，并解除节点境界要求：
