# 法身（avatar）

### 核心循环

法身自身没有专属的气。常态下法身牌只消耗元气，或借助相邻流派的资源（锻体的怒气、炼魂的煞气）——法身是"借势"的流派。真正的力量来自变身：打出高费变身卡，放弃原本卡组，化为神魔。神魔卡组是固定的攻击/防御牌，没有额外词条，但基础数值巨大，且只需要元气。

与其他流派化神才获得核弹卡不同，法身筑基即可变身，变身威力与当前境界挂钩。流派节奏 = 借势蓄力，请神上身。变身是终结姿态：用卡组的构筑深度交换神魔的纯粹数值。

### 关键字

变身：请神、神降、附体、显圣、法相、金身、降世
古神（炼魂·咒术）：烛龙、玄冥、后土、幽冥、摄魂
古魔（锻体·徒手）：刑天、蚩尤、夸父、撼山、断岳
古妖（御剑·武器）：九尾、毕方、化蛇、魅影、风雷
古灵（悟道·法术）：祝融、句芒、蓐收、共工、五行
常态（经文）：诵经、祈祷、仪式、香火、愿力

### 境界节点

- 凝气「阴阳相济」：回合开始时每25点神识+1元气\n每个回合一次：没有阳气时仍可打出卡牌，你获得对应的阴气
- 筑基「太极化生」：战斗开始时选择一张化身牌并将其洗入你的牌库
- 结丹「阴阳逆转」：化身提供的生命与攻击力加成 +50%
- 还婴「两仪归真」：化身牌费用 -2
- 化神「降世神通」：解锁化身牌第五形态「降世神通」——四相合体的终极神魔，卡组为四相神魔卡的精华融合

### 变身通用规则

- 变身卡为法身主词条卡，凝气起可得；费用为高额元气（8~12），或附带各形态特有的前提条件
- 打出后：原卡组（含手牌、弃牌）移出本场战斗，替换为固定的神魔卡组；清空所有有色气，保留元气与状态效果
- 变身时获得大量对应攻击力与额外生命值，数值按当前境界缩放（境界越高，神魔越强）
- 神魔卡组固定约 8 张：2~3 种攻击牌 + 1 种防御牌，只有基础数值，没有额外词条，费用全部为元气
- 每场战斗限变身一次

### 1. 古神（炼魂·咒术攻击力）——"烛龙临世"的构筑

天赋树位置：炼魂侧。与炼魂的咒术/煞气节点互认，投资咒术攻击力的炼魂系加点直接强化本形态。

- 变身卡「烛龙降世」：10 元气 + 弃掉全部手牌（请神需要虔诚）
- 神魔卡组：神罚·幽冥（咒术大伤害，吸血 X%）、摄魂（降低对手攻击）、神佑·烛照（大防御）
- 手感：消耗战+回复，数值碾压的同时吸血压制
- 节点：咒术攻击 +X
- 节点：变身为古神时，额外生命 +X%
- 节点：古神形态下每回合回复 X 生命
- 节点（capstone）「烛龙显圣」：古神形态下攻击牌附带吸血 X%

### 2. 古魔（锻体·徒手攻击力）——"刑天舞干戚"的构筑

天赋树位置：锻体侧。与锻体的破釜/战意分支相邻（见 bodyforge.md），徒手攻击力加点两派通用。

- 变身卡「刑天附体」：8 元气 + 对自己造成 20% 当前生命的伤害（魔神要血祭；自伤计入锻体怒气积攒）
- 神魔卡组：干戚之舞（多段徒手 ×3）、撼岳（单发重创）、金身（大防御）
- 手感：近战肉搏，皮糙肉厚，越战越勇
- 节点：徒手攻击 +X
- 节点：变身为古魔时，获得 X 点防御
- 节点：古魔形态下多段攻击段数 +1
- 节点（capstone）「战神不灭」：古魔形态下生命低于 50% 时，伤害 +X%（破釜联动）

### 3. 古妖（御剑·武器攻击力）——"九尾乱华"的构筑

天赋树位置：锻体侧远端（向御剑方向延伸）。与御剑的连斩/身法主题呼应，武器攻击力加点强化本形态。

- 变身卡「九尾附身」：10 元气，需要速度 ≥5 层（妖性灵动，非速不妖）
- 神魔卡组：妖刃乱舞（多段武器 ×4）、魅影（闪避 + 速度）、穿心（高伤单发）
- 手感：多段连击，快而致命
- 节点：武器攻击 +X
- 节点：古妖形态下速度 +X
- 节点：古妖形态下闪避 +X
- 节点（capstone）「千幻」：古妖形态下每回合第一张攻击牌段数 +1

### 4. 古灵（悟道·法术攻击力）——"祝融焚天"的构筑

天赋树位置：炼魂侧远端（向悟道方向延伸）。与悟道的元素主题呼应，法术攻击力加点强化本形态。

- 变身卡「祝融降灵」：12 元气（纯粹的高费，灵力洪流的代价）
- 神魔卡组：焚天（火系大伤害 + 灼烧）、五行轮转（每回合按 金→水→木→火→土 切换元素的大伤害）、灵盾（防御 + 元气回复）
- 手感：元素轰炸，每回合换着花样烧
- 节点：法术攻击 +X
- 节点：古灵形态下每回合额外 +1 元气
- 节点：古灵形态下元素牌伤害 +X%
- 节点（capstone）「五行归元」：古灵形态下五行轮转每换一种元素，本场战斗伤害 +X%

### 流派专属卡牌词条

常态法身牌（变身前）的定位：借势蓄力、防御生存、为变身创造条件。

主词条：
诵经：保留；每保留一回合，打出时效果 +X（念经积累）
请神：获得 X 元气；下回合变身卡费用 -X
神佑：获得大量防御
血祭：对自己造成 X 伤害，获得 X 煞气（与破釜/献祭主题联动）
愿力：接下来 X 回合，每回合 +1 元气

额外词条：
愿力充盈（打出时若元气 ≥8，效果 +X%）
香火（本牌保留在手中时，每回合 +X）
附体（打出后，手牌中的变身卡费用 -1）
神恩（抽 1 张牌）
净化（移除自身 1 个负面状态）
虔诚（若本回合未打出攻击牌，效果 +X）

### 绝世卡牌

- 烛龙降世 / 刑天附体 / 九尾附身 / 祝融降灵：四相变身卡（见各分支）
- 降世神通：（化神境界节点解锁的第五形态）四相合体，卡组为四相神魔卡的精华融合，数值按境界顶格计算
- 请神咒：从卡组中检索一张变身卡置入手牌，其费用 -X
- 神迹：本回合免疫死亡，回合结束时回复 X% 生命
