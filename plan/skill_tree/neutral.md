# 中立（neutral）

中立内容不属于任何流派。中立卡牌以元气为主要费用，任何构筑都可以使用；六张绝世卡覆盖无境到化神全部六个境界，两件绝世装备服务所有流派共通的构筑方向。

中立的主要决策是：**是否用中立卡补足流派的短板，以及用多大的构筑代价去换取中立的通用收益。**

## 核心规则

- **费用**：中立卡牌的标准费用是元气（凝气 1 点、筑基 2 点、结丹 2 点、还婴 3 点、化神 3 点）；标有 0 费的卡不消耗元气。动态费用 X 表示支付全部对应资源，太极之气不能用于支付。
- **死气**：死气是资源而非减益，不能被辟邪抵消。下回合的元气产出先与死气对冲；对冲后仍持有死气，则失去 5% 生命上限的生命，死气不会自动消耗。
- **易伤**：攻击牌的每一段攻击都会增加易伤层数点基础伤害，整牌结算后易伤全部消耗。自身易伤只有在自己受到攻击牌伤害时才会消耗。

## 绝世卡牌

绝世卡牌固定有 3 个固定额外词条，凝气解锁 2 个、筑基解锁 3 个，结丹/还婴/化神依次将三个已有词条太古化。
绝世卡牌需要鉴定，同一 `uniqueId` 在卡组中只能放入一张。下表的境界一列中，0 为无境，1～5 依次为凝气、筑基、结丹、还婴、化神；高起始境界的卡会在最低生成境界一次性应用所有已达成的解锁与太古。

### 归元功 `heal_vigor_all` 起始境界：无境

0 费。消耗全部元气，每点回复生命上限 {0}% 的生命；实际回复生命时随机移除 1 层负面状态。

| 解锁/太古境界 | 词条 | 效果 |
| --- | --- | --- |
| 0 | `qi_heal_armor` | 若本次消耗至少 3 点元气，每点消耗提供 {0} 点护甲。 |
| 1 | `qi_heal_cleanse` | 若本次消耗至少 3 点元气，额外随机移除 1 层可驱散的普通负面状态。 |
| 2 | `qi_heal_shield` | 若本次消耗至少 3 点元气，获得 1 层护盾。 |
| 3 | `qi_heal_armor`（太古） | 每点消耗元气提供的护甲 ×1.5。 |
| 4 | `qi_heal_cleanse`（太古） | 额外随机移除 2 层可驱散的普通负面状态。 |
| 5 | `qi_heal_shield`（太古） | 获得 2 层护盾，消耗门槛不变。 |

额外收益按本次实际消耗的元气结算，没有元气时全部不触发；即使生命已满、主效果没有产生实际治疗，额外净化仍会生效。

护甲与太极转化分别独立检查门槛，护甲不消耗元气，因此太极转化看到的是同一存量。死气会在下回合抑制元气产出（见核心规则）。

## 绝世装备

绝世装备需要鉴定，同种只能装备一件。首条为主词条，之后固定有 3 个固定额外词条：凝气解锁 2 个、筑基解锁 3 个，结丹/还婴/化神依次将三个已有词条太古化；主词条不参与太古。

### 乾坤戒 `cosmos_ring`（凝气，指环）

- **主效果**：手牌上限 +2；每回合正常抽牌 -1。
- `basicEnergyBonus`：每回合元气产出 +1。
- `handSizeMax`：手牌上限再 +1。
- `energyRetainLife`：至多保留 1 点元气到下回合，每保留 1 点受到 2 点纯粹伤害。

| 解锁/太古境界 | 词条 | 效果 |
| --- | --- | --- |
| 1 | `basicEnergyBonus` | 每回合元气产出 +1。 |
| 1 | `handSizeMax` | 手牌上限 +1。 |
| 2 | `energyRetainLife` | 至多保留 1 点元气，每点代价 2 点纯粹伤害。 |
| 3 | `energyRetainLife`（太古） | 元气保留上限由 1 点提高至 2 点，每点代价不变。 |
| 4 | `handSizeMax`（太古） | 手牌上限加成由 +1 提高至 +2。 |
| 5 | `basicEnergyBonus`（太古） | 每回合元气产出由 +1 提高至 +2。 |

正常抽牌减少与额外抽牌、手牌上限分别结算，所有实际抽牌仍受手牌剩余空间约束。元气保留独立于太极之气的永久保留规则，保留代价在下回合开始时结算。

### 无极佩 `limitless_amulet`（结丹，护身符）

- **主效果**：战斗开始获得「无极」状态——每回合第一张实际打出的中立加持牌使自身获得 1 层无极之气；五种流派卡牌费用 +1，中立卡不受影响。
- `start_battle_with_buff_all_damage`：战斗开始获得 {0} 层无极之气，数值随词条等级变化。
- `penetration`：提高护甲穿透，数值随词条等级变化。
- `critThreshold`：降低暴击充能阈值，数值随词条等级变化，仍受全局上下限约束。

| 解锁/太古境界 | 词条 | 效果 |
| --- | --- | --- |
| 3 | `start_battle_with_buff_all_damage` | 战斗开始获得无极之气。 |
| 3 | `penetration` | 提高护甲穿透。 |
| 3 | `critThreshold` | 降低暴击充能阈值。 |
| 3 | `start_battle_with_buff_all_damage`（太古） | 战初无极之气在普通数值基础上额外 +1 层。 |
| 4 | `penetration`（太古） | 护甲穿透数值 ×1.5。 |
| 5 | `critThreshold`（太古） | 暴击阈值修正数值 ×1.5，仍受上下限约束。 |

中立加持牌指没有流派归属的加持牌；法身卡属于法身流派，既不能触发也会受到流派加费。先打出流派牌或中立攻击牌不会消耗“每回合第一张中立加持牌”的机会。无极之气每层使造成的所有伤害 +5 基础值，可以跨回合累积，并可与虚空之气对冲。

## 构筑协同

- **乾坤戒 + 归元功/先天功**：额外元气提高消耗与治疗收益，保留元气可以支持下一次资源安排，但保留代价不能被忽略。
- **乾坤戒 + 万化归墟**：额外元气与保留提高 3+X 的可用存量，是大手牌元气构筑的终结方向。
- **无极佩 + 中立加持牌**：归元功、先天功、分心诀和参玄功都可以承担每回合的无极触发，再由后续攻击牌兑现增益。
- **无极佩 + 狭路相逢**：无极与穿透强化三段物理攻击；狭路相逢自身是攻击牌，需要先用其他中立加持牌蓄势。
- **无极佩 + 万化归墟**：无极可以增加纯粹伤害，但穿透与暴击阈值不参与纯粹伤害结算，不能把全部词条都视为万化归墟的线性增益。
