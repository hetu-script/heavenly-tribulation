# 锻体（bodyforge）

### 核心循环

怒气为滞后产出模型：上回合自身受到的伤害 ÷10 = 下回合开始时获得的怒气（需 `enable_rage`）。这带来流派的根本问题：怒气来源是被动的——对手不攻击，怒气就断供。解题钥匙有二：自伤卡牌（自己制造怒气来源），以及把"造成伤害"也纳入怒气积攒（结丹境界节点）。玩法感觉：刀尖舔血——以血养怒，以怒破局。

### 关键字

战意：愈战愈勇、怒涛、战吼、血怒、横扫千军、霸王再世
破釜：破釜沉舟、背水一战、浴血奋战、以伤换力、向死而生、玉石俱焚
（连斩、身法关键字见 swordcraft.md，与御剑共用）

### 境界节点

- 凝气「战意勃发」：战斗开始时每10点体魄获得1怒气。回合中每受到10伤害，下回合获得获得1怒气。
- 筑基「怒不可遏」：锻体牌怒气费用 -1
- 结丹「破釜沉舟」：造成伤害时你同样可以积攒怒气
- 还婴「血战到底」：你的生命低于 50% 时，徒手攻击力增加 50% 并获得 50% 攻击穿透
- 化神「崩天裂地」：战斗开始后将「绝世·崩天裂地」洗入你的牌库。「崩天裂地」：保留，耗费 10+X 点怒气，每点怒气造成 X 伤害，并对自己造成消耗值一半的伤害（此自伤计入怒气积攒——血不会白流）

### 1. 战意（怒气经济 / 蓄势）——"愈战愈勇"的构筑（与法身共享：法身同样使用怒气）

- 天赋（规则）「愈战愈勇」：每回合你第一次造成伤害时，额外获得 1 怒气。
- 节点：徒手攻击 +X
- 节点：生命上限 +X
- 节点「怒涛」：回合结束时，剩余怒气每 2 点转化为 1 点防御（怒气溢出利用，攻守一体）
- 节点（capstone）「霸王再世」：怒气达到 8 时进入狂暴——徒手牌伤害 +30%，但每回合结束时对自己造成 3 点伤害（风险回报，吸收旧设计"刀尖舔血"的博弈感；狂暴的自伤同样积怒）

法身侧表达：怒气是法身的第二资源（法身卡池使用怒气+煞气），怒气经济与溢流转化对两派等效。

### 2. 破釜（自伤 / 低血）——"向死而生"的构筑（与法身共享：血肉献祭）

- 天赋（规则）「浴血奋战」：生命低于 50% 时，受到伤害 -X%，徒手牌伤害 +X%。
- 节点：自伤伤害 -X%（自伤减免）
- 节点：生命上限 +X
- 节点「以伤换力」：每回合第一次自伤后，本回合下一张徒手牌伤害 +X%
- 节点（capstone）「向死而生」：每场战斗一次，生命降至 0 以下时保留 1 点生命并不死，获得 X 怒气

核心配套：自伤卡牌（见词条主词条）——即便对手不攻击，自己下回合也可以获得怒气。
法身侧表达：血肉献祭——法身以自身血肉为载体召唤上古存在，耗血换煞气与法身强化，与自伤主题天然同源。

### 3. 连斩（多段 / 追加）——与御剑共享

见 swordcraft.md 连斩分支。锻体侧表达：拳腿连打——punch 系卡牌本身就是 2 段攻击，直接享受段数与追加加成。

### 4. 身法（速度 / 闪避）——与御剑共享

见 swordcraft.md 身法分支。锻体侧表达：轻功（qinggong）、身法（shenfa）卡牌为两派共有，闪避反击同样是徒手反击流的发动机。

### 流派专属卡牌词条

主词条：
自伤：对自己造成 X 伤害，获得 Y 怒气（流派发动机的钥匙卡）
蓄势：本回合不打攻击牌时打出，获得 X 怒气与 X 防御
怒击：消耗所有怒气，每点怒气造成 X 伤害（小型核弹）
横扫：造成 X 伤害；若对手生命低于 50%，伤害 +X%
反震：获得 X 防御；下回合每次受到攻击时，对攻击者造成 X 伤害

额外词条：
浴血（打出时若生命低于 50%，伤害 +X）
以伤换力（打出后对自己造成 X 伤害，本回合下一张徒手牌 +X）
怒气充盈（打出时若怒气 ≥5，伤害 +X%）
坚韧（获得 X 点防御）
回气（打出后返还 1 怒气，每回合限一次）
震荡（攻击段数 +1，连斩联动）
重创（造成伤害时附加 1 层外伤）
战吼（打出后获得 1 层速度）

### 绝世装备

- 霸王鼎（法器）：每回合第一次受到伤害时，额外获得 1 怒气
- 玄铁护腕（手套）：徒手牌伤害 +X；自伤伤害 -20%
- 血衣（护甲）：生命低于 50% 时，防御 +X 且自伤卡的伤害 -X%
- 酒葫芦（饰品）：战斗开始获得 2 怒气，但闪避 -1（醉拳）
- 舍利子（法器）：「向死而生」触发时额外回复 X% 生命

### 绝世卡牌

- 天崩地裂：（化神境界节点获得）保留，耗费全部怒气（至少 10 点），每点怒气造成 X 伤害，并对自己造成消耗值一半的伤害（此自伤计入怒气积攒）
- 霸王卸甲：移除自身所有防御，每 1 点防御转化为 2 点伤害（破釜主题的极致：卸下防御，孤注一掷）
- 金钟罩：本回合受到伤害减半；每次被攻击时获得 1 怒气（把对手的攻势全部转化为怒气储备）
- 醉八仙：获得 3 层闪避与 2 怒气，下回合速度 -2
- 玉石俱焚：对双方各造成 X 伤害；若你的生命低于对手，你受到的部分减半
