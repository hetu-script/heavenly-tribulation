# 御剑（swordcraft）

> 状态：流派重构设计，尚未实施。现有御剑卡牌数据属于旧版内容，不作为本计划已经落地的依据。
> 本文定义流派规则与内容目标；具体机制契约、文件改造范围、实施顺序和验收方案见 `plan/skill_tree/swordcraft_implementation.md`。

御剑以武器牌积累剑气，以飞剑与多段攻击消耗剑气，并在连斩、身法、养剑和元素剑之间选择构筑方向。
流派的主要决策是：**如何衔接前后回合的剑气产出，以及何时把积累的剑意转化为一次完整的爆发。**

## 核心规则

- **剑气**：御剑卡牌的主要费用资源，在持有者的下个回合开始时清空。武器牌是当前节奏的产出端，飞剑与爆发牌是主要的消耗端。
- **剑意**：用于蓄势的普通状态，状态 id 为 `sword_intent`，不是永久状态、费用资源或阴阳气。每层剑意使剑法和御剑术攻击的每一段伤害获得 +5 基础值，随后再计算百分比、暴击、抗性与护甲。不使用剑法或御剑术攻击牌时始终保留；使用这类攻击牌后一次性全部消耗。
- **剑意获取**：不再由每张飞剑牌自动提供。普通主词条、公共随机额外词条、绝世卡牌与装备都可以成为剑意来源，分别服务冥想、养剑、身法和元素剑等构筑。
- **连斩**：多段攻击可以反复利用本次剑意加成，但也会多次触发护甲、破绽等按段结算的效果。
- **身法**：迅捷提供额外回合，闪避提供飘忽；额外回合会重新开始资源与“每回合”效果的结算。
- **养剑**：保留牌可以跨回合升级、减费或提供剑意，但会持续占用手牌空间。
- **元素剑**：火、水、雷剑与悟道共用元素和异常体系，并保留灵气费用。未选择「气剑同源」的纯御剑构筑通常无法使用元素剑；选择后可以用剑气支付，也可以用「五行轮转」等效果获得的灵气支付。
- **动态费用**：支付费用先于卡牌效果。N+X 中，N 是最低门槛，可按普通费用顺序由本色资源、互通资源（需「气剑同源」）和太极之气支付；X 只耗尽并计算卡牌本身指定的本色资源。其他颜色的气只补足 N，不计入 X，也不增加伤害、段数或超额支付效果。门槛类效果按支付后的剩余本色资源判断。

### 剑意的适用边界与结算顺序

- 仅作用于 `sword` 与 `flying_sword` 攻击牌，不强化拳法、点穴、持续伤害或异常伤害。
- 只修改当前这张牌的基础伤害，不影响之后打出的牌。
- 多段攻击的每一段都获得加成；剑意在整牌结算前不会因多段攻击而逐段消耗。
- 本张剑法或御剑术攻击牌的全部伤害与词条结算完成后，消耗当前全部剑意。即使本牌因条件未满足而没有造成伤害，也照常消耗。
- 获得剑意的额外词条可以设置负 `priority`，在主词条结算前生效。这样获得的剑意会参与本次攻击，并与原有剑意一起在整牌结算后消耗。
- 非攻击牌不消耗剑意；拳法、点穴等其他攻击牌也不消耗剑意。
- 剑意在回合与额外回合之间保留，战斗结束后清除。

### 保留与“从上回合保留至今”

- `isRetained` 表示卡牌具有保留能力，不等于它已经跨回合。
- “从上回合保留至今”必须以卡牌真正经历一次回合结束留手为准；刚抽到的保留牌不满足该条件。
- 卡牌实际打出或弃置后，其本次保留历史结束；以后再次抽到需要重新保留才能取得相关收益。
- 回合开始新抽到的牌不计入上一回合的保留牌。温玉剑鞘等效果只处理真正跨回合保留的卡牌。
- 额外回合结束同样可以进行保留结算。

### 气剑同源

「气剑同源」是御剑与悟道之间的可选共享节点，不属于御剑境界主轴。它只改变费用支付，不把两种资源在所有效果中视为同一种资源：

- 支付卡牌的有色费用时，灵气与剑气可以按 1:1 互相替代。
- 支付顺序固定为本色资源、另一种互通资源、太极之气。
- 灵气与剑气各自的产出、清空、保留、阴气对冲、阈值条件、溢出效果和其他非费用效果仍分别计算。
- 动态费用的最低门槛按本色、互通资源与太极之气的合计持有量判断；互通资源和太极之气只用于补足门槛。
- X 仍只支付本色资源。动态费用攻击的伤害、段数和超额支付效果不计算用于补足门槛的其他颜色资源。

纯御剑构筑可以完全不选择这个节点；元素剑构筑通过它用剑气支付灵气费用，「五行轮转」等效果提供的灵气也能反过来支付普通御剑牌的剑气费用。

## 绝世卡牌通用成长

绝世卡牌需要鉴定，同一 `uniqueId` 在卡组中只能放入一张。每张绝世卡牌有 1 条主词条和最多 3 条固定额外词条，主词条不参与太古。

- rank 1 解锁前 2 条额外词条，rank 2 解锁全部 3 条。
- rank 3、4、5 不再增加词条，按各卡的固定顺序依次将已有词条太古化。
- 起始 rank ≥2 的卡牌在最低生成境界就有全部 3 条额外词条。
- 起始 rank 3、4、5 的卡牌在最低生成境界分别已经拥有 1、2、3 条太古额外词条。
- 太古只强化对应词条的原有机制，不追加新的效果类型。

## 绝世装备通用成长

绝世装备首条为主词条，同种绝世装备只能装备一件，获得后需要鉴定。每件装备最多有 3 条固定额外词条，成长规则与绝世卡牌相同：

- rank 1/2 解锁 2/3 条额外词条；rank 3～5 依次太古化。
- 高起始境界装备在最低生成境界就具有相应数量的额外词条与太古词条。
- 一件装备的全部主逻辑合并为一条主词条，主词条不参与太古。
- 属性类词条的数值随词条等级变化，机制类效果按说明固定生效。

## 构筑协同

- **连斩／剑意**：公共主词条、额外词条、养剑效果与装备积累剑意，多段攻击一次性兑现；七星剑与剑意增幅类词条进一步放大段数收益。
- **身法／连斩**：万剑归宗把连续出牌转化为迅捷；额外回合提供更多出牌与产气机会，金丝剑穗也把飘忽转化为剑气和剑意。
- **养剑／爆发**：保留牌跨回合升级并降低费用，持续提供非攻击剑意来源，最终服务于藏剑、剑灵附体与剑道千秋的蓄势。
- **元素剑／悟道**：元素剑同时利用剑意和元素异常；抱真守一、五行轮转与气剑同源支持单元素专注、多元素轮转和两种资源的费用循环。
- **资源取舍**：剑气会在下回合开始时清空，剑意则在使用剑法或御剑术攻击牌前一直保留。玩家需要分别安排连续出牌的费用，以及一次性爆发的兑现时机。

## 数值与节奏复核重点

- 剑意每层每段 +5 是固定基础值，而普通卡牌数值随境界指数增长。实施前需用凝气、结丹、化神三档预期剑意层数和段数复核其相对收益。
- 万剑归宗、七星剑、金丝剑穗和剑灵附体都能提供迅捷；额外回合又会重新进行产出与“每回合”结算，需要测试连续行动是否过长。
- 藏剑与温玉剑鞘同时提供保留、升级和减费，需要检查长期占用手牌空间是否足以构成实际代价。
- 高起始境界的绝世内容在获得时已经完成部分或全部太古成长，强度评估不能只按普通词条版本计算。
