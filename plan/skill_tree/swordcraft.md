# 御剑（swordcraft）

### 核心循环

剑气为滞后产出模型：本回合打出的武器牌（cardType=weapon）数量 = 下回合开始时获得的剑气（需 `enable_chakra`）。飞剑牌本身是 spell 卡，消耗剑气但不积攒。流派节奏 = 以武养剑，以剑伤敌；资源过时不候（回合开始清空，仅煞气例外）。与悟道灵气的"囤积-规划"相反，剑气是"流转-爆发"。

### 关键字

连斩：剑雨漫天、连环剑、疾风快剑、追魂夺命、幻影分光、七星剑阵
身法：踏雪无痕、流星赶月、御风而行、电光石火、瞬身斩、剑步
养剑：剑丸、剑匣、温养、藏剑、祭剑、剑灵
元素剑（与悟道共享）：纯阳剑诀、寒冰剑气、五雷剑诀、离火剑、青冥剑

### 境界节点

- 凝气「剑气凝形」：战斗开始时每10点身法获得1剑气。回合中每打出一张武器牌，下回合获得获得1剑气。
- 筑基「剑气如云」：御剑牌剑气费用 -1
- 结丹「飞花摘叶」：拳法和飞剑牌也算作武器牌
- 还婴「万剑归宗」：每打出一张飞剑牌获得 1 层剑意
- 化神「剑道千秋」：战斗开始后将「绝世·剑道千秋」洗入你的牌库。「剑道千秋」：保留，耗费 10+X 点剑气，每点剑气化作一道飞剑各造成 X 伤害（多段核弹，与悟道「天地不仁」的单发高伤互为镜像）

### 分支节点

- 「剑影分光」：每回合你打出的第一张多段攻击牌段数 +1
- 「踏雪无痕」：触发额外回合时：抽一张牌，并免除其有色费用
- （和悟道共享）「抱真守一」：使用元素牌后，随机升级手牌中一张同类元素牌
- （和悟道共享）「五行轮转」：每使用一种不同的元素，获得 1 点灵气
- 「养剑」：战斗胜利后，所装备的剑有20%概率等级 +1，如该剑已达等级上限，有10%概率破境。

### 流派专属卡牌词条

主词条：
剑法·加持：rank: 2；将你的元气转化为等量剑气
法术·攻击：rank: 3；消耗所有剑气，每点剑气造成 X 伤害
飞剑术·攻击：rank: 3；本回合每打出过一张武器牌便攻击一次，造成 x 伤害

额外词条：
回剑·攻击/加持（打出后返还 1 剑气）
剑步·攻击/加持（打出后获得 1 层速度）
连击·攻击（若本回合已打出过其他武器牌，追加一次攻击，造成50%的伤害）
剑气充盈·攻击（打出时若剑气 ≥5，伤害 +X%）

### 绝世装备

- 七星剑（武器）：多段攻击每段伤害 +25%；
- 沉香木剑匣（法器）：战斗开始获得 2 剑气；每回合第一张飞剑牌剑气费用 -1
- 金丝剑穗（饰品）：触发闪避后获得 1 剑气
- 温玉剑鞘：养剑词条的每回合增量翻倍
- 剑丸（法器）：回合开始时若剑气为 0，获得 3 剑气

### 绝世卡牌

- 剑气纵横：（化神境界节点获得）保留，耗费全部剑气（至少 10 点），每点剑气化作一道飞剑各造成 X 伤害
- 一剑破万法：驱散对手所有增益与防御，造成 X 伤害；若驱散了至少一个效果，伤害翻倍
- 人剑合一：保留；打出后本回合你的武器牌与飞剑牌不消耗剑气
- 天外飞仙：造成大量伤害；若对手生命不高于 50%，伤害翻倍（斩杀）
- 御剑飞行：本回合无敌（闪避所有攻击），获得 2 层速度
