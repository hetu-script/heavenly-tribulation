# 秘境入口锁定卡组计划

> 状态：待评审，尚未实施。

## 背景

局外保留多卡组，便于保存和尝试不同构筑；进入秘境后则锁定一个有效卡组，避免通过中途换卡组绕过敌人克制、垃圾牌、删改牌和临时卡牌等秘境规则。

当前战斗会按 `battleDeckIndex` 从局外卡牌库重新创建卡牌，因此只锁定编辑界面不足以让秘境修改跨战斗保留，需要独立的秘境卡组实例。

## 目标规则

- 进入秘境前必须选择一个有效卡组，记录其来源并创建本次秘境卡组。
- 秘境期间不能切换、创建或删除卡组，也不能直接编辑局外卡组。
- 加入、删除、复制、升级、改费和修改词条等效果只作用于本次秘境卡组，并跨多场战斗保留。
- 离开秘境时移除临时卡牌、诅咒和临时数值修改。
- 明确标为永久奖励的卡牌进入局外卡牌库，由玩家回到局外后决定是否加入卡组。
- 明确标为永久升级的效果按原卡 ID 更新局外卡牌，不直接带回整张秘境副本。
- 秘境中途存档时保存入口卡组来源与当前秘境卡组状态。

## 实现方向

秘境中维护独立状态，例如：

```text
dungeonDeck:
  sourceDeck
  cards
  originalCardId
  isTemporary
```

秘境内的战斗从 `dungeonDeck` 创建卡牌；普通战斗仍按现有 `battleDeckIndex` 创建。秘境临时性使用来源或生命周期标记，不复用符箓的 `isEphemeral`。

## 暂不包含

- 删除局外多卡组功能；
- 同伴轮战或战斗中补位；
- 具体秘境事件和卡牌奖励内容；
- 最终确定永久升级、临时诅咒及存档结构。
