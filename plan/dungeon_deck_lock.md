# 秘境永久卡组与地牢卡扩展计划

> 状态：普通地牢卡与 Boss 永久卡搜刮、永久卡组上限、统一跨轮清理，以及当前房间与 RNG 状态读档恢复已实施。

## 背景

永久卡提供跨轮稳定的开局基础，地牢卡提供本轮临时的构筑变化。营地保留多卡组并允许调整；进入秘境后锁定一个出战卡组，避免通过中途换卡组绕过敌人克制、删牌和临时卡牌规则。

战斗会按 `battleDeckIndex` 从当前英雄的 `cardLibrary` 创建战斗副本，但卡库和卡组列表本身是持久角色数据。因此不需要另建 `dungeonDeck` 或双份卡牌资产。

## 目标规则

### 永久基础卡组

- 每轮开始前，从当前英雄的永久卡库沿用或调整一个出战卡组，不要求重新组牌。
- 开始秘境时使用简单确认对话框显示当前卡组名称、永久卡数量、默认补位提示和失败资产损失警告，提供打开仓库、调整卡组、开始和取消；打开仓库不会初始化秘境，不提供逐张卡牌浮窗或另一套编辑功能。
- 调整卡组统一进入营地卡牌库；开始沿用其 `battleDeckIndex`，索引无效时可选择第一个非空卡组。
- 没有可用的非空卡组时提示“无可用卡组”并禁止进入秘境，玩家必须自行在营地创建或调整；不允许空卡组或全部默认卡开局。
- **秘境之外的永久出战卡组以当前有效卡组下限同时作为上限**，不得超过；额外永久卡留在卡库，不自动加入出战卡组。非空卡组可以低于此数量，由默认卡补位。
- 永久卡主要由卡包产出：普通战斗低概率掉落，精英高概率，Boss 保底；开包只进入卡库，不自动加入出战卡组。
- 卡包只能在营地打开。秘境中可以获得、携带和查看卡包，但使用入口必须拒绝打开并提示返回营地，不能只依赖屏蔽卡牌库按钮。
- 未打开卡包在 Boss 胜利后带回营地；失败时未入库卡包随未保护随身物品丢失。
- 非空永久卡数量不足时不阻止开始；进入战斗后沿用 `BattleScene.getDeck()` 的现有逻辑，以 `blank_default` 补齐缺少数量。
- 默认卡只存在于战斗，不写入永久卡库或卡组列表。
- 秘境期间不能切换、创建或删除卡组，也不能通过卡牌库编辑其他卡组；首版秘境直接屏蔽卡牌库入口。

### 本轮地牢卡与 Boss 永久卡

- `isDungeonCard` 缺省为 `false`，永久卡跨轮保留。
- 普通敌人和精英的地牢卡来自战胜敌人后的搜刮。普通战利品窗口关闭后，从敌人当前实际出战卡组随机抽取三张不同卡牌实例并保存，在当前房间自动显示搜刮 Component。
- 普通搜刮选择后复制所选卡牌数据，只在玩家副本上设置 `isDungeonCard: true`，再写入当前英雄的 `cardLibrary` 与 `battleDecks[battleDeckIndex]`，允许本轮实际出战卡组超过永久卡组上限；敌人原卡不变，放弃则不获得卡牌。
- **Boss 搜刮改为永久卡**：同样固定三个候选并明确标注“永久功法”，选择后复制卡牌，不设置 `isDungeonCard`，只加入 `cardLibrary`，不加入本轮出战卡组，返回营地后保留；放弃则不获得。Boss 搜刮不是返回营地的条件。
- 搜刮 Component 直接属于当前 `DungeonScene`，不创建新场景；参考战斗观星点选和卡牌库开卡包展示，使用五个固定卡位中的前三个。
- 暂时关闭 Component 不完成搜刮，点击敌人可重新打开原候选；只有选择或明确放弃才完成且不可重做，回访和读档不刷新。
- 地牢卡计入实际卡组数量，因此会减少默认卡补位；增加卡组数量也可能稀释关键卡，放弃是正常策略选择。
- 秘境中不提供常规删牌入口，只有明确说明的少数特殊效果可以移除地牢卡。
- 加入、复制、升级、改费和修改词条等本轮效果直接作用于当前英雄的持久卡库与锁定卡组；地牢卡的修改随该卡在本轮结束时一起移除。
- 本轮 Boss 胜利、失败或中途放弃返回营地时，从 `cardLibrary` 与当前选择的 `battleDecks[battleDeckIndex]` 中一并移除所有地牢卡；其他未选中的卡组不处理，永久卡不受影响。下一轮从永久基础卡组重新开始，不足部分再次由默认卡补位。
- `isDungeonCard` 不复用符箓的 `isEphemeral`，也不与禁止卡包产出的 `isUnpackable` 混用。

### 存档与跨轮

- 普通场景存档直接保存当前英雄的 `cardLibrary`、`battleDecks`、锁定的 `battleDeckIndex` 和每张卡牌的 `isDungeonCard`。
- 房间实例同时保存三个搜刮候选及选择／放弃完成状态，Boss 候选的永久奖励属性也必须明确可恢复。
- 读档后恢复保存时的实际卡组、地牢卡与搜刮状态，不能刷新候选或重复获得。
- 胜利、失败或中途放弃的跨轮结算必须幂等，地牢卡只能移除一次，永久卡不得重复生成或误删。
- 失败不重置永久卡库、角色境界、仓库或装备栏。

## 暂不包含

- 删除营地多卡组功能；
- 独立秘境卡组副本或双份卡牌资产；
- 将默认补位卡写入永久卡库；
- 同伴轮战或战斗中补位；
- 具体卡牌奖励内容；
- 本轮结束后保留地牢卡的规则。
