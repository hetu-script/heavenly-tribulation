# 《天道奇劫》第一个试玩版本：目标与边界

> 本文用于约束第一个公开试玩版本（以下简称 DEMO）的范围。
>
> 本文不删除任何长期设计。未纳入 DEMO 的内容一律进入后续版本候选，而不是在开发过程中临时加入 DEMO。

## 1. DEMO 的产品定位

DEMO 是一款以卡牌战斗与功法构筑为核心、发生在随机仙侠沙盒世界中的单机 RPG 试玩版本。

玩家在一局随机生成的世界中修炼和探索，通过秘境获得功法、装备与材料，利用天赋、装备和卡牌精炼形成自己的流派构筑，再通过境界突破和据点挑战提升自己在世界中的地位。

DEMO 首先应当验证以下核心体验是否成立：

> **获得随机功法 → 改造并形成构筑 → 在秘境中验证构筑 → 获得成长与扩张收益 → 挑战更高难度内容。**

DEMO 不是完整的《天道奇劫》，不以实现长期设计中的全部系统为目标。

## 2. DEMO 的核心卖点

### 2.1 可收集、可改造的功法卡牌

卡牌不仅用于主动出牌战斗，也是具有境界、等级、主词条和额外词条的功法物品。

玩家可以获取、鉴定、比较、分解和精炼卡牌，将随机掉落逐渐改造为适合自己流派的构筑。

普通词条主要提供数值与次要变化；主词条、关键天赋和绝世词条负责形成机制与规则变化。避免所有成长都退化为数值叠加。

### 2.2 随机仙侠世界中的角色成长

每次游戏生成包含 NPC、门派、城市、据点、生产建筑和秘境入口的六边形沙盒世界。

随机世界应改变玩家的探索路线、资源获取和门派互动，但不能决定某个基础流派是否能够正常游玩。

### 2.3 构筑对世界产生实际影响

秘境用于检验战斗构筑，经营为成长提供资源，据点挑战让战斗胜利能够改变世界中的门派归属和设施使用权。

经营和门派扩张服务于角色成长，不单独扩张为完整经营游戏或 4X 游戏。

## 3. 核心玩法循环

DEMO 的主要循环为：

1. 在沙盒世界中探索，发现城市、据点、NPC、生产建筑和秘境。
2. 通过任务、交易和最小化经营获得资源。
3. 组建卡组并进入秘境，进行主动出牌战斗。
4. 获得功法卡牌、装备、材料、经验和秘境奖励。
5. 通过精炼、装备配置、天赋分配和修炼强化角色。
6. 提升境界，挑战更高阶秘境或敌对门派据点。
7. 解锁更多设施、资源和成长空间，然后进入下一轮挑战。

各系统的收益必须回到该循环：

- 经营产物用于卡牌精炼、装备打造、恢复、秘境入场或其他明确的角色成长用途。
- 据点占领提供设施使用权、一次性战利品、门派收益或生产管理能力中的至少一种。
- 境界提升解锁新的卡牌、天赋、装备栏、秘境或据点挑战。
- 秘境奖励必须能够形成实际的构筑选择，而不只是增加材料数量。

## 4. DEMO 的系统范围

## 4.1 卡牌战斗

### 目标

完成五个流派的基础可玩性，并形成能够区分流派的战斗体验：

- 悟道；
- 御剑；
- 锻体；
- 法身；
- 炼魂。

### DEMO 内

- 主动出牌、回合、抽牌、弃牌、手牌上限和出牌队列。
- 元气、流派资源、太极抵扣及必要的动态费用。
- 伤害类型、暴击、异常状态、增益与减益。
- 观星、额外回合、伤害预测等已经接入战斗主流程的机制。
- 五个流派的基础卡牌、核心天赋和必要的绝世内容。
- 与流派对应的 NPC 卡组生成、天赋分配和基础 AI。
- 足以验证构筑差异的普通敌人、精英和 Boss。
- 战斗结算、战败处理及与秘境、据点的衔接。

### 完成标准

- 每个流派至少具有一条清晰、可独立成立的基础构筑路线。
- 每个流派能够正常获得资源、支付费用并完成战斗循环。
- NPC 能体现流派差异，而不是仅更换卡牌名称和动画。
- 不存在阻断战斗结算、奖励发放或返回世界的流程问题。
- 不要求五流派在 DEMO 中拥有完全相同的卡牌数量和绝世内容数量。

### 不在 DEMO 内

- 为所有流派无限追加第二、第三套完整构筑分支。
- 为每种卡牌组合制作专属演出。
- 完整重写敌方 AI，使其达到高水平玩家水平。
- 太古词条等尚未进入实际消费流程的新词条层级。

## 4.2 卡牌、天赋、装备与修炼

### DEMO 内

- 暗黑式随机词条卡牌生成。
- 卡牌鉴定、分解及已有的主要精炼操作。
- 五流派基础天赋树和关键规则节点。
- 装备随机词条、穿脱、属性重算和战斗联动。
- 必要的绝世卡牌与绝世装备，用于展示规则型构筑。
- 卡包、丹药、符箓等已经能够服务核心循环的物品。
- 修为等级、经验、境界突破、渡劫、寿元与劫数的基础规则。
- 卡组构建、装备配置和角色属性界面。
- 清晰的卡牌比较、词条说明和来源提示。

### 完成标准

- 玩家能够理解同名卡牌之间的主要区别。
- 随机词条不会使核心流派完全依赖随机掉落才能成立。
- 玩家能够通过相对稳定的渠道获得基础流派卡牌。
- 精炼提供一定的构筑主动权，而不是只能不断替换为更高数值的随机掉落。
- 卡牌、装备和天赋的规则型效果有明确分工，避免大量重复的百分比加成。

### 不在 DEMO 内

- 装备破境、完整重铸体系及所有长期装备打造设想。
- 五流派全部天赋树的最终内容量和最终排布。
- 复杂的太古词条、卡牌塞入敌方牌库等新机制扩展。
- 仅为增加内容数量而制作的词条、装备和绝世物品。

## 4.3 沙盒世界

### 现有基础

DEMO 直接利用已经实现的程序生成世界，包括：

- 可选规模的六边形地图；
- 随机 NPC、境界、流派和门派；
- 随机城市、据点及据点内建筑；
- 随机生产建筑和秘境入口；
- 地图移动、探索、发现、NPC 移动及基础遭遇。

### DEMO 内需要补强的内容

- 默认提供一个明确标注的推荐世界规模。
- 保留世界规模选项，但不要求所有规模具有完全相同的游戏节奏。
- 起始区域具备完成核心循环所需的最低设施和资源保障。
- 起始角色能够找到适合当前境界的战斗、卡牌来源和秘境。
- 关键任务目的地和必需设施不会因为随机生成而不可达。
- 基础流派的关键成长条件不能完全依赖稀有随机结果。
- 世界内的时间推进、月度刷新和地点更新能够正确配合经营与任务。

### 起始区域最低保障

玩家初始可到达范围内应至少有：

- 可进入、交易、休息和接取基础任务的城镇；
- 适合初始角色的卡牌或装备来源；
- 与初始境界匹配的秘境入口；
- 支持基础生产或打造的资源来源；
- 境界合适的 NPC、敌人和门派成员。

### 不在 DEMO 内

- 新世界类型和大型地图生成算法扩展。
- 更复杂的地形生态、道路、商路或交通运输系统。
- 完整 NPC 自主生活、生产、修炼和战略行为。
- 为追求地图规模而增加缺乏互动的地点数量。

## 4.4 秘境

### 目标

使秘境成为 DEMO 中战斗、构筑验证和奖励获取的主要载体，具备清晰的开始、探索、风险决策、奖励和撤离过程。

### DEMO 内

- 普通秘境与高阶秘境的基本区别。
- 普通敌人、精英、Boss、商人、营地和奖励房间。
- 秘境层数、境界、入口消耗、战败和撤离规则。
- 与角色卡组、装备、境界和奖励系统的衔接。
- 足够的遭遇差异，避免所有房间只是重复战斗。
- 清晰展示房门或路线背后的风险与收益。
- 利用 AI 辅助制作必要的环境美术差异，但美术制作不得先于玩法闭环。

### 可选的小规模改进：空间展开式迷宫

可以验证“房间空间相连、逐步展开”的秘境形式，但首版只实现小规模规则：

- 房间在地图上实际相连，而非纯装饰走廊。
- 路线选择会产生资源、战斗、奖励或撤离方面的差异。
- 如使用钥匙，钥匙只承担路线控制，不再扩展复杂锁具体系。
- 如使用当局金币，仅用于秘境内的商店或服务，并在离开时清空。
- 尽量复用生命或游戏内时间表达探索消耗，不默认新增独立体力系统。
- 关键路线必须可解；不能因隐藏随机结果产生无法提前判断的必死局。
- 玩家无法或不愿抵达 Boss 时，可以撤离并按规则保留部分收获。

如果该形式不能在限定工作量内证明比现有房间序列更有趣，DEMO 保留现有秘境结构，不继续投入复杂迷宫生成。

### 不在 DEMO 内

- 把秘境做成与主世界完全分离的第二套 RPG。
- 大量秘境专属卡牌、独立永久成长和独立货币体系。
- 复杂房间拼接、任意形状墙体和大量特殊房间。
- 完整临时队友、傀儡队伍或多人编队系统。
- 数量庞大的随机事件和剧情支线。

## 4.5 最小化据点经营

### 定位

DEMO 实现“卡牌化生产面板”，借鉴 Stacklands 的直观拖拽表现，但不完整复刻 Stacklands。

该界面用于明确回答：

- 建筑运转需要什么；
- 当前为什么停产；
- 运转后能够生产什么；
- 新建筑需要什么才能建成。

### DEMO 内

- 建筑、资源、蓝图和劳力使用卡牌或统一卡牌形式展示。
- 材料卡显示堆叠数量，支持整叠或指定数量投入。
- 劳力抽象为个位数的平民单位，不赋予独立姓名、属性、关系和职业。
- 将维护资源与劳力分配到建筑后，建筑消耗游戏内时间进行生产。
- 蓝图、材料和劳力堆叠后，经过游戏内时间建成建筑。
- 玩家管理的据点使用统一生产规则。
- NPC 据点继续使用抽象补货和经济规则，不运行完整生产模拟。

### 建筑状态

首版只保留三种主要状态：

- 缺料停产；
- 正常运转；
- 修建或升级中。

### 生产规则

- 每个建筑首版只保留一条主要生产配方。
- 可以存在少量随机或额外产物，但不建立复杂多级生产链。
- 时间统一使用游戏内时间，不实现现实时间挂机和离线收益。
- 玩家可以运行一个周期、运行一段时间，或运行到缺料。
- 生产推进时间时，正常结算任务期限、世界刷新和其他必要时间规则。

### 不在 DEMO 内

- 劳动力幸福度、技能、职业、工资和人口繁衍。
- 复杂仓储、物流、运输和自动分配。
- 多层工业链与生产效率科技树。
- 商路、贸易路线和完整区域经济模拟。
- 现实时间等待、后台运行和离线收益。
- 全部副职业建筑的独立深度玩法。

## 4.6 最小化门派扩张

### 定位

DEMO 保留由玩家主动发起的据点挑战，不实现 NPC 战略 AI，不将系统扩展为完整 4X。

### DEMO 内

- 世界生成时确定门派关系和据点归属。
- NPC 不主动宣战、不主动改变外交、不主动扩张、不主动反攻。
- 玩家可以主动宣战或通过据点挑战进入敌对状态。
- 玩家挑战据点守军，胜利后改变整个据点及所属建筑的归属。
- 每个据点首版只进行一场代表性守城战，不引入军队和多波攻城。
- 战败沿用普通战败规则，NPC 不追击、不反攻。
- 敌对状态对进入、交易和设施使用产生必要限制。
- 占领提供至少一种明确收益：设施使用权、一次性奖励、门派收益或生产管理能力。
- 守军强度与门派、据点规模和境界相匹配。

### 规则约束

- 首版优先采用玩家代表所属门派发起挑战、占领归属于该门派的规则。
- 不为了实现私人领地而新增玩家建国和独立外交体系。
- 不允许玩家在无提示情况下造成无法理解的永久外交后果。
- 即使 NPC 不主动行动，也必须防止占领收益造成无条件经济滚雪球。

### 不在 DEMO 内

- NPC 宣战、结盟、外交提议和主动关系变化。
- NPC 攻城、反攻、调兵和战略扩张。
- 军队编制、城防建设、多波战斗和战争补给。
- 国家系统、完整外交树和世界大战。
- 占领后的税收、人口治理和抵抗运动。

## 4.7 任务、人物与门派生涯

### DEMO 内

- 保留能够服务探索、资源获取和门派成长的基础任务。
- 保留 NPC 关系、门派身份、功勋、职位和例会等已有功能中与核心循环直接相关的部分。
- 任务目的地应可理解、可到达，奖励应服务角色成长。
- NPC 的流派、卡组、境界和门派归属与战斗内容一致。
- 通过基础引导让玩家理解探索、秘境、修炼、经营和据点挑战的关系。

### 不在 DEMO 内

- 设计文档中全部高级职位任务。
- 完整人物三观、社会舆论和复杂关系演化。
- 大量随机剧情、婚姻、家族和师徒支线扩展。
- 完整 NPC 月度自主任务和门派经营行为。

## 4.8 剧情、表现与辅助内容

### DEMO 内

- 必需的新手教程和操作提示。
- 支持核心流程的中文文本、本地化键和百科说明。
- 能清楚区分境界、流派、稀有度、卡牌状态和词条的视觉表现。
- 必要音效、动画和反馈，优先保证战斗结算与操作可读性。
- 存档、读档和设置能够覆盖 DEMO 的完整流程。
- 利用 AI 提高美术、音乐和文本制作效率，但所有生成内容需经过筛选与统一处理。

### 不在 DEMO 内

- 三部曲主线和多世界剧情。
- 魂骨钉完整能力树及主线科幻揭示。
- 大规模剧情 CG、配音和复杂演出。
- 完整多语言版本。
- 与核心循环无关的新小游戏。
- 为展示技术而增加的 LLM 还价、动态对话等功能。

## 5. DEMO 明确排除的长期内容

以下内容不得因为相关系统已经存在而自动进入 DEMO：

- 完整 Stacklands 经营游戏；
- 完整门派 4X 与战略 AI；
- 商路、贸易路线和复杂生产线；
- 家宅升级、完整私人领地和玩家建国；
- 完整拍卖玩法和复杂拍卖经济；
- 大量临时队友、傀儡、队伍编排；
- 全部门派法令、外交和高级职位玩法；
- 全部辅助职业、阵法、幻术、通灵和显圣体系；
- 三部曲主线剧情及平行世界；
- 与核心循环无关的新系统和新小游戏。

长期想法记录在 `TODO.md`、`NEXT.md` 或其他设计文档中。DEMO 开发期间新增想法默认进入后续候选，不自动改变本文范围。

## 6. 建议的 DEMO 内容边界

DEMO 应当是一段有明确终点的体验，而不是无限内容沙盒。

建议目标：

- 新玩家能够在开始后的较短时间内进入第一次战斗。
- 前 30 分钟内至少经历一次有意义的卡牌、装备或天赋选择。
- 1～2 小时内能够经历至少一轮完整的构筑、秘境验证和境界或据点成长。
- DEMO 提供一个明确的阶段目标，例如击败指定高阶秘境 Boss、完成一次境界突破或攻下一个高阶据点。
- 达成目标后显示 DEMO 完成提示，并允许玩家继续自由探索。

五流派可以全部开放，但不要求玩家在单次试玩中体验全部流派，也不以展示全部内容作为通关条件。

具体城市、秘境和 Boss 数量服从节奏与测试需要，不为追求内容数量而复制低差异内容。

## 7. 推荐实施顺序

### 阶段一：完成战斗内容基线

- 完成五流派卡牌与关键天赋。
- 补齐 NPC 卡组、天赋配置和基础 AI。
- 验证资源循环、战斗时长和主要构筑路线。
- 冻结非必要的新战斗机制。

### 阶段二：打通秘境与角色成长

- 确保秘境从进入到撤离完整可玩。
- 调整敌人、奖励、修炼和境界突破节奏。
- 小规模验证空间展开式迷宫；不成立则保留现有结构。
- 完成一轮从随机掉落到精炼再到战斗验证的构筑体验。

### 阶段三：接入最小经营

- 统一玩家管理据点的建筑维护与生产规则。
- 完成卡牌化拖拽、劳力分配、生产进度和建筑修建。
- 将生产收益接入已有卡牌、装备和秘境需求。
- 不扩展 NPC 经济模拟。

### 阶段四：接入最小据点挑战

- 完成宣战或挑战入口、守城战和归属变更。
- 接入敌对后的设施限制和占领收益。
- 检查连续占领、战败、存档和返回世界的完整流程。
- 不增加 NPC 战略行为。

### 阶段五：整合与外部试玩

- 调整随机世界的起始保障和推荐地图规模。
- 完成新手引导、DEMO 阶段目标和结束提示。
- 统一 UI、文本、图标、音效和必要美术。
- 测试不同流派、地图规模、世界种子和存档流程。
- 根据外部反馈修正节奏与可读性，而不是继续增加系统。

## 8. DEMO 验收标准

只有同时满足以下条件，才认为 DEMO 的核心开发完成：

### 核心流程

- 能从新建随机世界开始，不依赖开发者指令完成整个 DEMO 流程。
- 探索、任务、秘境、修炼、经营和据点挑战之间没有阻断流程的问题。
- 玩家能够达成明确的 DEMO 阶段目标并看到完成反馈。
- 存档和读档后，卡组、装备、生产、外交、据点归属和秘境状态保持一致。

### 战斗与构筑

- 五流派均能完成基础战斗与成长循环。
- 每个流派至少有一种可被玩家理解和主动追求的有效构筑。
- 随机词条有比较和改造价值，不只是增加阅读量。
- 关键战斗机制、伤害预测和实际结算不存在明显矛盾。
- NPC 能正常使用对应流派资源与卡组。

### 世界与节奏

- 多个测试种子均能找到完成核心循环所需的设施与资源。
- 推荐地图规模下，玩家不会因过长移动和搜索而迟迟无法进入核心玩法。
- 基础流派不会因随机世界缺少关键卡牌或设施而无法成立。
- 经营收益和据点收益有明确用途，但不会立即破坏成长节奏。

### 可用性

- 新玩家不依赖开发者口头说明，能够理解基本出牌、精炼、修炼、生产和据点挑战。
- 建筑停产、无法支付、无法进入、挑战失败等状态都有明确原因提示。
- 主要界面能够清楚展示卡牌差异、资源数量、生产进度和战斗结果。
- 不存在频繁阻断游戏的崩溃、死锁或严重存档问题。

## 9. 外部试玩需要验证的问题

DEMO 的首要目的不是证明所有系统都存在，而是回答：

1. 玩家是否喜欢随机词条功法与卡牌战斗的结合？
2. 玩家是否能形成有意的构筑，而不是只选择数值更高的物品？
3. 秘境是否提供了足够清晰的挑战、风险和奖励节奏？
4. 境界突破和据点挑战是否让玩家感到成长具有意义？
5. 最小经营是否直观，还是反而打断战斗与探索？
6. 玩家是否愿意在 DEMO 结束后以不同流派或世界种子再玩一次？
7. 玩家最希望扩展的是战斗构筑、秘境、经营，还是门派与世界互动？

后续开发方向优先根据这些答案决定，而不是仅根据长期功能清单决定。

## 10. 范围变更规则

DEMO 开发过程中，如准备新增功能，必须先回答：

- 它是否直接修复核心循环中的断点？
- 它是否解决外部试玩中的高频阻塞问题？
- 它是否比修复现有战斗、秘境、UI 和节奏更重要？
- 它是否会引入新的货币、界面、AI、存档结构或测试组合？

如果答案不明确，则该功能进入后续版本候选。

允许通过删减低差异内容保证整体完成度。不得以“系统已经做了一半”为理由继续扩大 DEMO 范围。

DEMO 的成功标准不是系统数量，而是：

> **玩家能否在一个随机仙侠世界中，理解并享受一套完整的功法构筑、秘境冒险、修炼成长与有限扩张循环。**
