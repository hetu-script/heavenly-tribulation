# 《天道奇劫》第一个试玩版本：目标与边界

> 本文用于约束第一个公开试玩版本（以下简称 DEMO）的范围。
>
> 本文不删除任何长期设计。未纳入 DEMO 的内容一律进入后续版本候选，而不是在开发过程中临时加入 DEMO。

## 1. DEMO 的产品定位

DEMO 是一款以随机词条功法、卡牌战斗和装备成长为核心，采用“固定营地 + 场景链秘境”结构的单机 Roguelike 试玩版本。

只有开始新游戏时才随机创建角色。玩家在营地整理仓库、组成永久出战卡组、配置装备并修炼，随后使用同一角色进入连续场景构成的秘境。每轮 Boss 胜利或失败都会返回营地：胜利带回随身物品并提高下一轮层级，失败丢失未入库且未装备的物品并从层级 0 重来。角色、境界、永久卡库、仓库和装备栏跨轮保留。

DEMO 首先应当验证以下核心体验是否成立：

> **营地准备 → 按固定路线战斗与探索 → 获得功法与装备并形成构筑 → 挑战 Boss → 返回营地整理与突破 → 以更高层级再次冒险。**

DEMO 不是完整的《天道奇劫》，不以实现沙盒世界、门派生涯或经营模拟为目标。

## 2. DEMO 的核心卖点

### 2.1 可收集、可改造的功法卡牌

卡牌不仅用于主动出牌战斗，也是具有境界、等级、主词条和额外词条的功法物品。

永久卡保存在当前英雄的卡库中并跨轮保留。`isDungeonCard` 缺省为 `false`；标记为 `true` 的地牢卡可以在本轮扩展出战卡组，但胜利或失败返回营地时都会移除。永久卡不足卡组下限时，沿用战斗中的 `blank_default` 虚拟补位，不写入卡库。

玩家获取、鉴定、比较、分解和精炼卡牌，将随机掉落逐渐改造为适合自己流派的构筑。

普通词条主要提供数值与次要变化；主词条、关键天赋和绝世词条负责形成机制与规则变化。避免所有成长都退化为数值叠加。

### 2.2 装备、卡牌与境界的持续成长

当前英雄持续保留永久卡、仓库物品、已装备装备、配方、功能解锁、修为和境界。随身物品在胜利时带回营地，失败时丢失；玩家需要在轮次之间整理入库。

经验在秘境中也可获得，玩家在修炼界面手动升级和分配天赋。境界突破只能由营地突破设施发起，要求达到当前境界等级上限并携带目标境界的破镜丹；开始试炼即消耗丹药，失败无其他惩罚。成功后提升 `rank`、营地发展度和秘境境界，并将秘境层级归零。只有开始新游戏时才重新随机创建角色。

持续成长以收集、解锁、选择权和有限度的准备为主，不提供无限属性成长，也不能替代秘境中的随机卡牌构筑。

### 2.3 固定场景路线构成的秘境冒险

秘境不使用六边形地图、格子房间或空间迷宫。每个场景由插画背景、敌人、商人或营地功能入口组成，并按事先设计的固定顺序出现。

首版不随机生成路线，也不让玩家选择房间类型。固定遭遇顺序用于精确控制教学、战斗强度、奖励和突破节奏；随机性主要来自敌人卡组、卡牌词条、装备、奖励和随机商人。

### 2.4 有资源与机制差异的流派

流派差异由资源产出、卡牌主词条、关键天赋、额外词条和装备联动共同形成，而不是只更换卡牌名称、插画和动画。

五流派是内容目标，但不得阻塞单流派垂直切片和核心循环验证。

## 3. 核心玩法循环

DEMO 的主要循环为：

1. 开始新游戏时随机创建角色；在营地整理仓库、确认永久卡组与装备，完成精炼、天赋分配和修炼。
2. 进入秘境，在插画场景中按固定顺序遭遇敌人、随机商人和休息设施。
3. 战斗场景只有胜利才能继续前进；商人与休息场景允许直接前进。
4. 获得永久卡、地牢卡、装备、材料和经验，直接写入当前英雄。
5. 通过交易、休息恢复、装备配置、手动升级和天赋分配强化同一英雄；秘境中可打开修炼，但不能突破或打开卡牌库。
6. 按固定路线进入下一场景，逐步挑战精英与 Boss。
7. Boss 胜利后返回营地，带回随身物品并提高下一轮秘境层级；达到当前境界上限后不再提高。
8. 失败或主动放弃也返回营地，丢失未保护的随身物品、移除地牢卡，并从层级 0 开始下一轮。

各系统的收益必须回到该循环：

- 营地成长提供新的初始选择、构筑方向或有限便利，不直接取代局内成长。
- 秘境奖励必须能够形成实际的构筑选择，而不只是增加材料数量。
- 境界提升解锁当局内新的卡牌、天赋、装备栏和敌人挑战。
- 装备与卡牌改造必须能在之后的战斗中产生可感知的效果差异。

## 4. DEMO 的系统范围

## 4.1 卡牌战斗

### 目标

形成能够区分流派的战斗体验，并确保所有进入 DEMO 的流派都能独立完成资源与战斗循环。

### DEMO 内

- 主动出牌、回合、抽牌、弃牌、手牌上限和出牌队列。
- 元气、流派资源、太极抵扣及必要的动态费用。
- 伤害类型、暴击、异常状态、增益与减益。
- 观星、额外回合、伤害预测等已经接入战斗主流程的机制。
- 已开放流派的基础卡牌、核心天赋和必要的绝世内容。
- 与流派对应的敌人卡组生成、天赋配置和基础 AI。
- 足以验证构筑差异的普通敌人、精英和 Boss。
- 战斗结算、战败处理及与秘境场景的衔接。

### 完成标准

- 每个已开放流派至少具有一条清晰、可独立成立的基础构筑路线。
- 每个已开放流派能够正常获得资源、支付费用并完成战斗循环。
- 敌人能体现流派差异，而不是仅更换卡牌名称和动画。
- 不存在阻断战斗结算、奖励发放或返回秘境场景的流程问题。
- 不要求各流派拥有完全相同的卡牌数量和绝世内容数量。

### 不在 DEMO 内

- 为所有流派无限追加第二、第三套完整构筑分支。
- 为每种卡牌组合制作专属演出。
- 完整重写敌方 AI，使其达到高水平玩家水平。
- 超出当前太古品质、生成与固定成长规则的新词条层级。

## 4.2 卡牌、天赋、装备与当局修炼

### DEMO 内

- 暗黑式随机词条卡牌生成。
- 卡牌鉴定、分解及已有的主要精炼操作。
- 已开放流派的基础天赋树和关键规则节点。
- 装备随机词条、穿脱、属性重算和战斗联动。
- 必要的绝世卡牌与绝世装备，用于展示规则型构筑。
- 卡包、丹药、符箓等已经能够服务核心循环的物品。
- 经验获取、手动升级、普通天赋节点的境界要求，以及由设施发起、消耗破镜丹的境界试炼。
- 卡组构建、装备配置和角色属性界面。
- 清晰的卡牌比较、词条说明和来源提示。

### 完成标准

- 玩家能够理解同名卡牌之间的主要区别。
- 随机词条不会使核心流派完全依赖随机掉落才能成立。
- 玩家能够通过相对稳定的渠道获得基础流派卡牌。
- 精炼提供一定的构筑主动权，而不是只能不断替换为更高数值的随机掉落。
- 卡牌、装备和天赋的规则型效果有明确分工，避免大量重复的百分比加成。
- 每个流派仅使用普通卡牌、基础天赋和稳定可获得的普通装备，也能完成 DEMO 基础流程；绝世内容用于改变构筑，而不是修复资源循环。

### 不在 DEMO 内

- 装备破境、完整重铸体系及所有长期装备打造设想。
- 五流派全部天赋树的最终内容量和最终排布。
- 仅为增加内容数量而制作的词条、装备和绝世物品。
- 寿元、复杂劫数和其他不服务当局节奏的长期规则扩展。

## 4.3 固定营地与跨轮成长

### 定位

营地是每轮之间的静态、安全整理场景，不运行沙盒世界模拟。开始秘境、仓库、打造、修炼、突破试炼和卡牌库统一使用卡牌入口，不占用 NPCList。秘境中保留修炼入口但屏蔽卡牌库，胜利与失败都返回营地。

### DEMO 内

- 功能卡入口：开始秘境、仓库、装备打造、功法管理、修炼、突破试炼和基础教学；开始秘境卡固定在右下角。
- 当前英雄的永久卡库、仓库、装备栏、随身物品、修为与境界。
- 永久卡组沿用和装备配置，不要求每轮重新组牌。
- 有上限的装备升级与便利能力。
- Boss 胜利提高下一轮层级、失败重置层级、突破提高秘境境界的规则。
- 营地与秘境共用“插画背景 + 卡牌选项”交互。

### 单一角色与资产边界

- 只有开始新游戏时才创建随机角色，角色跨轮保留。
- 仓库和装备栏中的物品始终安全；成功带回随身物品，失败清空未保护的随身物品。
- 永久卡跨轮保留；`isDungeonCard` 卡牌在胜利或失败结束本轮时移除。
- 不建立双角色、双份英雄资产或物品永久标记。
- 永久出战卡组以当前有效下限为基础，不足时由战斗中的默认卡虚拟补位。

### 装备与卡牌约束

- 永久卡组不能超过基础数量；地牢卡可在本轮额外加入。
- 装备仍受当前境界和装备栏限制。
- 所有改造直接作用于当前英雄，不需要深拷贝或回写另一份角色资产。
- 营地发展度由境界派生，不提供无限属性堆叠。
- 装备和卡牌优先提供构筑方向差异，而不是唯一的最高数值答案。

### 不在 DEMO 内

- 英雄创建和角色选择界面。
- 营地生产链、劳力分配和建筑维护。
- 功能 NPC 的日程、关系、生产和自主任务。
- 双角色、双份资产或每轮强制重新组牌。

## 4.4 场景链秘境

### 目标

使秘境成为 DEMO 中战斗、构筑验证和奖励获取的主要载体，具备清晰的固定遭遇、持续成长、Boss 与更高难度循环。

### DEMO 内

- 普通战斗、精英、随机商人、休息和 Boss 等少量场景类型。
- 场景模板、敌人配置、商人与库存、奖励和固定路线数据。
- 当前场景完成后按 `currentSceneIndex` 进入路线中的下一场景。
- 战斗胜利后才能前进；商人与休息场景完成后继续前进。
- 秘境境界、失败返回营地并重置层级、Boss 后返回营地并提高下一轮层级的规则。
- 与当前英雄卡组、装备、境界和奖励系统的直接衔接。
- 清晰展示当前场景内容、奖励和前进状态。
- 从旧地牢迁移普通敌人、精英、Boss、休息和随机商人；旧 `encounter`／灵泉事件暂不迁移。

### 美术与内容复用

- 使用固定比例的场景插画，并预留功能入口、NPC 和对话的 UI 区域。
- 功能卡与缩略图可以从背景插画裁切，不要求重复制作。
- 通过 NPC、敌人、局部道具、光影和必要差分复用场景背景。
- AI 生成内容不得包含需要游戏内渲染的文字，且必须经过筛选与统一处理。
- 先以占位背景验证场景机制，再制作正式美术。

### 不在 DEMO 内

- 下一场景卡选择、随机候选房间和随机路线。
- 格子地图、房间放置、体力与门锁；相关可选扩展见 `plan/grid_dungeon.md`。
- 六边形随机地牢、空间展开式迷宫和复杂房间拼接。
- 地图移动、寻路、战争迷雾和地图可达性系统。
- 仅为测试六边形引擎而保留的地图交互。
- 与卡牌构筑无互补关系的大型地图解密。
- 旧地牢 `encounter`／灵泉和大量随机事件、剧情支线。
- 大量秘境专属卡牌、独立永久成长和独立货币体系。
- 完整临时队友、傀儡队伍或多人编队系统。

## 4.5 剧情、表现、存档与辅助内容

### DEMO 内

- 必需的新手教程和操作提示。
- 支持核心流程的中文文本、本地化键和百科说明。
- 能清楚区分境界、流派、稀有度、卡牌状态和词条的视觉表现。
- 必要音效、动画和反馈，优先保证战斗结算与操作可读性。
- 当前英雄、永久卡、地牢卡、仓库、装备、解锁和秘境进度所需的存档与读档。
- 只有普通营地或秘境房间可以保存；读档后恢复同一英雄、当前房间和跨轮层级。
- 利用 AI 提高场景美术、音乐和文本制作效率，但所有生成内容需经过筛选与统一处理。

### 不在 DEMO 内

- 三部曲主线和多世界剧情。
- 魂骨钉完整能力树及主线科幻揭示。
- 大规模剧情 CG、配音和复杂演出。
- 完整多语言版本。
- 与核心循环无关的新小游戏。
- 为展示技术而增加的 LLM 还价、动态对话等功能。

## 5. DEMO 明确排除的长期内容

以下内容不得因为相关系统已经存在而自动进入 DEMO：

- 六边形沙盒世界及其地图移动、探索和地图交互；
- 六边形随机地牢与空间展开式迷宫；
- NPC 社会、月度自主行为、任务与门派生涯模拟；
- 完整 Stacklands 经营游戏和卡牌化生产面板；
- 完整门派 4X、据点挑战、战略 AI 与外交系统；
- 商路、贸易路线和复杂生产线；
- 家宅升级、完整私人领地和玩家建国；
- 完整拍卖玩法和复杂拍卖经济；
- 大量临时队友、傀儡、队伍编排；
- 全部门派法令、高级职位玩法；
- 全部辅助职业、阵法、幻术、通灵和显圣体系；
- 三部曲主线剧情及平行世界；
- 与核心循环无关的新系统和新小游戏。

六边形地图引擎与既有世界代码可以保留，但不作为当前版本的必经流程或验收依赖。未来只有在领地、资源、邻接、距离和地形本身构成门派经营策略时，才考虑将六边形随机沙盒用于独立的门派模拟部分。

长期想法记录在 `TODO.md`、`NEXT.md` 或其他设计文档中。DEMO 开发期间新增想法默认进入后续候选，不自动改变本文范围。

## 6. 建议的 DEMO 内容边界

DEMO 应当是一段有明确终点的体验，而不是无限内容沙盒。

建议目标：

- 新玩家能够在开始后的较短时间内完成营地准备并进入第一次战斗。
- 前 30 分钟内至少经历一次有意义的卡牌、装备或天赋选择。
- 玩家能够完成一轮从营地准备、秘境验证到 Boss 胜利、返回营地并提高下一轮层级的完整体验。
- 优先完成结丹及以下的内容，以凝气产资源、筑基减费和结丹特色机制展示流派差异；还婴、化神及对应终极内容默认进入后续版本。
- DEMO 提供明确的 Boss 或阶段目标，达成后返回营地显示完成反馈，并在当前境界上限内提高下一轮层级。
- 五流派可以逐步全部开放，但不要求玩家在单次试玩中体验全部流派，也不以展示全部内容作为通关条件。

具体场景、敌人和 Boss 数量服从节奏与测试需要，不为追求内容数量而复制低差异内容。

## 7. 推荐实施顺序

### 阶段一：完成悟道单流派垂直切片

- 使用固定初始卡组与悟道现有内容。
- 从旧地牢迁移普通敌人、精英、Boss、休息和随机商人，组成固定顺序的路线。
- 打通普通战斗、随机商人、休息、精英、奖励和 Boss。
- 接入当前英雄的卡牌获取、精炼、天赋分配与境界突破。
- 使用占位背景和基础敌人，不等待其他流派或最终美术。
- 验证资源循环、战斗时长、奖励价值和构筑选择。

### 阶段二：接入固定营地、跨轮结算与难度循环

- 完成营地仓库、功能入口和每轮准备。
- 完成无世界存档与读档，角色和永久资产跨轮保留。
- 实现 Boss 后返回营地并提高层级，失败或放弃返回营地并重置层级。
- 验证“营地准备 → 秘境冒险 → Boss／失败 → 整理与突破 → 下一轮”的完整循环。

### 阶段三：扩展流派与内容

- 按御剑、其他已具备完整设计的流派顺序扩展。
- 同步敌人卡组、资源配置和基础 AI。
- 补齐结丹及以下的普通卡、关键天赋和必要绝世内容。
- 冻结非必要的新战斗机制。

### 阶段四：整合与外部试玩

- 调整固定路线、场景内容、敌人、奖励、修炼和境界突破节奏。
- 完成新手引导、DEMO 阶段目标和结束提示。
- 统一 UI、文本、场景插画、图标、音效和必要美术。
- 测试不同流派、固定路线、随机内容种子和存档流程。
- 根据外部反馈修正节奏与可读性，而不是继续增加系统。

## 8. DEMO 验收标准

只有同时满足以下条件，才认为 DEMO 的核心开发完成：

### 核心流程

- 能从无尽模式入口开始，不依赖开发者指令完成整个 DEMO 流程。
- 随机角色、营地准备、固定路线前进、战斗、奖励、修炼和 Boss 胜利之间没有阻断流程的问题。
- 玩家能够达成明确的 DEMO 阶段目标并看到完成反馈。
- 玩家始终可以放弃当前冒险并按失败规则返回营地。
- 存档和读档后，当前英雄的卡组、仓库、装备、天赋、境界和路线索引保持一致。
- 失败保留角色、永久卡、仓库、装备栏与境界，只清除未保护的随身物品和地牢卡，下一轮从层级 0 开始。

### 战斗与构筑

- 每个已开放流派均能完成基础战斗与成长循环。
- 每个已开放流派至少有一种可被玩家理解和主动追求的有效构筑。
- 随机词条有比较和改造价值，不只是增加阅读量。
- 关键战斗机制、伤害预测和实际结算不存在明显矛盾。
- 敌人能正常使用对应流派资源与卡组。
- 基础构筑不依赖随机绝世内容才能成立。

### 秘境与节奏

- 固定路线在多个内容随机种子下均能完成，敌人、商人和奖励生成结果正确保存。
- 玩家不会因过长移动、搜索或不透明路线而迟迟无法进入核心玩法。
- 固定遭遇的顺序、强度、奖励和休息间隔能够支持当局构筑节奏。
- 持续装备与解锁提供追求，但不会立即破坏秘境成长节奏。
- 仓库、装备栏、随身物品和地牢卡的跨轮保留边界能够被玩家提前理解。

### 可用性

- 新玩家不依赖开发者口头说明，能够理解基本出牌、精炼、修炼、营地准备和秘境前进。
- 无法支付、无法前进、挑战失败和存档恢复等状态都有明确原因提示。
- 主要界面能够清楚展示卡牌差异、资源数量、装备变化和战斗结果。
- 不存在频繁阻断游戏的崩溃、死锁或严重存档问题。

## 9. 外部试玩需要验证的问题

DEMO 的首要目的不是证明所有系统都存在，而是回答：

1. 玩家是否喜欢随机词条功法与卡牌战斗的结合？
2. 玩家是否能形成有意的构筑，而不是只选择数值更高的物品？
3. 固定遭遇顺序、随机商人和奖励是否提供了足够清晰的挑战与成长节奏？
4. 境界突破和 Boss 胜利是否让持续成长具有意义？
5. 装备与卡牌保留是否令人期待更高难度，还是促使玩家重复刷取数值？
6. 失败丢失未入库且未装备的随身物品、移除地牢卡并重置层级，同时保留角色和永久资产，是否公平、清楚并能被玩家接受？
7. 玩家是否愿意在 DEMO 结束后以不同流派、装备或更高难度再玩一次？
8. 玩家最希望扩展的是战斗构筑、秘境场景、装备成长，还是未来的门派与世界互动？

后续开发方向优先根据这些答案决定，而不是仅根据长期功能清单决定。

## 10. 范围变更规则

DEMO 开发过程中，如准备新增功能，必须先回答：

- 它是否直接修复核心循环中的断点？
- 它是否解决外部试玩中的高频阻塞问题？
- 它是否比修复现有战斗、秘境、UI 和节奏更重要？
- 它是否会引入新的货币、界面、AI、存档结构或测试组合？
- 它是否只是因为某套引擎、代码或美术已经存在而被加入？

如果答案不明确，则该功能进入后续版本候选。

允许通过删减低差异内容保证整体完成度。不得以“系统已经做了一半”或“需要测试既有引擎”为理由继续扩大 DEMO 范围。

DEMO 的成功标准不是系统数量，而是：

> **玩家能否在固定营地与连续秘境之间，理解并享受一套完整的功法构筑、装备成长、境界突破与失败重来循环。**
